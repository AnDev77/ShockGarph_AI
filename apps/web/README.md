# 금융 시장 첫 화면

`index.html`은 모바일 우선 정적 화면이다. 개발 중에는 저장소 루트에서 `python -m http.server 8000 --directory apps/web`을 실행하고 `http://localhost:8000`을 연다. 아직 계정·관심 목록·공식 발표 자동 목록·채팅과 연결하지 않았다.

QQQ·SPY 가격 차트는 [TradingView의 무료 삽입 위젯](https://www.tradingview.com/widget-docs/whats-new/)이 제공한다. `market.js`는 허용된 두 종목의 위젯 속성과 원문 링크만 바꾼다. 우리 서버는 위젯 내부의 가격을 읽거나 보관·재배포하지 않는다. 브랜드 표기를 제거하거나 위젯 데이터를 자체 분석 API의 원본으로 사용하지 않는다. 이용자의 브라우저는 위젯 제공자에게 직접 접속하므로 배포 전 외부 스크립트·쿠키·개인정보 고지 및 실제 로드 상태를 브라우저에서 확인한다.

FOMC는 연준, CPI·고용은 BLS, PCE·GDP는 BEA의 공식 일정 링크만 제공한다. 아직 예정일 데이터나 발표 결과를 가져오는 수집기는 없으므로 카드에 날짜·수치를 만들어 넣지 않았다. QQQ 비공개 Alpaca 분석과 화면 차트는 분리돼 있으며, 과거 발표별 충격·미래 예측 수치는 검증과 게시 권한 확인 전까지 `HOLD`다.

실제 배포 경로, Java 로그인·종목방 연결, 공식 발표 API 연동과 웹 화면의 사용자 흐름 검증은 후속 작업이다.
