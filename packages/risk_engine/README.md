# 일별 위험 계산 패키지

`shockgraph_risk.daily`는 가격의 실제 이용 가능 시각을 검증한 후, 과거 가격만으로
5·20거래일 변동성 기준선을 만들고 미래 정답을 별도 단계에서 붙인다. 명시된
거래소 세션 목록과 수정 종가가 필요하다. 공급원 어댑터, 실자료 성능 주장,
실제 가격에 기반한 포트폴리오 손실 및 종목 채팅은 아직 구현되지 않았다.

`shockgraph_risk.macro_panel`은 보관된 전체 가격 스냅샷에서 계산한 기준선에
전통 시장 지표와 **발표 전에 이용 가능했던 하나의 고정 계약 확률**을 결합한다.
지표는 관측·이용 가능 시각을, 발표 일정은 공지·이용 가능·발표 시각을,
확률은 기존 `ProbabilitySnapshot`의 관측·이용 가능 시각을 각각 검사한다.
선택된 관측의 출처와 원본 해시를 유지하고, 정해 둔 최신성·발표 선행 기간을
넘거나 값이 없으면 제외 사유를 센다. 결과의 `traditional_rows`는 B 입력이고,
`probability_rows`는 각 행의 바로 그 B 입력과 A 가격 기준선을 참조한다.
같은 날짜의 A/B/C 비교를 *별도 연구로* 수행한다면 `probability_rows`에 있는
행만 사용한다. 첫 제품의 A/B 위험 모델에는 이 행이 필요하지 않다. Kalshi
확률은 계약 정의와 시점·권리가 확인될 때 특정 계약의 당시 기대를 설명하는
맥락 자료다. 단일 CPI 임계값 계약을 CPI 전체 결과 분포라고 부르지 않는다.
현재는 합성 자료의 결합 경로만 검증했으며 실제 가격·시장 지표·확률 공급원의
권리와 모형 B/C의 학습·표본 외 성능은 아직 확인하지 않았다.

`shockgraph_risk.portfolio`는 **합성 다자산 가격**의 공통 세션과 공개 시각을
검증하고, 일별 재조정 비중의 공동 수익률로 5·20거래일 최근 변동성/EWMA
기준선을 계산한다. 미래 포트폴리오 수익률은 사후 평가에만 사용한다.
방법과 연준 연구의 적용 경계는
[포트폴리오 위험 예측 방법론](../../docs/portfolio-risk-methodology.md)을 따른다.
