# ShockGraph AI의 포트폴리오 설명

## 프로젝트 소개

ShockGraph AI는 거시경제 이벤트의 시장 내재확률과 과거 자산 반응을 연결하는
시나리오 리스크 분석 시스템이다. CPI를 당시 컨센서스 대비 상회·부합·하회로 나누고,
SPY·TLT의 과거 수익률 분위수와 표본 수를 보여주는 읽기 전용 웹 서비스를 구현했다.
현재 동작 화면의 수치는 합성 데모이며 실제 시나리오 자료 연결은 남아 있다.

## 문제 해결과 구현 성과

서로 다른 출처의 자료를 단순 날짜로 합치면 실제 발표 이후 정보가 입력에 섞일 수 있었다.
Kalshi 관측·가용 시각, BLS 최초 발표 시각·값, Alpaca ETF 분봉 가용 시각을 구분하고
UTC 계약·사건 단위 분할·제외 사유·원본 해시를 갖춘 검증 파이프라인을 구축했다.
실제 발표시각 정렬 수정으로 공통 표본이 27건에서 24건으로 바뀐 기록도 보존했다.
이는 검증 가능한 누수 방지 규칙을 구현한 경험이며 정합성 100%를 주장하는 성과가 아니다.

다중 CPI 임계값의 YES 확률에는 임계값이 높아질수록 확률이 작아지는 제약이 필요했다.
PAVA 기반 등위회귀로 단조 곡선을 구성하고 최대 보정량 0.05 초과를 거절했다.
정확한 인접 계약이 있을 때만 컨센서스 하회·부합·상회 확률을 만들고, 없는 경계를
임의 보간하지 않는 품질 계약을 구현했다. 호가의 경제적 편향까지 제거했다고 주장하지 않는다.

확률 예측에는 Brier, 수익률 분포에는 CRPS를 적용해 비교 기준과 불확실성을 분리했다.
24개 CPI 사건에서 단순 과거 빈도 대비 개선이 있었지만 ETF 추가 예측력은 입증되지 않았다.
이에 미래 가격을 약속하는 화면을 시나리오별 과거 반응의 기술통계 화면으로 전환했다.
FastAPI·Next.js·Chakra UI, 동일 출처 조회 프록시, 컨테이너 및 CI 검증 구성을 연결했다.

## 이력서에 사용할 수 있는 표현

- 거시 이벤트·예측시장·ETF 자료의 UTC 정렬, 사건별 분할, 가용시각 검증과 원본 계보를
  갖춘 데이터 파이프라인 및 Brier·CRPS 기반 평가 도구 구현.
- PAVA 기반 단조 확률곡선과 정확한 컨센서스 경계를 사용한 배타적 시나리오 구성,
  표본 수·과거 분위수·데모 출처를 명시하는 분석 API와 웹 화면 구현.
- 자산 예측 추가 효과가 확인되지 않은 검증 결과를 근거로 제품 범위를 시나리오 분석으로
  전환하고, 읽기 전용 조회·배포 구성·실제 자료 연결 조건을 분리한 제품 설계.

## 표현하지 않을 내용

미래 정보 누수 완전 차단, 백테스트 정합성 100%, 모든 관측이 정확히 발표 5분 전,
Kalshi의 자산 예측력 입증, 실사용자 수익률 개선, 운영 DB·무중단 배포 완료는 근거가 없다.
실제 공개 URL을 확보하기 전에는 배포 완료로 소개하지 않는다.
합성 자료의 사건 수·분위수를 금융 예측 성과로 쓰지 않는다.
