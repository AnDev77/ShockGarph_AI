# 포트폴리오 위험·리밸런싱 방향 결정 리뷰

기준일: 2026-11-02. 사용자가 QQQ·SPY ETF 분석에 본인 포트폴리오 조정과 PB 검토 가능성을 결합하도록 명시적으로 방향을 변경했다. 원격 main `a993373`와 열린 PR #8~#13을 확인하고 별도 worktree에서 시작했다. 기존 일일 TLT 분석, Kalshi 사건 맥락, 종목방은 이력/병행 기능으로 보존한다. 새 제품 판단의 단일 기준을 `docs/current-product-direction.md`로 정하고 `AGENTS.md`가 이 문서를 먼저 읽도록 바꿨다.

## 중간 검토와 선택

- ETF 가격과 지수의 구분, 자산 사이 공동 움직임, 투자자의 목표 비중·현금 흐름·비용을 분리했다. QQQ와 SPY만으로 방어적 조정을 시험할 수 없어서 추가 자산의 권리·공통 날짜를 선행 조건으로 놓았다.
- 현재 합성 포트폴리오 코드는 매일 고정 비중을 가정한다. 정책 비교의 보유 유지·정기·허용 범위와 같지 않으므로 기존 결과를 정책 성과로 재표시하지 않는다.
- 연준 2026 개정 논문의 고빈도 실현 변동성과 프로젝트의 일봉 기반 미래 변동성은 다른 목표다. HAR/상태전환/ML은 고빈도 자료·충분한 독립 시험이 확보된 뒤 후보로 둔다. PCA-FHS의 상관 급변 시 이점도 개인 ETF 리밸런싱의 성과로 전용하지 않는다.
- Vanguard의 목표일 펀드 문턱값은 특정 상품의 설정이다. 보유 유지, 정기, 허용 범위를 먼저 고정하고 순성과·거래비용·목표 이탈을 비교한다. AQR의 위험 모델 연구는 거래 속도와 비용을 포함해 평가할 근거로 쓴다.
- 기관 PB를 실제 사용자로 부르기 전에 투자 기간, 허용 손실, 현금 필요, 비용·세금, 보고서 감사 가능성 및 사용권을 별도 검증한다.

## 검증과 남은 조건

이번 작업량은 현재 방향 1개 신설, 개발 기준 1개 개정, 기능 리뷰 1개 신설이다. 알고리즘이나 백테스트 코드를 수정하지 않았다. Markdown 링크·용어·금지된 비공개 수치·중복 목표를 점검하고 `git diff --check`로 공백을 검사한다. 따라서 wheel, Ruff/Pyright, 전체 시험은 기존 코드의 통과 근거를 새 변경의 성능으로 재사용하지 않는다. 새 초안 PR의 원격 문서 게이트를 확인하고 기록한다.

실제 SPY·QQQ·방어 자산의 이용 가능한 공통 수정가격과 공개 표시권, 사용자 현금흐름, 거래비용, 독립 미래 정답은 아직 확보되지 않았다. 실증 모델 정확도, 리밸런싱 순성과, PB 채택 수요는 모두 HOLD다. 이전 진행/장애/검증표 전체는 과거 비공개 수치로 자동 승인 검토가 거절됐으므로 이 PR에 다시 업로드하지 않는다. 원본 가격·비밀값·비공개 MAE/CI도 기록하지 않는다. PR은 초안이며 병합·배포·투자 주문을 하지 않는다.

다음 작업은 `packages/risk_engine/shockgraph_risk/rebalance.py`의 보유 유지·정기·허용 범위 시뮬레이션과 `tests/unit/test_rebalance.py`의 현금·비용·거래일 검증이다. 그 결과가 생겨도 실제 고객에게 비중을 권하거나 PB 검증 완료로 표현하지 않는다.
