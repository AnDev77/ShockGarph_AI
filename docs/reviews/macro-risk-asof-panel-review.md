# 거시 확률과 TLT 위험 입력의 시점별 결합 리뷰

검토일: 2026-10-20

## 변경 목적과 계산 구조

가격만 쓰는 TLT 변동성 기준선 A와 발표 전 거시 확률 모델 C 사이에는
당시 이용 가능했던 금리·VIX 등 전통 입력 B를 같은 날짜에 맞춰 결합하는
경로가 필요했다. [새 패널](../../packages/risk_engine/shockgraph_risk/macro_panel.py)은
기존 전체 수정가격 스냅샷으로 계산한 `VolatilityForecast`에 지표 관측과
사전에 고정한 거시 계약의 확률 스냅샷을 붙인다. 가격 입력 지문이 없는
예측은 거부한다. 지표와 확률은 각각 `observed_at`과 `available_at`이 모두
`prediction_at`을 넘지 않아야 하며, 공식 발표 전 확률만 선택한다.

일정도 실제 공지 후 이용 가능했던 `available_at`을 검사한다. 같은 기간에
발표가 여러 개라면 사전에 알려진 가장 가까운 발표를 선택하며, 그 발표의
고정 계약에 자료가 없으면 다른 발표의 확률로 대체하지 않는다. 뒤늦은 수정
값은 이전 예측 행을 바꾸지 않는다. 결측·오래된 지표, 알 수 없는 예정 발표,
결측·오래된 확률을 구분해 제외 횟수를 센다. C 행이 참조하는 B 행에는 같은
날짜의 A 기준선이 들어 있으므로, 후속 A/B/C 비교는 **C가 가능한 공통
날짜**만을 사용해야 한다. 하나의 CPI 임계값 계약은 전체 CPI 확률 분포가 아니다.

| 파일 | 역할 |
|---|---|
| `packages/risk_engine/shockgraph_risk/macro_panel.py` | 시장 지표·사전 공지 일정 계약, 발표 전 확률의 시점별 선택, A/B/C 공통 행과 커버리지 생성 |
| `tests/unit/test_macro_risk_panel.py` | 미래 값·사후 수정의 누수 방지, 고정 계약과 가까운 발표 선택, 결측·오래된 입력, 가격 스냅샷 기준선 결합 검사 |
| [위험 패키지 안내](../../packages/risk_engine/README.md), [프로젝트 흐름](../project-flow.md) | 구현 범위와 다음 실자료 연결 조건 표시 |

## 확인한 결과와 한계

합성 예측 시작일 3개에서는 A 3행, 지표가 갖춰진 B 3행, 발표 전 계약 확률까지
갖춘 C 2행을 만들었고 C 2행이 같은 발표 1건에 속함을 확인했다. 보관 가격
스냅샷에서 계산한 별도 합성 기준선 4행에도 지표 4행과 확률 2행이 연결됐다.
이는 **행 결합의 결과**이며 5·20일 TLT 예측 성능, 두 개의 독립 발표,
실제 공급원의 과거 게시 시각이나 권리를 입증하지 않는다. 계약 호가의
스프레드·거래량 품질과 다중 결과 구간의 완전성도 이 패널만으로 판정하지
않는다. B/C 모형의 학습, 정답과의 비교, 머신러닝 D는 이번 작업에 없다.

`make quality PYTHON=.venv/bin/python`에서 Ruff의 정적 규칙 검사는 오류 없이
완료됐고 Pyright는 오류 0개·경고 0개였다. `make test PYTHON=.venv/bin/python`의
전체 계약·단위·통합 시험 120개가 통과했으며 이번 7개 시험이 새 패널의
시점 규칙을 검사한다. 늦게 도착한 같은 관측의 수정값을 넣었을 때 앞선
날짜의 지표와 확률은 바뀌지 않았고 다음 날짜에서만 새 값이 선택됐다.
금리·VIX 중 하나가 빠지거나 발표 전에 유효한 확률이 없으면 해당 C 행은
생기지 않았고 제외 사유가 보고됐다. `git diff --check`에서도 공백 오류는
없었다. 이 검증은 합성 자료와 기존 코드 회귀 검사이며 공개 예측 승인이 아니다.

## 사용자 점검표와 다음 분석

- [ ] 가격·금리·VIX·계약 확률의 **원천별** 실제 수신 시각과 연구·외부 공개
  권리를 확인한다.
- [ ] CPI/FOMC 등 같은 사건의 계약 정의와 발표 시각, 예정일 변경 이력을
  검토한다. 현재 패널은 사건당 하나의 고정 일정·계약만 받는다.
- [ ] 실제 공통 날짜와 고유 발표 수, 결측·오래된 값의 비율을 먼저 센다.
- [ ] B와 C의 학습 전에 신선도·발표 선행 기간 및 계약 선택을 고정한다.
- [ ] 후속 독립 시험에서 A/B/C의 같은 날짜·정답과 겹치는 미래 구간을
  고려한 오차·불확실성을 비교한다.

다음 작업은 이 패널에 공급원별 실제 관측을 넣어 커버리지를 조사하고,
자료와 권리가 확인된 범위에서 B와 C를 동일 모형으로 학습·평가하는 것이다.
