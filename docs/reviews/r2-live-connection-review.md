# R2 실연결 시험 리뷰

## 변경 구조

기능 브랜치의 워크플로 파일을 갱신할 때만 실행하는 `push` 조건을 추가했다. 구성 검사 후 Alpaca SIP에서 TLT·SPY를 수집하며, 비공개 R2 버킷에 원본·가격 스냅샷·예측 기록을 저장한다. 저장 명령은 원격 객체를 다시 읽어 해시와 기록 시각을 검사한다. 마지막 단계는 같은 수집본으로 가격 이력 탐색 분석을 수행하고 자산별 거래일 수만 로그에 출력한다.

## 확인 기준과 한계

로컬 정적 검사와 테스트 결과, 원격 Actions 실행 링크와 상태를 각각 기록한다. 설정값이 비어 있거나 API 접근이 거부되면 원격 보관 성공으로 기록하지 않는다. 탐색 분석은 현재 조정 가격 이력을 재계산한 값이며 미래 가격의 독립 평가가 아니다. 첫 사전 예측의 5·20거래일 성능은 정답 기간이 지난 뒤에야 판정할 수 있다.

## 사용자 확인

- GitHub Actions의 실행이 성공했는지 확인한다.
- R2 비공개 버킷에서 객체가 생성되었는지 확인한다.
- 실패 시 민감값 대신 실패한 단계 이름만 공유한다.

## 로컬 검증 결과

`make quality PYTHON=.venv/bin/python`에서 Ruff 경고 0건과 Pyright 오류·경고 0건을 확인했다. `make test PYTHON=.venv/bin/python`에서는 175개 시험이 모두 통과했다. 이 시험은 원본 해시, 보관 예산, 읽기 재검증 및 시각 게이트의 합성 사례를 포함한다. 실제 Cloudflare R2의 권한과 Alpaca 응답, 새 예측의 성능은 이 로컬 시험만으로 확인할 수 없다.
