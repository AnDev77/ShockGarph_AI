# 다년 Nasdaq 거래일과 보관 가격 평가 연결 리뷰

작성일: 2026-10-21. TLT 변동성의 동일 날짜 A/B 평가에 필요한 거래일 검사를
2024~2026년으로 넓혔다. 이 변경은 여러 해의 **실제 가격을 확보한 결과가 아니며**
모델 성능 판정은 계속 `HOLD`다.

## 변경된 코드 구조

- `shockgraph_data_pipeline.market_calendar.nasdaq_sessions`는 검토한 연도별
  미국 주식시장 휴장·조기 폐장과 미국 동부시간의 일광절약시간을 적용해 UTC
  종가 시각을 만든다. 기존 `nasdaq_2026_sessions`는 2026년 전용 호출자를
  위해 유지한다. 달력 지원 범위 밖의 연도는 주중이라는 이유로 세션을
  만들어 내지 않는다.
- `daily_price_import.import_daily_prices`와 `evaluate_snapshot_holdout.py`의
  manifest 로더가 같은 다년 달력을 사용한다. 기존 CSV·manifest 입력 형식과
  출력의 비공개 판정 규칙은 유지하되 달력 버전을 2024~2026년 검토본으로 남긴다.
  가격 행이 휴장일에 있거나 실제 조기 폐장 시각과 다르면 품질 검사에서
  거부한다. 기존 5·20일 기준선과 A/B 모델도 동일한 manifest 로더를 사용한다.
- [Nasdaq 2024년 달력](https://www.nasdaqtrader.com/content/technicalsupport/2024tradingcalendar.pdf),
  [2025년 달력](https://www.nasdaqtrader.com/content/technicalsupport/2025tradingcalendar.pdf),
  [2026년 거래일 안내](https://www.nasdaqtrader.com/trader.aspx?id=calendar)를
  기준으로 했다. 2025년 1월 9일 지미 카터 전 대통령 국가 추모일의 임시
  휴장은 [거래소 추가 공지](https://www.nasdaqtrader.com/TraderNews.aspx?id=ETA2024-87)를
  별도로 적용했다. 연간 예정 달력만으로 과거 실제 세션을 모두 증명할 수
  없으므로 공급원 원장과 개별 예외 공지의 후속 대조가 필요하다.

## 검증 결과와 의미

달력 함수로 계산한 전체 예정·확인 세션은 2024년 252개, 2025년 250개,
2026년 251개다. 2024년 12월 24일 조기 폐장은 18:00 UTC, 2025년 1월
10일 정규장 종가는 21:00 UTC, 2025년 7월 3일 조기 폐장은 17:00 UTC로
확인했다. 2025년 1월 9일 가격을 합성 manifest에 삽입하면 스냅샷의
거래일 범위 검사가 보고를 거부했고, 정상적인 2024년 말~2025년 초
합성 스냅샷은 원본 해시와 함께 같은 평가 경로를 통과했다. 2024년 11월부터
2025년까지 이어지는 75개 합성 세션에서는 2025년 1월 9일을 제외한
같은 날짜로 GARCH·가격 Ridge(B0)·금리 Ridge(B1)도 평가했다. 이 경우
학습 가능 행 31개, 공통 시험 날짜 30개였고 GARCH 학습 수익률은
39개로 **테스트 한정** 최소 30개를 넘었다.

`make test PYTHON=.venv/bin/python`에서 계약·단위·통합 시험 **132개가 모두
통과**했다. 신규 달력 시험은 연도 경계와 임시 휴장, 조기 폐장, 지원 밖 연도
거부를 확인했고, 신규 CLI 시험은 다년 manifest가 수집된 전체 가격 파일로
평가되며 가짜 휴장일 가격이 차단되는지 확인했다. 다년 모델 시험은 훈련
정답 스냅샷이 홀드아웃 경계 시점에 고정되고 A/B/GARCH가 같은 평가
기간에서 계산되는지도 확인했다. `make quality
PYTHON=.venv/bin/python`에서 Ruff는 오류가 없었고 Pyright는 오류 0건,
경고 0건이었다. `git diff --check`도 공백 오류가 없었다. 테스트의 가격은
모두 합성 자료이므로 132개 통과와 거래일 수는 **TLT 예측 오차의 측정값이
아니다**.
