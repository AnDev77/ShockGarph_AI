# 26~27일차 종목·기간별 표본 평가 리뷰

## 작업 목표와 변경 구조

세 ETF와 두 관찰 기간 모두의 가격이 완전해야 한다는 교집합 조건 때문에 개별 종목의
가용 사건까지 잃는 문제를 분리한다. Kalshi의 발표 전 확률 품질 조건은 그대로 유지한다.

- `scripts/evaluate_cpi_asset_groups.py`: CPI 발표·Kalshi 품질 판정·Alpaca 분봉으로
  종목(SPY·TLT·GLD)과 기간(5분·30분)별 독립 표본을 구성하고, 시간순 확장 학습으로
  과거 사건 평균 수익률과 0 수익률 기준선의 절대오차를 비교한다.
- `.github/workflows/alpaca-cpi-validation.yml`: 기존 전체 교집합 평가와 손실 진단을
  유지하면서 종목별 집계 결과를 Actions 요약 및 14일 보관 Artifact에 추가한다.
- `tests/integration/test_asset_group_baseline.py`: 종목별 결측과 Kalshi 품질 탈락,
  최소 시험 사건 게이트, 개별 수익률 비공개, 입력 변경 시 결과 불변성을 검증한다.

## 평가 해석과 한계

각 종목·기간은 자신의 완전한 가격창과 `eligible` Kalshi 사건만 사용한다. 처음 5건을
학습하고 그 이후는 해당 시험 사건보다 앞선 사건의 수익률만 이용한다. 시험 사건이
10건 미만이면 `insufficient_test_events`로 표시하고 오차 지표를 공개하지 않는다.
종목마다 사용한 사건 집합이 다를 수 있으므로 오차를 그대로 비교해 특정 종목의
예측력이 더 좋다고 결론 내릴 수 없다. 이는 **가격만 사용하는 진단 기준선**이며,
Kalshi 확률이 예측 성능을 높였다는 검증도, CPI의 인과 효과 추정도 아니다.
입력 CSV 해시와 집계 수치만 공개하고 개별 가격·수익률·사건별 예측은 남기지 않는다.

평균 절대오차(MAE)는 5분 SPY 0.003453·TLT 0.003899·GLD 0.003278,
30분 SPY 0.003476·TLT 0.004349였다. 같은 각 조합에서 0 수익률 기준선은
차례로 0.003340·0.003746·0.003450, 0.003654·0.004358이다.
따라서 단순 과거 평균이 0 기준선보다 항상 나은 것도 아니며, 이 수치로
Kalshi의 추가 예측력을 주장할 수 없다. GLD 30분의 MAE는 비공개다.
