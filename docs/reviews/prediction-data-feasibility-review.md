# TLT 예측 실증을 위한 데이터 가능성 판정 리뷰

작성일: 2026-10-20. 사용자 요청에 따라 모델을 추가하기 전에 **실제 자료로
예측력을 판정할 수 있는가**를 점검했다. 최종 판정은 `HOLD`다. 실제 TLT의
예측력이 부족하다는 실험 결과는 아직 없으며, 합성 가격 성능을 실증으로
전환하지 않았다.

## 확인한 사실과 수치

- 저장소의 가격 입력은 합성 CSV와 합성 시험 이력뿐이다. `data/raw/`의 실제
  공급원 원본, 이 작업 환경의 공급원 키·계약 증빙은 확인되지 않았다.
  비밀키의 값을 열람하거나 저장하지 않고 구성 여부만 점검했다.
- 현재 `market_calendar.py`와 CSV CLI는 2026년 Nasdaq 예정 일정으로 제한된다.
  2026-01-02부터 2026-10-19까지 200개 예정 세션에서, 매일 유효한 파일이
  **있다고 가정해도** 20일 목표의 평가 가능한 정답은 최대 160개, 겹치지 않는
  미래 구간은 최대 8개다. 실제 홀드아웃과 결측을 적용하면 이보다 작다.
- [iShares TLT 자료](https://www.ishares.com/us/products/239454/ishares-20%20-year-treasury-bond-etf)는
  NASDAQ 상장과 월별 분배를 표시한다. 원시 종가의 분배락과 분배를 반영한
  수익률은 정의가 다르므로 예측 목표의 가격 기준을 공급원별로 일치시켜야 한다.
- [Databento EOD 종가 예제](https://databento.com/docs/examples/equities/closing-prices),
  [시점별 기업행동](https://databento.com/docs/venues-and-datasets/corporate-actions),
  [조정계수](https://databento.com/docs/venues-and-datasets/adjustment-factors)는
  전체 수정가격 파일을 매일 보관하지 않고 당시 정보로 재구성할 **후보 경로**다.
  TLT의 실제 커버리지와 자료 정정 시각, 분배 처리, 구독·외부 표시 권리는
  샘플이나 계약으로 아직 확인하지 못했다.
- [Alpha Vantage 수정 일봉](https://www.alphavantage.co/documentation/)은 Premium
  자료를 설명하나, 현재 한 번 내려받은 수정 이력으로 과거 각 날짜의 파일을
  되살릴 수는 없다. [상업적 이용 조건](https://www.alphavantage.co/terms_of_service/)과
  과거 버전 제공 여부도 확인해야 한다. FRED/ALFRED의 경제지표 빈티지는
  TLT 가격의 대용이 아니다.

## 제품 판단

| 조건 | 판정과 작업 |
|---|---|
| 실가격·시점별 기업행동·이용권 중 하나라도 확인 불가 | 예측 실증 `HOLD`. 분석 모델·API 예측 화면에 합성 성과를 연결하지 않는다. |
| 여러 해의 실제 가격과 당시 이용 가능한 조정 정보 확보 | 다년 달력·시점 계약을 추가하고 먼저 5일 기준선의 표본 외 오차를 측정한다. 20일은 유효 비중첩 구간과 국면별 오차를 별도 평가한다. |
| 시장 변수/복잡한 모델이 기준선보다 낫지 않음 | 학습 모델을 승격하지 않는다. 기준선 자체의 실측 오류와 표시 가능성은 별도로 판정한다. |
| 데이터 확보가 지연되거나 제품 표시 권리가 없음 | 출처·공개 시각을 갖춘 경제지표·공시 변화 레이더를 별도 가설로 검증한다. 검증되지 않은 미래 위험 숫자는 내지 않는다. |

## 검증 기록

이번 작업은 **데이터 인벤토리와 공식 공급원 문서의 대조**이며 실자료
모델 백테스트가 아니다. 로컬 가격 파일과 공급원 접근 설정이 없음을 확인했고,
예정 거래소 달력 함수로 200개 세션과 20일의 라벨 상한을 계산했다.
`make quality`에서 Ruff 검사가 통과했고 Pyright는 오류·경고 0개를 보고했다.
`make test`의 기존 계약·단위·통합 시험 106개가 모두 통과해 가격 입력과
시점별 예측의 기존 동작에 회귀가 없음을 확인했다. 이 시험 중 실제 TLT 가격을
사용한 경우는 0개이므로 통과 결과가 TLT 예측력을 증명하지는 않는다.

## 사용자 점검표와 다음 작업

- [ ] TLT의 여러 해 종가·분배·분할 이력을 같은 공급원에서 확보할 수 있는가?
- [ ] 각 과거 예측 시점에 실제로 알려진 값과 정정 시각을 재구성할 수 있는가?
- [ ] 비공개 연구와 외부 웹 서비스의 지표 표시 범위를 계약으로 구분했는가?
- [ ] 실제 샘플을 받은 뒤 달력 확장, 원본 계보, 5일 기준선의 실증 평가부터 진행했는가?

위 세 데이터 조건을 충족한 작은 샘플과 사용 범위가 확인되면 공급원 어댑터를
연결한다. 샘플 없이 코드에서 당시 가격의 `available_at`을 추정하지 않는다.
