# 통계 변동성 기준선과 전통 지표 추가 효과 비교 리뷰

작성일: 2026-10-21. TLT의 미래 5·20거래일 변동성 연구에서 단순 가격 규칙이
분석 전체로 오해되지 않도록, GARCH(1,1) 통계 기준선과 동일 모형의
가격 전용 Ridge(B0)·전통 지표 Ridge(B1)를 같은 시점별 홀드아웃에 추가했다.
합성 입력의 구현 검증이며 실제 TLT 예측 성능 판정은 계속 `HOLD`다.

## 변경된 코드 구조

- `shockgraph_risk.garch`는 일별 로그수익률, 0의 조건부 평균, 정상성 조건
  `α+β<1`을 사용하는 GARCH(1,1)을 가우시안 준최대우도로 추정한다.
  [Bollerslev의 원 논문](https://doi.org/10.1016/0304-4076(86)90063-1)을
  통계 기준선의 근거로 삼고 SciPy의 제한 최적화를 사용한다. 이는
  [연준의 2026년 개정 비교 연구](https://www.federalreserve.gov/econres/feds/linear-and-nonlinear-econometric-models-against-machine-learning-models.htm)의
  주식 고빈도 실현 변동성 모델이나 HAR-RV를 재현한 것이 아니다.
- `traditional_model`은 홀드아웃 시작 당시 가격 스냅샷에서 **시작일
  이전** 수익률만 사용해 GARCH 모수를 한 번 고정한다. 시험 날짜마다 그날까지
  이용 가능한 완전 가격 버전으로 상태를 필터링하고, 알려지지 않은 미래
  충격 대신 조건부 기대 분산을 5·20일 전개해 평균한 다음 제곱근을 취한다.
  기본 훈련 수익률이 100개 미만이거나 추정이 수렴하지 않으면 GARCH
  점수와 비교 구간만 보류하고 이유를 남긴다.
- B0는 B1의 **동일 학습·평가 날짜, 정답, 로그 목표, 표준화, Ridge
  패널티 10**을 사용하되 가격 변동성 두 항만 입력한다. B1은 같은 두 항에
  DGS10 등 선택된 지표 수준을 더한다. 두 모형의 MAE·QLIKE와
  `B1−B0`의 기간 길이별 짝지은 블록 구간을 기록한다. 가격 입력 해시와
  지표를 포함한 입력 해시를 따로 남겨 입력 변경을 추적한다.
- 기존 최근 변동성·EWMA와 B1 비교는 유지하며 GARCH가 수렴한 경우에만
  같은 지표 공통 날짜에서 GARCH·B1의 오차를 비교한다. 비공개 보고의
  `schema_version`은 새 출력 필드에 맞춰 2로 높였다. SciPy는 이 비교기가
  실행되는 연구 경로의 제약 최적화 의존성으로 등록했다.

## 검증 결과와 해석

합성 가격 75세션, 합성 DGS10 시계열, 미래 5일 정답을 사용한 시험에서는
홀드아웃 전에 정답이 끝난 B0/B1 학습 행이 31개이고, 지표가 빠진 하루를
제외한 공통 시험 날짜가 29개였다. 비중첩 시험 구간은 보수적으로 5개로
계산했다. **테스트에서만** GARCH 최소 수익률을 기본 100개에서 30개로
낮췄고 실제 사용한 과거 수익률은 39개였다. 합성 자료의 MAE는 최근 변동성
0.003648, EWMA 0.004775, B0 0.001097, B1 0.001071,
GARCH 0.002472였다. 이 생성 자료의 `B1−B0` 짝지은 구간은 약
`−0.000180 ~ +0.000128`로 0을 포함한다. 이 숫자는 **실제 금리 정보의
효용이나 TLT 예측력**을 보여주지 않는다.

홀드아웃 뒤 최종 가격을 바꾸는 시험에서는 B0/B1 계수와 GARCH 모수,
학습 입력·가격 정답의 해시가 그대로이고 사후 평가 오차만 바뀌는지
확인했다. 지표 값만 바꾸는 시험에서는 B0 계수·오차·가격 입력 해시가
그대로이고 B1의 지표 입력 해시와 오차가 달라졌다. 지표가 항상 같은
값이면 B1과 B0의 MAE·QLIKE가 같았으며, GARCH의 첫 미래 분산은
알려진 마지막 수익률 충격에 반응하고 그 이후는 장기 분산으로 돌아가는
재귀식을 확인했다. 전체 테스트 및 정적 분석의 최종 결과는 아래에 기록한다.

- `make test PYTHON=.venv/bin/python`: **129개 통과**. 새 시험은 지표 입력의
  순수 추가 효과, 홀드아웃 이후의 수정값이 모수를 바꾸지 않는지,
  GARCH의 다기간 재귀식과 기간별 평가 보류를 검증한다.
- `make quality PYTHON=.venv/bin/python`: Ruff 통과, Pyright 오류 0건·
  경고 0건. `git diff --check` 공백 오류 0건.

## 다음 데이터 조건과 사용자 점검

- [ ] 여러 해의 실제 TLT 가격 스냅샷과 DGS10의 **실제 게시·이용 가능 시각**,
  이용권, 거래소 달력을 확인한다. 현재의 한 벌짜리 수정종가 이력과 합성
  GARCH 결과는 독립 예측 성능이 아니다.
- [ ] B1−B0는 지표 입력 효과, B1−GARCH와 B1−EWMA는 서로 다른
  예측 방법 전체의 성능 비교라는 차이를 유지한다. 패널티와 지표 후보는
  최종 독립 시험을 열기 전에 훈련·검증 구간에서 확정한다.
- [ ] 일별 종가를 고빈도 실현 변동성이라고 부르지 않는다. HAR-RV는
  분봉 자료가 시점별로 확보된 뒤 별도 실험한다.
- [ ] ML 후보도 같은 입력·날짜에서 검증하고, 표본이 부족하면 복잡한 모형의
  수치 우위를 주장하지 않는다. Kalshi 계약 기대는 사건 맥락에만 둔다.
