# SPY·TLT 공동 시장 분석과 초기 채팅 범위 리뷰

**이전 설계 이력:** 공동 상관·동반 하락을 첫 화면에 둔 결정과
`joint_market.py`는 이후 사용자 피드백에 따라 철회했다. 현재 구현과 제품
범위는 [단일 종목 우선 리뷰](asset-first-market-overview-review.md)를 따른다.

검토일: 2026-10-21. TLT 단일 모델 연구를 첫 제품 화면의 유일한 경로로 삼았던
설계를 수정했다. **첫 공개 화면의 대상은 SPY·TLT**이고, 첫 예측 연구의
정답은 계속 TLT 5·20거래일 변동성이다. 채팅은 공동 분석 화면과 병행하는
작은 제품 기능으로 계획하며, 예측 성능이나 주주 인증의 증거로 취급하지 않는다.

## 이번 구현

- `joint_market.py`는 두 수정종가 이력의 같은 날짜를 맞춘다. 한 자산만 빠진
  날과 그 바로 다음 날의 수익률은 건너뛰어 여러 날의 변화를 하루 변화로
  잘못 세지 않는다. 최근 60개 등의 공통 수익률에 대해 각 ETF의 관측 일별
  변동성, 동반 하락 날짜 수, 상관관계, 입력 비중으로 매일 재조정했다고 가정한
  **과거** 누적 변화와 최대 하락 폭을 계산한다.
- `analyze_joint_market.py`는 SPY·TLT의 별도 비공개 CSV와 출처를 받아
  원본 해시·결측 수·날짜별 움직임을 JSON으로 기록한다. 현재 가격의 외부
  표시 권리와 전체 거래소 달력은 확인하지 않았으므로 출력은
  `public_display_allowed=false`, `is_prediction=false`다.
- 제품 명세와 화면 문서에서 SPY·TLT 관측을 첫 웹 화면으로, TLT A/B를 별도
  예측 연구로 분리했다. 로그인 쓰기 공개 채팅을 SPY·TLT 또는 특정 분석
  카드에 연결하고, 영속 메시지·커서 조회·WebSocket·신고·차단·전송 제한을
  첫 채팅 범위로 정했다. **채팅 서버와 웹 화면은 아직 구현하지 않았다.**

## 검증과 남은 입력

같은 날짜의 두 수익률을 고정 비중으로 합성했을 때 실제 과거 누적값과 맞는지
시험했다. 한 ETF 가격만 빠졌을 때 그 날짜와 이어지는 날짜를 함께 제외하는지도
시험했다. 공통 수익률이 부족하면 숫자를 내지 않는 시험도 포함했다.
`make test`의 전체 138개 테스트가 통과했고, `make quality`의 Ruff와 Pyright는
오류 0건이었다. 이 검증은 계산 경로를 확인할 뿐 실제 SPY·TLT 실증이나
사용자 화면의 가치를 입증하지 않는다.

현재 저장소의 비공개 실제 수정종가 파일은 TLT 한 종목뿐이다. SPY 실가격,
두 공급원의 외부 표시 권리, 동일 날짜가 양쪽에서 모두 빠진 경우를 찾을
거래소 달력 대조는 아직 없다. 따라서 실제 두 종목의 공동 결과, 공개 분석
화면, 채팅의 사용자 경험을 완료했다고 표현하지 않는다.

## 다음 세 작업의 완료 기준

1. **자료와 API:** SPY·TLT의 허가된 실가격과 공통 거래일을 확인해 실제
   공동 분석 JSON을 만들고, 결측·시각·권리 상태를 응답에 담는다.
2. **첫 화면:** 로그인 없이 두 종목의 같은 날짜 움직임, 동반 하락, 입력
   비중의 역사적 변화와 원본 시각을 보여준다. 사용자가 무엇을 판단했는지
   한 번의 화면에서 확인할 수 있게 한다.
3. **초기 채팅:** 공개 읽기·로그인 쓰기, 영속 저장·커서 조회·WebSocket,
   신고·차단·전송 제한을 첫 화면에 연결한다. 보유 인증 배지는 제공하지 않는다.

데이터 이용권과 실제 SPY 입력이 확보되지 않으면 첫 화면을 공개 성과라고
표현할 수 없으며, 공개 일정은 이 선결 조건에 따라 조정한다.
