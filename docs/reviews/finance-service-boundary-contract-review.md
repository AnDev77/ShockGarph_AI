# Java–FastAPI 금융 서비스 계약과 첫 배포 범위 리뷰

작성일: 2026-10-28. 이번 작업은 회원·관심 종목·토론의 최종 Java 소유와 공식 발표·가격·연구의 Python 소유를 요청·응답·이전 절차로 내린 문서 작업이다. 사용자 변경에 따라 개인 노트는 10월 31일 1차 배포 범위에서 제외했다. 구현된 금융 Java 서비스나 신규 QQQ 자료 수집으로 해석하지 않는다.

## 시작·중간·완료 근거

- 시작: ShockGraph 초안 PR #11의 FastAPI 관심 종목·사건 조회와 doChallenge 초안 PR #6의 로그인·운동 모임 STOMP 인증을 대조했다. 현재 두 DB를 동시에 업데이트하는 연결 기능은 없다.
- 중간: Java 로그인 응답의 `success/data/error`, FastAPI의 `/v1/me/watchlist`·`/v1/me/events` 실제 코드와 토큰의 `sub/iat/exp`를 확인했다. 금융 Java 회원 서버·공개 거시 사건 API·실토큰 연동은 목표로 남겼다.
- 완료 범위: [API 경계 계약](../api/finance-service-contract-v1.md)에 현재/목표 경로, 임시/최종 관심 목록 소유, 읽기 조립, 인증·오류·이전/롤백을 기록했다. [배포 계획](../finance-v1-2026-10-31-plan.md)과 `AGENTS.md`에서 첫 배포 노트를 제거하고 [이전 계획](../finance-community-five-day-milestones.md)은 이력으로 표시했다.

## 검증과 객관적 판정

변경은 기존 Markdown 문서 3개와 신규 API 계약·리뷰 2개에 한정한다. 원격 게이트의 wheel 빌드·내용 검사·Ruff/Pyright·전체 시험은 기존 코드 회귀를 확인할 뿐 실제 Java→FastAPI 호출을 검증하지 않는다. 실제 가입·로그인→금융 회원 관심 등록→공식 자료 조회→종목방 연결은 새 코드와 통합 시험이 필요하다. 오늘의 계약 성과는 소유권 충돌과 이전 시 실패 지점을 명시한 것이며 QQQ/SPY의 과거 리스크·예측 성능과 제품 수요는 `HOLD`다.

## 다음 기능의 인수 기준

1. Java 금융 회원 ID와 FastAPI 임시 ID의 일치 또는 대응표를 실제 환경에서 검증한다.
2. `iss/aud`·키 교체·탈퇴/차단·다른 회원의 목록을 실제 발급 토큰으로 시험한다.
3. 기존 FastAPI 목록 쓰기를 중지하고 Java 단일 DB로 옮길 때 중복·삭제·차이를 대조한다.
4. 공개 자료 API에는 회원 목록 사본을 쓰지 않고, 미래 공개 원문과 자료 권리 제한을 지킨다.

비밀값, 원본 가격, 비공개 성능 수치는 이 리뷰에 포함하지 않았다. 기존 진행·장애·검증표 전체는 이전 자동 승인 검토에서 거절됐으므로 공개 저장소에 재업로드하지 않는다.
