# 모델별 성과에 따른 제품 경로 정정 리뷰

검토일: 2026-10-20

## 잘못 묶였던 결정

이전 [제품 경로](../product-goal-and-fallback.md)는 거시 확률 C의 증분 성능이
없으면 수치 전망을 모두 숨기고 사건 리포트로 넘어가는 것처럼 읽혔다.
그러나 C가 B를 이기지 못해도 전통 정보 B가 가격 기준선 A를 이길 수 있다.
B도 개선하지 못하더라도 A의 실제 오차와 안정성을 검증해 유용한 기준 정보로
제공할 가능성은 남는다. 이때 A를 AI의 예측 우위나 손실 보증으로 팔 수는 없다.

자료 권리·과거 입력 시점·독립 시험이 없으면 현재처럼 `HOLD`이고 실패 판정이
아니다. C, B, A 각각의 독립된 검증 결과와 사업적 사용성을 분리해 기록한다.
신뢰할 수 있는 수치가 없을 때는 자동 사건·자산 리포트의 수동 조사 대비 효용을
별도로 실험한다. 리포트마저 효용이 없으면 **그 사업 가설**을 멈추고 사용자
문제를 다시 고른다. 데이터 파이프라인·연구 성과와 저장소를 폐기한다는 뜻은
아니다. 대상 자산을 바꿀 경우에는 새로운 평가 기준과 독립 기간을 먼저 확보한다.

## 바뀐 문서와 실행 코드 경계

- [제품 경로](../product-goal-and-fallback.md)에 C/B/A의 분기, 수치가 부적합한
  경우와 리포트 사업 가설의 중단 조건을 각각 명시했다.
- [제품 명세](../../shockgraph-ai-project-spec.md), [모델 설계](../tlt-volatility-model-design.md),
  [위험 방법론](../daily-risk-methodology.md), [화면](../product-ui-direction.md),
  [사용자 흐름](../project-flow.md), README·AGENTS의 같은 내용을 정렬했다.
- 데이터 수집, 모델 계산, API 및 웹 실행 코드는 수정하지 않았다. 실자료
  C/B 판정, A의 공개 품질, 사건 리포트의 사용자 가치, 커뮤니티 수요는
  모두 아직 검증 전이다. 현재 가격 전용 Ridge의 탐색 점수는 이 결정의
  C/B 비교나 제품 출시 근거가 아니다.

## 검증 결과와 범위

`make quality PYTHON=.venv/bin/python`에서 Ruff는 검사 오류 없이 완료됐고
Pyright는 오류 0개와 경고 0개를 보고했다. `make test PYTHON=.venv/bin/python`은
기존 가격 시점·위험 계산·이벤트 연구의 계약·단위·통합 테스트 113개가
통과했다. 수정된 Markdown의 상대 링크를 확인했으며 경로가 없는 링크는
발견하지 못했다. `git diff --check`에서도 공백 오류를 찾지 못했다.
이는 문서 정정에 따른 기존 코드의 회귀 점검이다. 실제 성과와 사용자
재방문을 입증한 시험은 아직 수행하지 않았다.
