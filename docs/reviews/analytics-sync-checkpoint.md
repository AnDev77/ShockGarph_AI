## 이어서 할 일

1. 집 PC의 별도 변경이 있다면 원격에 반영된 브랜치와 커밋을 확인하고,
   이 분석 브랜치와 비교한다. 확인되지 않은 로컬 작업을 임의로 덮어쓰지 않는다.
2. 데이터 이용이 승인된 환경에서 CPI의 발표 전 확률, 공식 최초 발표치,
   당시 기대값과 SPY·TLT·GLD 가격의 공통 기간을 확인한다.
3. 고정 임계값의 계약 정의, 발표시각, 수익률 측정 시작·끝, 사용 가능한 가격 빈티지를
   검증해 정규화 입력으로 연결한다.
4. 그 뒤 전통적 기대·최근 변동성 기준 모델, 실제 surprise 크기 모델을
   동일한 발표별 표본 외 시험 구간에서 비교한다.
5. 독립 사건 수·표본 외 손실 차이를 확보하기 전에는 자동 모델 승격이나 운영 배포를 시작하지 않는다.

현재까지 구현된 범위의 세부 사항과 명령은 [5~6일차 리뷰](day-05-06-review.md)를 따른다.
