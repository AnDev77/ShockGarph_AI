# 포트폴리오 가격본의 시점별 선택 — 기능 리뷰

## 시작 근거 (2026-11-03)

- main `a993373`, 최신 초안 PR #15 `67bffbb`를 확인했다. 별도 worktree에서 #15 위에 이 기능을 개발하여 미커밋 변경을 덮지 않았다.
- #15의 정책 계산기는 날짜별 가격이 이미 하나씩 선택됐다고 가정한다. 같은 거래일의 뒤늦은 정정 가격을 과거 판단에 넣지 않도록 하는 입력 계약이 비어 있었다.
- main의 11월 2일 생성된 예약 실행은 완료·성공이며 사전 검사, 보관, 재감사, 고유 시작일 감사, 공식 채점 단계가 모두 성공으로 기록됐다. 로그의 고유 사전 예측 거래일은 여전히 **1개**이므로 새 고유 거래일 확보는 확인되지 않았다. 단계 성공은 신규 보관이나 신규 정답 생성을 뜻하지 않는다.

## 중간 검증

- `point_in_time_panel.py`에서 공통 날짜·USD 조정 종가·원본 식별·이용 가능 시각을 검사하고, 각 과거 의사결정 시각까지 이용 가능했던 마지막 가격본을 선택한다. 동시각의 복수 가격본은 조용히 임의 선택하지 않고 중단한다.
- 합성 자료의 7개 사례는 통과했으나 첫 Pyright는 nullable `available_at`의 타입 축소 오류 2건을 발견했다. 명시적 `None` 필터로 고쳤다.
- 공급원 이름 목록은 연구 입력의 출처 통제일 뿐, 공급 계약·가격 재배포 권한의 증명은 아니다. 실제 공급원, 배당·분할 조정 규칙, 방어 자산 선택은 아직 검증 전이다.

## 완료 근거와 작업량

- 신규 기능 모듈 1개, 단위 시험 파일 1개(7개 사례), 공개 가능한 기능 리뷰 1개를 작성했다. wheel의 필수 7개 소스와 새 모듈 포함을 확인했고 Ruff·Pyright 오류 0건, 전체 시험 195개가 통과했다. 첫 wheel 검사 명령은 파일 경로를 빠뜨려 중단됐으며 경로를 넣고 재실행해 통과했다. [원격 PR 게이트 41592156287](https://github.com/AnDev77/ShockGarph_AI/actions/runs/41592156287)의 빌드·산출물 검사·정적 검사·전체 시험 단계도 성공했다.
- 기존 정책 계산기에 선택된 패널을 실제로 입력하는 합성 통합 사례가 있다. 원본 가격, 비밀값, 비공개 성능 수치는 기록하지 않았다.

## 연구와 제품 판정

- [연준 연구진의 2026년 9월 개정 논문](https://www.federalreserve.gov/econres/feds/linear-and-nonlinear-econometric-models-against-machine-learning-models.htm)은 S&P 500과 개별 40종목의 **고빈도 실현 변동성**을 대상으로 HAR, ARFIMA, 상태 전환, ML을 비교한다. 우리 목표는 ETF **일봉**의 5·20일 위험과 그에 따른 정책 효과다. 목표·빈도·대상이 달라 연구의 순위를 그대로 옮기지 않는다. 공통 날짜와 독립 미래 평가가 먼저 필요하다.
- [연준 연구진의 PCA-FHS 포트폴리오 증거금 연구](https://www.federalreserve.gov/econres/feds/portfolio-margining-using-pca-latent-factors.htm)는 상관 변화와 집중 위험을 점검할 후보 근거다. 청산소 증거금의 결과가 개인 ETF 리밸런싱 성능을 입증하지 않는다.
- [연준 2026 스트레스 시나리오](https://www.federalreserve.gov/publications/2026-stress-test-scenarios.htm)는 은행 자본을 평가하는 가상 충격이며 실제 경제 예측이 아니다. 향후 시나리오 민감도 설계 참고에만 사용한다.
- 이번 완료는 **합성 입력 소프트웨어 검사**다. 실제 QQQ·SPY·방어 자산의 동일 기준 가격·권리·배당 조정, 독립 미래 정답, 모델 성능, 리밸런싱 순효과, PB 수요는 **HOLD**다. 공개 추천이나 주문 실행의 근거가 아니다.
