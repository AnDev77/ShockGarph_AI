# 15~16일차 일별 위험 기준선과 데이터 시점 검사 리뷰

작성일: 2026-10-19. 제품 방향 전환 뒤 첫 구현 작업이다.

## 완료 범위

실제 ETF 성과 없이 일별 위험의 계산 경계를 먼저 구현했다. `AssetPriceRecord`에
수정가격 버전의 `available_at`을 추가했다. 과거 이벤트 연구 입력에서는 생략할 수
있지만 일별 위험에는 반드시 필요하다. 거래소 세션 목록은 가격 파일과 별도 인자로
받으며 결측·중복 날짜, 자산/통화/공급원 혼합을 거부한다.

| 경로 | 변경 |
|---|---|
| `packages/domain/shockgraph_domain/records.py` | UTC 이용 가능 시각과 관측 뒤 공개 순서 검증 |
| `packages/risk_engine/shockgraph_risk/daily.py` | 최근 변동성·EWMA, 미래 정답 분리, 학습 분할 purge, 쌍별 MAE/QLIKE와 블록 재표집 |
| `scripts/run_daily_risk_demo.py`, `Makefile` | 합성 가격만 사용하는 `make risk-demo` |
| `tests/unit/test_daily_risk.py`, `tests/unit/test_ingestion_records.py` | 미래 가격 변경, 늦은 공개, 결측 거래일, 정답 만료, UTC·분할·표본 수 검증 |
| `docs/data-source-gate-b.md`, `docs/daily-risk-methodology.md`, `README.md` | 새 코드의 경계와 공급원 권리 보류 상태 표시 |
| `docs/project-flow.md`, `docs/architecture.md` | 새 데이터·제품 경로, 모델·API·조건부 메시지 큐 구성과 실제 구현 상태를 흐름도로 구분 |

`make risk-demo`는 150개의 **합성 평일 세션**을 생성한다. 미국 거래소 휴장일과
서머타임을 재현하지 않으므로 실제 TLT 데이터 또는 성능으로 해석할 수 없다.
5·20일 목표는 `sqrt(sum(미래 일별 로그수익률²)/기간)`이며 같은 단위의 최근
실현 변동성과 EWMA를 비교한다. QLIKE는 예측 분산 하한 `1e-12`를 적용한다.

## 검증 결과

- `make quality`: Ruff 통과, Pyright 오류·경고 0개.
- `make test`: 전체 88개 통과. 신규 시점·수식·정답·평가 검사 9개 포함.
- `make risk-demo`: 5일 45개, 20일 30개 합성 평가 표본과 `DEMO` 표시 확인.
- 20일 데모의 평가 표본 30개는 20일 길이의 비중첩 블록 두 개보다 적어
  쌍별 재표집 구간이 `null`로 보고된다.

## 금융·제품 결정과 보류 사항

1. 예측 시점의 기준선은 과거 가격만 읽고, 정답은 미래 구간 모든 가격의 이용 가능
   시각이 지나야 붙인다. 분할 경계 전에 종료·공개되지 않은 정답은 학습에서 제외한다.
2. 날짜와 시각, 수정가격 버전은 다르다. 값의 관측일만 보고 과거에 이용 가능했다고
   간주하지 않는다. 실제 공급원 어댑터는 가격 빈티지와 이용권 검토 후 도입한다.
3. Alpha Vantage 수정 일봉은 Premium 표기 및 상업 이용 문의가 필요하므로
   원천 일봉이나 파생 서비스 결과를 공개하는 것을 승인하지 않았다. EIA/FRED
   관측일도 정확한 게시 시각이 아니다.
4. 현 상태는 TLT 실자료, Brent/금리/VIX 결합, PostgreSQL 저장, API, 웹,
   주주 인증 채팅을 구현하지 않았다. 합성 MAE 차이는 실증 모델 개선의 증거가 아니다.
