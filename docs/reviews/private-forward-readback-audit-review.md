# 비공개 사전 예측 원격 재검증 리뷰

작성일: 2026-10-23. 직전에는 비공개 버킷에 쓴 객체의 크기와 해시를 기록하는 코드가 있었지만, 전체 원본과 예측 index를 한 번에 다시 읽고 **S3 서버의 실제 기록 시각**으로 사전 예측 여부를 검사하는 독립 명령은 없었다. 이번에는 `audit_capture`를 저장 직후에 실행하고 `scripts/audit_private_capture.py --index-key <보관 결과의 index_key>`로 나중에 읽기 전용 감사를 반복할 수 있게 했다.

## 범위와 검증

- 저장된 index와 index가 가리키는 모든 가격 CSV·원본 봉투·manifest를 S3 `HEAD`와 `GET`으로 다시 읽는다. 바이트 길이·SHA-256·객체 메타데이터와 index의 해시 목록을 대조한다. manifest 해시는 저장 키에 기록된 값과도 비교한다.
- S3의 `LastModified`로 원본 객체가 예측 시각보다 뒤에 쓰이지 않았는지, 예측 index가 실제 첫 정규장 개장 전에 쓰였는지 검사한다. 기록 시각이 없거나 UTC가 아니면 성공으로 처리하지 않는다. S3의 초 단위 시각 정밀도를 고려해 원본·index와 예측 시각의 비교에 1초 여유를 둔다.
- 두 종목 각각 5·20일 예측과 입력 CSV의 해시를 확인한다. 원본만 저장한 실행에서는 예측값과 예측 시각이 비어 있어야 한다. 감사 명령은 가격 원문과 예측값을 공개 로그로 출력하지 않는다.
- 합성 S3 통합 시험은 정상 사전 예측과 원본만 남긴 늦은 실행을 감사하고, 업로드한 원본 바이트 변조와 첫 개장 후 index 기록을 거절한다. 사전 보관 시험은 총 **5개**다. `make quality PYTHON=.venv/bin/python`에서 Ruff 위반 0건, Pyright 오류·경고 0건이었다. `make test PYTHON=.venv/bin/python`에서 전체 **173개 시험이 통과**했다.

## 실제 실행 조건과 리서치팀 시각의 판정

| 판정 항목 | 현재 근거 | 판정 |
| --- | --- | --- |
| 데이터 출처·재현성 | 합성 통합 시험에서 원본과 예측 index의 실제 S3 기록 시각·전체 바이트 해시를 검증한다. 기존 Alpaca Actions는 실제 TLT·SPY 각각 705거래일을 수집했다. | 저장 계약의 구현은 한 단계 진전했다. **실제 S3의 읽기·쓰기 실행은 0회**이므로 운영 재현성은 미검증이다. |
| 사전 예측의 시점 무결성 | 예측 시각은 다음 개장 전이어야 하고, 감사에서 S3의 index 기록 시각도 그 이전인지 확인한다. | 늦게 작성한 예측을 사전 예측으로 인정하지 않는 검사로 타당하다. 그러나 index 쓰기 완료 후에야 감사가 실행되므로, 늦은 기록은 삭제되는 대신 **실패로 표시**된다. 버킷 접근 제어와 보존 정책도 필요하다. |
| 예측의 정보 가치 | 실제 새 기간 사전 예측 0개, 성숙한 5·20일 정답 0개. 이번 작업은 모델 적합과 오차를 새 기간에 평가하지 않았다. | **성능 근거 추가 없음.** EWMA 대비 GARCH·GJR 우위, 사용자에게 보여줄 신호, 증권사 리서치 자료로서의 효용은 아직 승인할 수 없다. |
| 이번 작업의 양 | 저장 후/사후 감사 기능·별도 읽기 명령·변조 및 시각 시험·운영 조건을 추가했다. | **독립 커밋으로는 합당**하지만 직전 약속한 첫 실제 기록은 달성하지 못했다. 이를 실데이터 분석 완료로 세지 않는다. |

초안 PR #7은 `feat/treasury-rate-collection`에 열려 있고 새 보관 workflow는 기본 브랜치 `main`에 없다. 따라서 `workflow_dispatch`를 통한 첫 실행은 아직 불가능하다. 현재 작업 환경에는 비공개 버킷 설정과 Alpaca 키가 없으며, 연결된 GitHub 도구로 저장소 변수·비밀값의 등록 여부도 읽을 수 없다. **실제 비공개 저장 빈티지 0개, 새 사전 예측 0개, 신규 성능 판정 `HOLD`**로 기록한다. 기본 브랜치 반영과 접근 설정 후 첫 실행의 `index_key`를 받아 읽기 전용 명령으로 재검증해야 한다. 2027년 이후 표본은 거래일 달력 확장과 검증 전에는 예측하지 않는다.
