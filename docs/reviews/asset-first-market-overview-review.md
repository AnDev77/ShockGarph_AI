# 단일 종목 우선 화면과 기간 총변동률 리뷰

검토일: 2026-10-21. 사용자는 SPY·TLT 각각을 먼저 판단하고 두 종목을 함께
보는 값은 기간 총변동률이면 충분하다고 범위를 정정했다. 이에 따라 이전의
상관관계·동반 하락·매일 재조정된 공동 위험을 **첫 제품 계산과 화면에서
제외**했다. 기존 합성 포트폴리오 위험 연구 코드는 별도 연구 이력으로 남는다.

## 코드와 결과 계약

- `asset_market.py`는 SPY 또는 TLT **한 종목의** 수정종가만 받아 최근
  5·20거래일 가격 변화율, 선택한 기간의 변화율·최대 하락 폭, 최근 20개
  수익률의 관측 변동성과 그 변동성이 입력 이력의 20개 수익률 이동 구간에서
  차지하는 위치를 계산한다. 가격 날짜 중복과 비정상 가격, 표본 부족은 거부한다.
- `analyze_asset_history.py`는 비공개 한 종목 CSV를 받아 해시·출처·계산값을
  JSON으로 저장한다. 실제 전체 거래소 세션, 공급원의 이용권과 과거 수정가격
  버전은 검증되지 않아 `public_display_allowed=false`다.
- `weighted_total_change`는 두 종목이 같은 시작일·종료일의 기간 변화율을
  가질 때만 `w × R₁ + (1−w) × R₂`를 계산한다. **최초 비중으로 보유하고
  중간에 재조정하지 않은** 경우의 과거 총변동률이며, 미래 예상 수익률이나
  포트폴리오 변동성으로 표시하지 않는다. 두 종목의 조정 기준·통화·사용
  권리는 실제 자료를 연결할 때 별도로 확인한다.

## 검증 결과

단일 종목 시험은 해당 종목의 마지막 5개 수익률을 복리로 합친 가격 변화율과
계산 결과가 일치하는지 확인한다. 기간별 변동성 창 개수와 비공개·비예측
플래그도 검사한다. 두 종목 합산 시험은 최초 비중의 **기간 변화율 가중합**을
대조하고, 시작·종료 날짜가 다르면 계산을 거부하는지 확인한다. 짧은 종목
이력은 점수를 내지 않는 시험으로 검사한다. 전체 `make test`에서 **138개
시험이 통과**했다. `make quality`의 Ruff 검사와 Pyright 정적 검사는
모두 오류 0건이었다. 이 검증은 계산식과 입력 거부 경로를 확인하지만,
SPY 실자료의 품질이나 사용자 재방문 가치를 검증하지 않는다.

## 다음 화면과 채팅

첫 화면은 `SPY`, `TLT`를 선택하면 해당 종목의 관측 변화·변동성 위치·
하락 폭, 날짜·출처·자료 상태를 보여준다. 비중 합산은 두 종목 자료의
시작·종료일이 같은 경우에만 선택 기능으로 노출한다. 각 종목 카드에서
해당 공개 채팅방으로 진입하며 로그인 쓰기·신고·차단을 먼저 구현한다.
실제 SPY 가격 파일, 외부 표시 권리, 웹 화면과 채팅은 아직 없다.
