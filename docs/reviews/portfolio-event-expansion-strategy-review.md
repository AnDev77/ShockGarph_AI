## 근거와 범위

연준·CME·EIA·원유 충격 연구·XLE 공식 자료와 Kalshi 공개 약관을 확인했다.
EIA·FOMC API 수집, 새 실제 학습·예측 성능 시험, 공급자 허가 확인, 클라우드 배포는 수행하지 않았다.
신규 일정과 결과 카드는 목표이며 구현 완료나 향후 예측 성능을 의미하지 않는다.
