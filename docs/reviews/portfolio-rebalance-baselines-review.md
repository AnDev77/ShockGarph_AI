# 포트폴리오 조정 기준 정책 계산기 리뷰

기준일: 2026-11-02. 이 기록은 합성 자료 기반 소프트웨어 검증이며 실제 가격·비공개 성능 수치를 담지 않는다.

## 시작 근거

- main `a993373e`, 열린 초안 PR #14 `4ddad2a3`을 확인했다. #14의 현재 방향 문서가 다음 핵심 기능으로 보유 유지·정기·허용 범위 정책 계산기를 지정한다. 기존 `portfolio.py`의 공동 수익률은 매일 같은 비중으로 복귀하는 가정이어서 보유 유지와 다르다.
- 2026-11-02 확인 당시 main의 R2 예약 워크플로는 2026-10-30 실행까지 완료 성공이었다. 예약 설정과 실제 실행을 구별한다. 최신 실행의 사전 검사·감사·비공개 채점 단계는 성공으로 표시되지만 새 고유 예측 거래일이나 새로운 정답·모델 우위는 그 표시만으로 확인되지 않는다.

## 중간 구현·오류

- `packages/risk_engine/shockgraph_risk/rebalance.py`에 보유 유지, 지정된 날짜의 정기 조정, 그 날짜에 목표 비중 이탈이 문턱을 초과한 경우의 조정을 구현했다. 같은 공통 USD 수정종가, 이용 가능 시각, 목표 비중, 양의 납입과 거래 비용을 입력한다. 종가를 본 뒤 결정한 거래는 **다음** 종가 간 수익 구간부터 영향을 준다.
- 목표 비중으로 조정한 뒤 비용을 별도 차감하면 음의 현금이 생기는 오류를 피하기 위해, 비용과 거래 후 목표액을 함께 수렴시킨다. 거래액은 자산 매수·매도 절대액의 합이며 비용은 그 거래액에 적용한다.
- 최초 로컬 시험은 의존성 미설치로 실행되지 않았다. 개발 의존성 설치 후 전체 시험을 수행했고, 첫 Ruff 검사에서 import 형식·줄 길이 두 건을 발견해 수정했다.

## 완료 근거와 작업량

- 새 기능 모듈 1개, 단위 시험 파일 1개, 안전한 리뷰 1개. 시험은 정책 간 다음 날 차이, 임계값, 비용 차감, 납입 현금 대기, 반복 실행 동일성, 늦은 가격·누락 날짜·잘못된 입력의 실패를 확인한다.
- 로컬 `make test`: 188개 통과. `make quality`, wheel 빌드·포함 파일, 원격 PR 게이트는 각각 최종 실행 결과를 확인해 PR에 별도 기록한다.
- 인출·세금·스프레드·환전·정수 주식·자동 주문은 이 계산기의 범위가 아니다. 실제 가격의 사용권·배당 조정·공통 거래일, 신규 거래일의 5/20일 정답, 실제 거래 비용, PB 사용성은 확인 전이다.
