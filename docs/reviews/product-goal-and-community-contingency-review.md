# 제품 목표와 성과별 커뮤니티 경로 리뷰

검토일: 2026-10-20

## 무엇을 결정했는가

첫 연구의 정답은 TLT의 다음 5·20거래일 실현 변동성이다. 발표 전 Kalshi 거시
확률을 B의 전통 정보에 더한 C가 실제로 개선하는지를 공통 날짜에서 검증하고,
자료가 충분하면 같은 입력의 머신러닝 D도 비교한다. 과거 가격만 쓴 Ridge의
실패나 CPI 계약 적중률은 확률 C의 성능 결과가 아니다.

성과가 나쁘다는 말은 **실제 독립 시험에서 개선이 없거나 불확실한 경우**에만
사용한다. 권리·과거 시점별 자료·독립 표본을 확보하지 못한 현재 상태는
`HOLD`이며 예측 실패와 구분한다. 승인된 경우에만 위험 수치를 제공한다.
승인되지 않으면 거시 발표의 당시 기대·최초 발표 결과·기간을 명시한 시장
관측과 출처를 정리하는 이벤트 페이지의 사용성을 별도 시험한다.

주주 인증은 이미 유사 기능이 있어 단독 차별점이 아니다. 근거 페이지에서
발표 전에 남긴 가설을 사후에 복기하는 비동기 의견을 작게 시험하며, 그 자체의
반복 사용과 관리 비용을 확인한다. 주주 인증 실시간 종목방은 허가된 보유 확인
공급원과 신원·방 권한·신고 운영이 갖춰진 **후속 선택지**다. 예측의 실패가
채팅의 사용자 수요를 입증하지는 않는다.

## 검증 결과와 한계

`make quality PYTHON=.venv/bin/python`에서 Ruff 정적 규칙 검사가 통과했고
Pyright가 오류·경고를 각각 0개 보고했다. `make test PYTHON=.venv/bin/python`의
계약·단위·통합 테스트 113개가 통과해 기존 가격 시점 선택·일별 위험 계산·
CPI 연구 경로가 그대로 실행됨을 확인했다. 수정한 Markdown 9개의 상대 링크
71개를 확인했으며 대상 파일이 없는 링크는 없었다. `git diff --check`에서도
공백·패치 형식 문제는 없었다. 이번 작업은 제품 선택 기준과 화면 설계의
문서 정정이므로 모델의 실자료 성능, 설명 도구의 실제 재방문율, 게시판의
운영 가능성을 검증한 결과는 아니다.
