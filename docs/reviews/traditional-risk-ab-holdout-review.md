# 전통 지표 A/B의 시점별 홀드아웃 비교 리뷰

개정일: 2026-10-20. TLT 가격 기준선 A와 전통 지표 모델 B를 **같은 날짜·정답**에서
비교하는 비공개 연구 경로를 구현했다. 합성 입력으로 계산의 누수 방지를 검증한
것이며 실제 TLT 예측 성능이나 공개 상품 승인이 아니다.

## 바뀐 코드 구조

- `shockgraph_risk.macro_panel`은 `include_probability_research=False`일 때
  확률 계약·발표 일정 없이 가격 A와 전통 지표 B의 공통 행을 만든다. 확률이 없는
  이유를 B의 결측으로 세지 않는다.
- `shockgraph_risk.traditional_model`은 보관 가격 파일에서 A를 재계산해 입력
  패널의 계보를 확인한다. **학습 정답은 홀드아웃 시작 시각까지 캡처된 마지막
  완전 가격 파일에서**, 시험 정답은 평가 시점까지 캡처된 별도 파일에서 만든다.
  훈련 정답이 분할 경계를 넘거나 그 시각에 이용 가능하지 않으면 제거한다.
- B는 당시 가격의 최근 변동성·EWMA 로그와 선택된 전통 지표 값을 훈련 구간
  평균·표준편차로 표준화한 다음, 절편을 제외하고 패널티 10의 Ridge를 한 번
  학습한다. 같은 B 날짜의 최근 변동성·EWMA A와 MAE·QLIKE 및 길이 `h`의
  쌍별 블록 재표집 구간을 비교한다. 기본 훈련 100행 또는 비중첩 시험 구간
  2개 미만이면 모든 점수를 보류한다. 계수·입력 해시·가격 정답 스냅샷 해시·
  실제 공통 평가 날짜 수를 남긴다.
- `scripts/evaluate_traditional_holdout.py`는 기존 가격 manifest와 지표 CSV를
  받는다. 지표에는 `name,source,observed_at,available_at,value`가 필요하고,
  비공개 출력은 해당 CSV 바이트의 SHA-256을 기록한다. `make risk-compare`가
  이 경로를 호출한다. 기존 가격 홀드아웃 CLI는 공통 입력 로더로 리팩터링했고
  출력 계약은 유지했다.

## 검증 결과

합성 가격 75개 세션과 `DGS10` 형태의 합성 지표에서 5일 B 모델의 학습 행은
31개였다. 시험 정답이 확정된 A의 30개 예측 중 지표가 빠진 하루를 제외해
A/B에 공통인 예측 29개를 평가했고, 보수적 비중첩 구간은 5개였다. 이 **합성
예제**의 MAE는 최근 변동성 0.003648, EWMA 0.004775, B 0.001071이며,
B−EWMA의 짝지은 블록 구간은 약 −0.004288부터 −0.003118까지다. 생성 규칙이
있는 수치이므로 실제 금리의 추가 예측력이나 통계적 우위를 의미하지 않는다.

시험 종료 뒤 가격 한 행의 수정본을 입력해도 학습 계수·학습 입력 해시·
학습 정답 스냅샷 해시는 그대로이고 시험 MAE와 평가 해시는 변하는지 확인했다.
예측 시각보다 늦은 지표 관측은 입력으로 거부하며, 학습 100행 미만이면 점수와
계수를 모두 숨기는 시험도 통과했다. 비공개 CLI는 가격 파일과 지표 CSV의
체크섬을 남기고, 너무 짧은 홀드아웃에서는 점수를 보류하며, 이미 있는 출력
파일을 덮어쓰지 않는다. 전체 `make test PYTHON=.venv/bin/python`의 계약·단위·
통합 시험 126개가 통과했고, `make quality PYTHON=.venv/bin/python`의 Ruff
및 Pyright는 오류 0건·경고 0건이다. 변경 문서의 상대경로 링크 60개에서
누락은 0건이었고 Git 패치 공백 오류도 0건이다.

## 실자료 판정 조건

[FRED DGS10](https://fred.stlouisfed.org/series/DGS10)는 일별 미국 국채
10년 금리이고 [VIXCLS](https://fred.stlouisfed.org/series/VIXCLS)는 CBOE의
일별 VIX다. [FRED의 과거 관측 API](https://fred.stlouisfed.org/docs/api/fred/series_observations.html)는
날짜별 빈티지를 조회할 수 있지만, 그 날짜의 **정확한 일중 게시 시각**과
사용자의 실제 과거 파일 수신을 입증하지 않는다. VIX는 원 공급원의 저작권·
재표시 조건이 별도로 표기돼 있다. 원본 게시 시각·실제 수신 기록·권리를 확인한
금리 파일과 여러 해의 가격 빈티지, 실제 세션 및 새 독립 시험 기간이 필요하다.
현재 가격 manifest의 달력은 2026년 예정 일정뿐이며 과거에 본 2024년 이후
수정종가 한 벌을 새 모델의 독립 최종 시험으로 재사용하지 않는다. 따라서
`public_performance_allowed=false`이며 실제 A/B 성과 판정은 `HOLD`다.

## 사용자 점검표

- [ ] 전통 지표 CSV의 `available_at`을 관측일이나 파일 생성 시각으로 임의 역산하지 않는다.
- [ ] 가격과 지표의 연구·공개·파생 결과 이용권 및 시점별 원본 증거를 확인한다.
- [ ] A/B는 동일한 평가 날짜·정답·자산으로 비교하고 결측 수를 공개한다.
- [ ] 새 독립 기간을 정하기 전에는 기존 탐색 결과로 B의 설정을 고르거나 공개 성능을 주장하지 않는다.
- [ ] Kalshi의 계약 확률은 이 모델에 입력하지 않고 사건 당시 기대의 별도 자료로 다룬다.
