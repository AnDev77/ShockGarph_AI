# 무료 한도 우선 비공개 R2 가격 빈티지 전환 리뷰

작성일: 2026-10-23. 사용자는 AWS의 기간 한정 무료 플랜 이후 유료 전환을 원하지 않았다. 기존 비공개 원본·사전 예측 저장 계약은 유지하고, 실행 공급원을 Cloudflare R2의 S3 호환 API로 바꿨다. **실제 R2 버킷·키는 아직 연결되지 않았다.** 이 리뷰의 합성 시험은 실제 보관이나 연구 성능 검증을 뜻하지 않는다.

## 구현과 무료 한도 방어

- R2 계정 ID, 전용 버킷, 전용 버킷에만 적용되는 Object Read & Write 키를 GitHub 변수 `SHOCKGRAPH_R2_ACCOUNT_ID`, `SHOCKGRAPH_R2_BUCKET`와 비밀값 `SHOCKGRAPH_R2_ACCESS_KEY_ID`, `SHOCKGRAPH_R2_SECRET_ACCESS_KEY`에서 주입한다. `region_name=auto`와 계정별 S3 엔드포인트를 사용한다. 계정 ID·키는 저장소에 넣거나 공개 로그에 출력하지 않는다.
- 원본 객체의 조건부 `If-None-Match: *`, 원본·index의 해시·재시도·기록 시각 감사와 다음 개장 전 예측 제한은 유지한다. R2에서 지원하지 않는 AWS `GetPublicAccessBlock` 호출과 `ServerSideEncryption=AES256` 요청을 제거했다. R2는 저장 데이터와 메타데이터를 자동 암호화한다. [R2 S3 API 지원 범위](https://developers.cloudflare.com/r2/api/s3/api/), [암호화 문서](https://developers.cloudflare.com/r2/reference/data-security/).
- 원본의 전체 바이트를 확인한 뒤 첫 쓰기 **전**에 현재 버킷 객체 크기를 전부 나열한다. 이번 실행의 예상 총량이 4,000,000바이트를 넘거나 현재 버킷 사용량과 합해 8,000,000,000바이트를 넘으면 원격 쓰기를 시작하지 않는다. 사전 예측 index를 위해 64,000바이트를 예약한다. 이 한도는 R2 Standard 저장소의 월 10GB 무료 구간보다 여유 있게 작다. [R2 요금](https://developers.cloudflare.com/r2/pricing/).
- workflow는 계속 **수동 실행**이다. 전용 버킷을 비공개로 만들고 `r2.dev` 공개 URL과 사용자 지정 공개 도메인을 연결하지 않아야 한다. R2 S3 API에는 AWS의 Public Access Block 확인 기능이 없어 공개 여부를 코드가 독립 확인하지 못한다. [비공개 기본값](https://developers.cloudflare.com/r2/buckets/create-buckets/), [공개 설정](https://developers.cloudflare.com/r2/buckets/public-buckets/).

이 방어는 **0원 보장이 아니다.** R2는 6개월 만료 대신 월 무료 한도를 제공하지만 초과하면 사용량에 따라 과금할 수 있다. 위 코드는 이 전용 버킷의 객체 크기만 확인하며 계정의 다른 R2 버킷, 요청 횟수, 다른 사용자 쓰기와 결제 설정을 통제하지 못한다. 계정 개설·R2 구독 과정에서 결제 수단을 요구할 수 있으므로 실제 등록 화면에서 확인해야 한다. 결제 수단 등록을 피하거나 절대 과금 불가를 요구한다면 R2 계정 생성 전에 이 경로를 중단하고 무료 로컬 수집·백업 경로로 다시 설계해야 한다.

## 검증 및 증권사 리서치팀 판정

합성 보관 통합 시험에서 R2의 인자 형태로 조건부 쓰기를 검사하고, 정상 원본·예측 index를 재검증한다. 변조 파일, 예측보다 늦은 원본, 개장 후 index를 거절하는 기존 계약을 유지한다. 새 시험은 버킷 사용량이 한도 직전이면 **원본 쓰기 0건**으로 종료하는지, 실행당 4MB 상한을 검사하는지, R2 endpoint·`auto` 리전·전용 키가 정확히 연결되는지를 확인한다. `make quality PYTHON=.venv/bin/python`에서 Ruff 위반 0건과 Pyright 오류·경고 0건이었다. `make test PYTHON=.venv/bin/python`에서 **전체 175개 시험이 통과**했다. 실제 R2 API 요청 시험은 실행하지 못했다.

| 기준 | 이번 결과 | 리서치팀 관점 |
| --- | --- | --- |
| 작업 진행량 | AWS 전용 요청을 R2 호환 요청으로 교체하고 비공개 수동 작업·예산 검사·연결 시험을 추가했다. | 독립 기능 커밋으로 충분하다. 그러나 실제 원격 빈티지가 없으므로 실데이터 성과로 집계하지 않는다. |
| 데이터 계보 | 원본·정규화 가격·예측 index의 해시와 S3 서버 기록 시각 감사 경로를 보존했다. | 사전 예측 증거를 남기는 방법으로 타당하다. 실제 R2 쓰기와 공개 설정은 아직 미검증이다. |
| 모델 성과 | 이번에는 EWMA·GARCH·GJR의 새 실가격 정답과 오차를 계산하지 않았다. | **신규 독립 예측 0개, 성숙 점수 0개.** 성능 및 고객 효용 판정은 `HOLD`. |
| 비용 위험 | 4MB/실행과 8GB/전용 버킷 사전 차단, 수동 실행만 허용한다. | 저장소 코드 차원에서 비용 노출을 줄였지만 결제 계정 전체의 상한이나 요청 과금까지 차단하지 못한다. |

- [x] 예산 초과일 때 원본 업로드 전 중단한다.

- [ ] 기본 브랜치에 workflow를 반영하고 GitHub 변수·비밀값을 등록한다.
