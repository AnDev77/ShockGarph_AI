# QQQ 비공개 원본의 시간순 재감사 리뷰

2026-10-30. 초안 PR #12의 비공개 QQQ 원본 보관을 이어서 검증한다. 기존 코드는 R2 객체의 저장 바이트와 SHA-256, 개별 객체의 기록 시각을 재확인했지만, 보관된 일봉 CSV의 거래일 순서와 각 행의 관측·이용 가능 시각을 재검사하지 않았다. 이번 작업은 **저장 후 읽기 감사의 데이터 품질** 한 건이다. 공개 화면의 가격 제공이나 사전 예측 모델을 추가하지 않는다.

## 시작·중간·완료 근거와 작업량

| 단계 | 관측과 조치 | 판정 |
| --- | --- | --- |
| 시작 | main은 2026-10-26 PR #7 병합 커밋이며 QQQ 보관 초안 PR #12가 열린 상태. 로컬 작업 트리의 기존 진행 문서 수정과 별도로 원격 PR HEAD에서 작업 | 다른 실행의 수정·비공개 문서를 덮어쓰지 않음 |
| 실패 시험 | 원본 CSV와 index 양쪽의 해시를 일관되게 바꾼 거래일 역순·늦은 이용 가능 시각 사례를 기존 감사가 통과시킴 | SHA 일치만으로 시간순 품질을 주장할 수 없음 |
| 구현 | R2 재조회 CSV에서 단일 QQQ manifest, CSV 형식, 거래일 중복·누락, Nasdaq 정규장 종가, 관측·수집·이용 가능 UTC 순서, 양수·유한 가격과 원본 manifest 해시를 검사 | 실패 시 비공개 날짜·값을 출력하지 않는 일반 오류만 반환 |
| 로컬 완료 | 대상 통합 시험 7개, 전체 192개 통과. wheel 여섯 패키지 내용 확인. Ruff·Pyright 결과는 최종 게이트에 함께 기록 | 실 R2 재조회는 원격 결과 확인 전까지 미확인 |

변경 작업량은 보관 감사 코드 한 파일, 시간 오류 4종을 포함한 통합 시험 한 파일, 이 기능 리뷰와 로컬 진행·장애·검증표다. 시험용 CSV는 합성 자료이며 실제 비공개 원본이나 가격·오차를 PR에 포함하지 않는다. 같은 해시를 가진 손상된 원본을 찾는 시험과, index 해시까지 함께 바꾼 논리 오류를 찾는 시험을 구별한다. R2 쓰기 시점의 원본 검사는 유지한다.

## 연구·제품 경계

[연준 FEDS 연구(2025년 발행, 2026년 9월 개정)](https://www.federalreserve.gov/econres/feds/linear-and-nonlinear-econometric-models-against-machine-learning-models.htm)은 S&P 500과 40개 종목의 **고빈도 실현 변동성**을 기간별로 비교한다. 이번 QQQ CSV는 **일봉 종가**이며 목표 변수·입력 빈도가 다르다. 향후 TLT/QQQ/SPY의 5일과 20일 위험을 비교하려면 같은 날짜의 사전 예측, 이후 처음 얻은 성숙 정답, 당시 이용 가능한 지표, 기간별 독립 표본을 먼저 확보하고 EWMA 같은 공통 기준선을 맞춰야 한다. 데이터 품질 검사는 그 조건의 일부이지 예측력 증거가 아니다.

[BlackRock의 2026년 기관 자본시장 가정](https://www.blackrock.com/institutions/en-global/institutional-insights/thought-leadership/capital-market-assumptions)은 장기 거시 시나리오의 불확실성을 다루고, [위험 대시보드](https://www.blackrock.com/corporate/insights/blackrock-investment-institute/interactive-charts/geopolitical-risk-dashboard)는 지정학 사건과 민감 자산의 충격을 설명한다. 현재 QQQ 저장 자료에 이 방법론의 결과를 옮겨 적을 수 없다. 발표 시각·기대치·자산의 공통 관측일·사용 권리가 갖춰져야 별도 사건 분석을 할 수 있다.

소프트웨어 검사 통과와 실제 R2 운영 읽기, 모델 성과, 재방문 수요는 네 개의 별도 판정이다. 첫 5일 미래 정답이 독립적으로 성숙했다는 근거가 없으므로 **실전 성능과 제품 수요는 HOLD**다. 기존 과거 비공개 성과 문서의 전체 업로드를 다시 시도하지 않는다. 이 PR은 초안으로 유지하고 병합·배포·공개 성능 발표·매매 실행을 하지 않는다.
