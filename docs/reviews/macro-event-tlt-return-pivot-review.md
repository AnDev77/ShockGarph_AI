작성일: 2026-10-20. 첫 검증 목표의 독립변수와 종속변수를 바로잡았다.
기존 가격 기반 변동성 모델의 결과가 사용자가 의도한 TLT 수익률 예측으로
읽힐 위험이 있어 제품 명세·흐름·모델 설명을 수정했다.

## 정확성 판단

뉴욕 연준의 거시 발표 반응 연구와 미 연준의 FOMC 행동·경로 충격 연구는
기대 대비 뉴스와 반응 시점이 중요하다는 설계 근거다. Kalshi에 관한
2026년 연준 연구는 거시 기대의 측정에 관한 연구이므로 TLT 수익률
예측 성능을 대신하지 않는다. 발표 전에는 실제 CPI·사후 surprise를
입력할 수 없고, 발표 후 모델은 발표 전 정답 가격 구간을 재사용할 수
없다. 전날 종가에서 발표일 종가까지의 TLT 수익률에는 동시 뉴스와
FOMC 이전의 당일 움직임도 섞이므로 발표의 인과 효과로 부르지 않는다.

현재 CPI `T0.3`의 유효 확률 29개와 과거비율 비교 24개는 사건별
ETF 수익률 모델을 입증하기에 충분하다고 판단하지 않는다. TLT 수정가격
이력 한 벌에서 관찰한 5·20일 변동성 MAE는 별도 위험 연구의 숫자다.
거시 이벤트와 TLT 가격을 실제 시점별로 결합한 공통 표본 수가 나오기
전까지 수익률 성능과 공개 화면은 `HOLD`로 둔다.

## 검증 결과

이번 변경은 문서와 목표 정의만 바꿨고 실행 코드나 기존 계산 결과는
수정하지 않았다. `make test`는 사건 자료 계약과 TLT 가격 처리·미래
정답 누수 방지 등 전체 113개 검사를 실행해 모두 통과했다. `make quality`의
Ruff는 모든 파일에서 검사 오류가 없었고 Pyright는 오류와 경고를 각각
0개 보고했다. 자동 검사가 새 수익률 모델의 성능을 증명하는 것은 아니며,
새 사건 입력 계약의 구현과 독립 시험은 다음 작업이다.

## 사용자 점검표

- [ ] 첫 종속변수가 부호 있는 TLT 수익률인지 확인한다.
- [ ] CPI 실제값을 발표 전 모델에 넣지 않는지 확인한다.
- [ ] 가격 기반 변동성 모델의 오차를 수익률 예측 성과로 소개하지 않는지 확인한다.
- [ ] TLT 사건 수익률 학습·검증·서비스가 아직 구현되지 않았다고 표시되는지 확인한다.
