# 데이터 확대 전략 수정 리뷰

작성일: 2026-10-01 (한국 시각)

## 변경 범위

사용자 요청에 따라 기획만 수정했다. 새 개발 일차를 진행하거나 수집·모델 코드를
변경하지 않았다. `docs/paper/data-expansion-strategy.md`에 재수집 우선 원칙,
F0~F4 민감도 후보, 비교 표본 통제, DNN 후속 실험과 논문 주석을 기록했다.
분석 계획의 오래된 공통 27건·시험 7건 표기를 실제 발표시각 검증 후 24건·4건으로 보완했다.

## 해석 보완

- 필터 성능 변화는 편향이나 필터 필수성의 증명이 아니다.
- 시험 입력에도 윈도우를 사용할 수 있으며 평가 단위·시각·라벨 경계가 핵심이다.
- 기존 24건은 이미 관찰한 자료이므로 새 기준의 확인적 시험 자료로 취급하지 않는다.
- DNN은 후속 계획이고 현재 초점은 재수집·필터 감사·Kalshi 추가 효과 검증이다.

## 사용자 점검 사항

검증: `make quality` 통과, `make test` 118개 통과(기존 Starlette 경고 1개),
`git diff --check` 통과. 필터 민감도 실험 자체는 아직 실행하지 않았다.

1. F0를 유지하고 단일 조건 변경과 결합 완화안을 모두 비교하는지 확인한다.
2. 공통 시험 사건 비교와 전체 가용 사건 결과가 별도 표인지 확인한다.
3. 후보 선택 이후의 최종 시험 기간과 원본·정책 해시를 고정한다.
4. 실행 결과와 전략을 구분한다. 이번 작업으로 표본이나 성능 수치가 바뀌지 않았다.
