# 자산 예측 프로젝트의 유의미성 재평가

검토일: 2026-10-06. 기능 개발을 재개하기 전에 기존 실제 결과와 현재 구현을 점검했다.

## 판정

**예측 상품의 확장 개발은 보류하고, 핵심 가설의 검증은 조건부로 계속한다.**
현재 자료로 Kalshi를 추가하면 사용자 자산 예측이 더 좋아진다고 주장할 수 없다.
반대로 이 가설이 틀렸다고 확정할 근거도 부족하다. 연구 질문은 타당하지만,
현재 결과는 탐색 단계이며 상품성·논문 성과·공모전 경쟁력을 입증하지 않는다.

추가 UI, DNN, 이벤트 확장보다 아래의 데이터·비교 설계 조건을 해결하는 것이 우선이다.
조건을 해결할 경로가 없으면 Kalshi 기반 자산 예측 개발을 멈춘다.

## 확인한 근거와 구현

- 현재 모델: `packages/event_study/shockgraph_analytics/kalshi_ablation.py`의
  `binary_empirical_shrinkage4`. 과거 CPI가 0.3%를 넘었는지에 따라 ETF 수익률을
  두 집단으로 나누고, 작은 집단을 전체 과거 분포 쪽으로 축소한다. 두 집단의 혼합 비중을
  과거 발생비율 또는 해당 발표 전 Kalshi 확률로 바꿔 비교한다. DNN은 아니다.
- 현재 실제 비교는 SPY·TLT의 발표 후 5분·30분 수익률 분포에 대한 것이다.
  장기 자산 가격, 임의 포트폴리오 비중, 포트폴리오 꼬리 위험의 예측 성능은 입증하지 않았다.
- CPI 기존 기록: `docs/paper/results/cpi-probability-recorded-2026-09-26.json`.
  문서의 소수점 네 자리 지표를 보존한 기록이며 이번에 재계산하지 않았다.
- ETF 최신 확인: GitHub Actions 실행 `36874806023`, 집계 산출물
  `alpaca-cpi-validation-sip`의 `kalshi_filter_sensitivity.json`.
  아래 수치는 기존 산출물을 읽은 값이며 새로운 학습·성능 시험 결과가 아니다.
- 해당 산출물에는 원시 호가, ETF 개별 가격, 사건별 예측·수익률이 없다.
  현재 로컬 저장소에서도 새 실제 비교를 재현할 원본이나 실제 컨센서스 빈티지는 확인하지 못했다.
  원본이 사용자 로컬 또는 별도 저장소에 있는지는 이번 점검으로 확정할 수 없다.

## 결과의 의미

### CPI 확률 자체

24개 비교 사건에서 `CPI MoM > 0.3%`의 Brier 점수는 Kalshi 0.1005,
발표 이전 사건의 누적 발생비율 0.2342다. 기록된 평균 차이는 -0.1337,
사건 대응 재표집 95% 구간은 [-0.1876, -0.0857]이다. 낮을수록 좋다.

이 비교에서는 개선 근거가 있다. 다만 비교 상대가 단순 과거 빈도이므로,
당시 컨센서스나 강한 인플레이션 예측 모델보다 우수하다는 의미는 아니다.
전체 CPI 수치·분포의 정확도나 ETF 상승·하락 정확도로 바꿔 해석할 수도 없다.

### ETF 수익률 분포

차이는 `CRPS(Kalshi) - CRPS(과거 발생비율)`로 정의한다. 음수가 개선이다.
공통 사건 수에는 학습 사건이 포함되며 시험 사건 수와 다르다.

| 조건 | 공통 사건 | 초기 20건 학습 뒤 시험 사건 | 기존 결과 |
| --- | ---: | ---: | --- |
| F0: 15분·스프레드 0.10·양수 거래량 | 24 | 4 | 연구 집계 공개 문턱 미달. 초기 5건 학습 진단의 19건에서는 네 조합 모두 평균 악화 |
| F1: 30분으로 완화 | 30 | 10 | 두 조합 평균 개선, 두 조합 평균 악화 |
| F2: 스프레드 0.15로 완화 | 24 | 4 | F0와 동일 |
| F3: 양수 거래량 요건 해제 | 36 | 16 | 네 조합 모두 평균 개선, 모든 95% 구간에 0 포함 |
| F4: 30분·0.15·거래량 요건 해제 | 40 | 20 | 한 조합 평균 개선, 세 조합 평균 악화 |

F3의 상세 값은 다음과 같다. CRPS는 수익률 분포의 오차이며 수익률·정답률 그 자체가 아니다.

| 자산·반응 구간 | 평균 CRPS 차이 | 사건 대응 재표집 95% 구간 |
| --- | ---: | --- |
| SPY 5분 | -0.00008405 | [-0.00028467, 0.00014437] |
| SPY 30분 | -0.00009447 | [-0.00031334, 0.00016044] |
| TLT 5분 | -0.00003917 | [-0.00018894, 0.00014128] |
| TLT 30분 | -0.00000588 | [-0.00016811, 0.00018141] |

F3에는 개선 가능성이 있으나 불확실성이 크다. F3 전체 기간의 초기 5건 학습 진단에서는
네 조합 모두 평균 악화였다. 필터별로 학습 사건·시험 사건·선택 호가가 달라지고,
이미 본 결과에서 좋은 설정을 고르는 사후 선택 문제도 있다. F3를 채택했다는 사실만으로
우위를 주장해서는 안 된다. 같은 CPI의 두 자산·두 구간은 네 개의 독립 사건이 아니다.

## 핵심 검증 공백

1. **고정 임계값과 시장 충격은 다르다.** 실제 CPI 0.3%는 당시 예상이 0.2%이면
   상방 충격이고 0.4%이면 하방 충격이다. 현재 실제 ETF 비교에는 당시 컨센서스와
   거시 상황을 통제한 기준 모델이 없다. 결과가 나빠도 Kalshi의 독립적 정보 가치 자체를
   제대로 반증한 것으로 볼 수 없다.
2. **전체 분포의 반복 검증이 부족하다.** 최신 `cpi_threshold_curve.json`에는
   `KXCPI-26AUG` 한 사건의 유효 임계값 3개가 기록돼 있다. 곡선 구성·컨센서스 시나리오
   변환 코드는 있지만 여러 사건의 실제 분포를 ETF 예측에 투입한 검증 결과는 아니다.
3. **강한 비교 상대와 외부 시험이 없다.** 단순 과거 빈도와의 차이는 기존 거시정보에
   Kalshi를 추가한 효과와 다르다. 이미 관찰한 사건들은 새로운 최종 시험으로 취급하지 않는다.
4. **정확도와 사업성은 별도다.** 오차 개선이 있어도 실용적 크기, 실시간 제공 가능성,
   데이터 비용, 이용권, 사용자 지불 의사는 추가 검증 대상이다. 이번에는 확인하지 않았다.

## 데이터 이용과 실행 가능성

기존 `docs/troubleshooting/kalshi-data-use-authorization.md`와 공식 공개 약관을 확인했다.
API 접근 가능 여부와 연구·소프트웨어·서비스에 쓸 권한은 별개다. 공개 개발자 약관은
자신의 거래 지원 외 API 이용을 제한하고, 데이터 약관은 소프트웨어 개발 및
포트폴리오·위험 관리 서비스 등의 이용을 제한한다. 별도 계약이 있다면 적용 범위를
확인해야 한다. 현재 저장소에서는 프로젝트의 별도 허가 기록을 확인하지 못했다.

따라서 이번 점검에서는 새 Kalshi 수집, 기존 실제 원본을 이용한 새 학습, 연구 워크플로
실행을 하지 않았다. 이미 생성된 집계 결과와 구현만 검토했다. 공급자 허가·사용 범위는
사용자가 개발을 승인하거나 저장소 변수를 켜는 것으로 대체되지 않는다.

## 개발을 재개할 조건과 종료 기준

### 조건을 충족하면 할 한 번의 핵심 비교

1. 이용 범위가 확인된 사건별 발표 전 데이터, ETF 가격, 당시 컨센서스를 확보하고
   접근 경로·시각·원본 해시를 보존한다. 확보 가능한 사건 수와 기준선의 실행 가능성을
   먼저 확인한다. 조건을 충족하기 전 DNN·이벤트·화면 기능을 늘리지 않는다.
2. 현재 규모에서 추정 가능한 단순 정규화 모델로 기존 가격·변동성·거시 기대만 쓰는
   기준 모델과, 동일한 모델에 Kalshi 분포 정보를 추가한 모델을 비교한다.
   발표 후 actual이나 realized surprise를 발표 전 입력으로 넣지 않는다.
   실제 surprise는 과거 학습의 결과 변수 또는 사후 설명에 사용한다.
3. 주 평가 대상을 SPY 발표 후 30분 분포로 미리 고정하고 TLT·5분은 보조 결과로 둔다.
   기존 사건은 개발용으로 취급한다. 실행 전에 필터·특징량·학습 구간·모델 복잡도·시험
   구간을 확정하고, 선택은 학습 구간 안에서만 수행한다.
4. 같은 시험 사건에서 CRPS 차이, 불확실성, 상승확률의 Brier 및 보정 상태를 함께 보고한다.
   시험 10건 같은 소프트웨어 공개 문턱을 통계적 충분성으로 해석하지 않는다.
   사건 수·효과 크기·의존성에 맞는 검정력과 불확실성을 별도로 평가한다.

### 판정 후의 선택

- 반복 가능한 실질적 개선이 있고 이용권·실시간 운영 조건이 맞으면 사용자 자산 중심 MVP를 개발한다.
- 적절한 비교에서도 ETF 개선이 확인되지 않지만 CPI 기대 정보의 효용이 있으면,
  이용권이 허용하는 시장 기대 알림을 별도 상품 가설로 검토한다. 고객 수요나 수익성을
  입증한 것으로 취급하지 않는다.
- 원본·컨센서스·허가 확보 경로가 없거나 적절한 비교에서도 개선 근거가 없으면,
  Kalshi 기반 자산 예측 개발을 멈추고 기존 코드와 탐색 결과를 보존한다.
- 시험이 불확실하게 끝나도 필터를 계속 바꾸며 개발을 연장하지 않는다.
  증거 부족 상태에서는 예측 상품 출시를 보류한다.

## 연구 의의와 차별성

연준의 FEDS 연구 `Kalshi and the Rise of Macro Markets`는 Kalshi가 거시 기대를
실시간 분포로 관찰하는 데 유용하다는 연구 근거를 제공한다. 이는 연구 주제의 타당성을
뒷받침하지만 우리 ETF 모델의 성능을 보증하지 않는다. 단순히 Kalshi를 쓰는 것만으로
새로운 연구는 아니다. 기존 정보 대비 자산 반응의 추가 예측력, 품질 필터의 영향,
실패 조건을 재현 가능하게 밝히는 것이 이 프로젝트의 가능한 연구 기여다.

현재 확인된 성과는 수집·시각 정렬·누수 방지·평가 기반과 필터 민감도 진단이다.
유의미한 양의 자산 예측 성과나 공모전 입상·논문 게재 가능성까지 주장하지 않는다.

## 사용자 점검표

- 기존 비교가 단순 발생비율 기준이라는 점과 컨센서스 기준이 아직 없다는 점을 확인한다.
- F3의 평균 개선과 개선 입증을 구분한다.
- 별도 원본 데이터와 당시 컨센서스의 보유 위치·이용 범위를 확인한다.
- Kalshi 연구용·상업용 허가가 별도로 있는지 확인한다.
- 위 조건이 해결되기 전 상품 기능 확장을 보류한다.

## 변경과 검증

코드·모델·UI는 수정하지 않았다. 이 문서만 추가했고 새 실제 예측 시험은 하지 않았다.
품질 검사와 회귀 테스트 결과는 아래에 기록한다. 이 검사들은 코드의 정상 동작을 확인하며
예측 성능을 검증하는 실험이 아니다.

- `make PYTHON=.venv/bin/python quality`: Ruff 통과, Pyright 오류·경고 0개.
- `make PYTHON=.venv/bin/python test`: 기존 153개 테스트 통과.
- 기존 Starlette 사용 중단 예정 경고 1개. 이번 문서 변경과 무관하다.
- 새 실제 수집·학습·예측 성능 시험·커밋·푸시는 수행하지 않았다.
