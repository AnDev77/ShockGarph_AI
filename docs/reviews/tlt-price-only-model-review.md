# TLT 가격 이력 학습 모델 비교 리뷰

작성일: 2026-10-20. 실제 TLT의 현재 수정종가 이력 한 벌로 새 예측 모델을
시험하고, 같은 날짜의 단순 최근 변동성·EWMA보다 나은지 비공개로 비교했다.
**결과: 평균 절대오차 기준으로 5일과 20일 모두 기존 방식보다 나빴다.**
이 결과를 제품 예측으로 승인하지 않는다.

## 구현 구조와 시간 분리

| 경로 | 역할 |
|---|---|
| `packages/risk_engine/shockgraph_risk/exploratory_model.py` | 과거 1·5·20개 가격 행의 변동성을 입력으로 만드는 단순 로그 변동성 Ridge 모델을 학습한다. 절편 외 계수에 고정 패널티 10을 적용하고 학습 구간으로만 입력을 표준화한다. |
| `scripts/evaluate_exploratory_history.py` | 기존 2열 비공개 CSV에 `--compare-model`을 추가하면 같은 시작 날짜·같은 미래 결과에서 세 방식의 MAE·QLIKE를 기록한다. |
| `tests/unit/test_exploratory_model.py` | 시험 기간 이후의 가격 변경이 학습 계수를 바꾸지 않는지, 기존 두 방식과 시험 날짜가 정확히 같은지, 학습 행이 부족하면 점수를 숨기는지 검사한다. |

시험 시작일은 2024-01-02로 고정했고, 학습의 마지막 미래 정답은
2023-12-29에 끝난다. 시험 기간의 미래 가격은 학습이나 입력 표준화에 사용하지
않는다. 5일 모델은 학습 527개·시험 696개 시작일, 20일 모델은 학습
512개·시험 681개 시작일을 사용했다. 각 미래 구간이 서로 겹치므로 시험
시작일 수를 독립적인 관측 수로 간주하지 않고 5일 139개, 20일 34개의
비중첩 구간과 블록 재표집 차이를 함께 보고한다. 모델 학습 기준은 한 번만
선택했고, 2024년 이후 결과로 패널티·특징량을 다시 선택하지 않았다.

비공개 보고서의 평균 절대오차에서는 두 기간 모두 Ridge가 EWMA와 단순
최근 변동성보다 높았다. 5일은 Ridge의 QLIKE가 더 낮아 지표가 서로
다른 평가를 낸다. 20일은 MAE와 QLIKE에서 모두 기존 방식보다 나빴다.
5일의 Ridge와 EWMA의 오차 차이에 대한 블록 구간은 0보다 컸다.
이것은 **현재 이력 한 벌의 특정 시험 기간에 한정된 탐색 결과**이며,
처음에 정의한 미래 모델의 일반적인 성능을 입증하거나 다른 모델의 실패를
뜻하지 않는다. 자료 이용권과 날짜별 수정가격 버전·전체 거래소 달력은
여전히 미확인이다.

## 계산 검사와 다음 선택

미래 시험 기간의 가격만 변경한 단위 시험에서 학습 계수와 마지막 학습 정답 날짜가
같게 유지돼 뒤에 알게 된 정답이 학습에 들어가지 않음을 확인했다. 같은 입력에 대해
기존 두 방식과 후보 모델의 시험 시작일·마지막 날짜·표본 수가 일치했고 두 기준선의
MAE도 이전 계산과 일치했다. 학습 행이 100개보다 적은 시험에서는 후보 모델과
기준선의 오차 숫자를 함께 숨겼다. 전체 `make test`는 113개가 통과했고,
`make quality`의 Ruff 검사도 통과했으며 Pyright는 오류·경고를 0개 보고했다.
이는 계산 경로와 시간 분리의 시험 결과로, 미확인 공급원 시각을 보증하지 않는다.

이번에는 입력 후보가 과거 가격만이므로 브렌트유·금리·VIX의 추가 가치를 평가하지 않았다. 다음에는
학습 전용 기간과 최종 시험 기간을 다시 고정해, 새로운 변수의 게시 시각을
확인한 뒤 기존 방식과 같은 날짜의 오차가 줄어드는지 시험한다.

## 사용자 점검표

- [ ] 2023년 말까지 정답이 확정된 날짜만 학습에 들어갔는지 확인한다.
- [ ] 세 방식의 시험 시작일과 미래 결과가 동일한지 확인한다.
- [ ] 평균 오차와 QLIKE가 다를 때 한 지표만 골라 모델을 승인하지 않는다.
- [ ] 가격 수집 계약과 과거 수정가격 공개 시각이 확인되기 전까지 외부 서비스에 표시하지 않는다.
