# QQQ 비공개 원본 수집과 공식 발표 일정 출처 검토

2026-10-28. 첫 배포의 QQQ·SPY 비교 화면에 필요한 QQQ 가격을 **비공개 연구 입력**으로만 수집한다. 기존 TLT·SPY 예약 수집, 사전 예측 기록과 공식 점수 계산은 변경하지 않는다.

## 이번 변경과 작동 범위

- Alpaca SIP 일봉 수집·정규화 허용 종목에 QQQ를 추가하고 `--symbols QQQ` 또는 `make collect-qqq PRICE_END=...`로 선택한다. 기존 기본값은 TLT·SPY다.
- `raw`와 `all` 조정 버전의 원본 응답과 해시, 실제 수신 시각, 예정 거래일의 누락·중복 검사를 종전과 같은 방식으로 적용한다. 이 원본의 과거 게시 시각을 추정하지 않는다.
- 별도 Actions 분기는 이미 설정된 비밀 변수를 사용해 QQQ를 조회한다. 값과 원본을 로그·공개 아티팩트에 남기지 않는다. 첫 실행은 Actions 임시 디스크에서 끝났으며 지속 보관의 후속 구현과 실연결 감사는 [별도 리뷰](qqq-immutable-r2-archive-review.md)에서 판정한다. R2의 기존 TLT·SPY 빈티지에 QQQ를 섞지 않는다.
- 테스트는 QQQ만 두 조정 버전으로 요청하고, TLT·SPY 미요청·중복 종목 거부·비공개 표시를 검사한다. 실제 API 성공 여부는 원격 실행 결과로 따로 판정한다.

로컬 검증에서 `make quality`의 Ruff와 Pyright는 오류·경고 0건, `make test`는 **185개 통과**였다. wheel 빌드가 완료됐고 `scripts/check_wheel_contents.py`에서 필수 소스 7개를 확인했다. 처음에는 QQQ CLI 회귀 시험이 선택 인수 부재로 실패했으며 인수·허용 종목을 추가한 뒤 통과했다. 원격 Actions와 실제 키 조회 결과는 별도로 기록해야 한다.

## 공식 거시지표 발표의 출처와 시간

| 발표 | 일차 출처 | 화면에 적용할 시간 정책 |
| --- | --- | --- |
| FOMC | [연준 회의 달력](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm) 및 해당 회의 성명 | 공식 회의 예정과 발표 시각을 따로 저장한다. 성명·기자회견의 실제 게시 기록을 확인하기 전에는 결과를 예정 시각에 관측했다고 간주하지 않는다. |
| CPI·고용 | [BLS 발표 일정](https://www.bls.gov/schedule/news_release/current_year.asp) 및 개별 보도자료 | 미국 동부 현지 시각과 시간대 식별자를 보존한다. 일정 수정 시 버전을 갱신하고, 실제 발표 내용은 발표 이후에만 붙인다. |
| PCE·GDP | [BEA 발표 일정](https://www.bea.gov/news/schedule) 및 개별 보도자료 | 예정 발표와 실제 발표 원문, 수집 시각을 분리한다. 과거 값의 개정 여부를 표시한다. |

발표 전 화면에는 당시 공지된 일정과 그 시점까지 이용 가능한 자료만 쓴다. FOMC 발표와 ETF의 당일 수익률을 붙일 때 장중·장후와 미국 거래소 휴장일을 구분한다. 일봉만으로 발표 직후 수 분의 충격을 입증하거나 인과 효과를 단정하지 않는다. 실제 발표 내용 수집기와 공식 일정 API는 아직 구현하지 않았으므로 이 표는 공급원·시간 계약이다.

## 가격 권리와 공개 조건

[Alpaca의 시장 데이터 안내](https://alpaca.markets/support/can-i-redistribute-alpacas-market-data)는 API 데이터 재배포를 허용하지 않는다고 설명한다. 현재 키로 조회가 되는 사실만으로 원본 가격, 과거 반응의 수치, 가격에서 계산한 공개 지표의 게시 권리까지 확보했다고 보지 않는다. 서비스 화면에 수치형 가격·비교 결과를 게시하기 전 별도 라이선스 또는 공급자의 서면 허가를 확인한다. 공식 일정의 링크·출처를 보여주는 기능과 비공개 가격 연구는 별도 진행할 수 있다.

### 공개 화면을 위한 수집 경로 전환

공개 제품은 Alpaca 원본을 직접 제공하는 방식으로 설계하지 않는다. 비공개 실험 입력은 기존 Alpaca SIP를 유지하고, 공개 표시용 ETF 일봉은 재배포 권한을 명시적으로 계약한 **별도 공급원**의 어댑터로만 받는다. 종목·거래일·조정 방식·공급원 식별자·수집 시각을 함께 저장해 서로 다른 공급원의 수익률을 조용히 섞지 않는다.

| 후보 | 공급자 공식 안내 | 이번 판정 |
| --- | --- | --- |
| [Tiingo EOD](https://www.tiingo.com/products/end-of-day-stock-price-data) | ETF 일봉 및 원본·조정 가격을 제공하고 별도 표시 재배포 상품을 명시한다. [약관](https://app.tiingo.com/tos/)은 일반 API의 외부 배포를 금지하고 별도 승인을 요구한다. | 표시 권한 계약의 현실적인 후보. 무료·일반 키를 공개 서비스에 연결하지 않는다. |
| [Massive](https://massive.com/knowledge-base/article/how-can-i-redistribute-massives-market-data) | 개인 구독으로 사용자가 보는 차트·표를 제공할 수 없고 상업적 라이선스가 필요하다. 파생 신호의 권한도 사례별 검토라고 밝힌다. | 비교 견적 후보. 결과 수치까지 포함한 사용 사례를 계약에서 확인한다. |
| [Alpaca](https://alpaca.markets/support/redistribute-alpaca-api) | API 원본 재배포를 허용하지 않는다고 명시한다. | 기존 키는 비공개 연구에 한정한다. |

FRED도 [원천 저작권과 API 이용 조건](https://fred.stlouisfed.org/legal/terms/)이 자료별로 다르고 ML 학습 관련 제한이 있으므로 ETF 가격과 거시지표를 '무료 공개·학습 가능'이라고 일괄 가정하지 않는다. CPI·고용·PCE 등은 BLS·BEA의 원문을 우선 검토한다. 별도 유료 계약을 체결하기 전에는 화면에서 공식 발표 일정과 기관 원문 링크를 제공하고, 수치형 QQQ·SPY 과거 반응은 비공개로 유지한다.

## 판정과 후속 분기

- 소프트웨어: 선택적 QQQ 요청, 원본·수정본 보존, 거래일 검사는 로컬 모의 응답 시험으로 확인한다. 실제 API 연결은 Actions 결과가 성공할 때만 성공이라고 쓴다.
- 데이터: 초기 Actions 수집은 임시 보관이었다. 후속 변경의 QQQ 전용 R2 불변 보관과 저장 후 재조회 감사 결과는 [기능 리뷰](qqq-immutable-r2-archive-review.md)에서 별도로 판정한다.
- 연구: QQQ·SPY 공통 날짜·발표 전 이용 가능 시각·독립적인 미래 정답이 아직 없으므로 예측 성능 **HOLD**. 테스트 통과가 유용성 또는 사용자 수요의 증거는 아니다.
- 제품 분기: 첫 공개 화면에 수치형 비교가 필요하면 게시 권한 있는 공급원/계약을 먼저 확정한다. 그 전에는 공식 일정·출처·방법 설명 위주로 제공한다.

## 작업량·장애 대응 기록

초기 변경은 가격 수집기·가져오기·명령행·Makefile·별도 Actions 분기·통합 시험의 여섯 경로와 이 리뷰 한 건이다. QQQ 요청이 403이면 키 존재 여부만 확인하고 과거 SIP 범위·계정 권한을 구분하며 원문 응답과 비밀값은 로그에 남기지 않는다. 예정 거래일이 빠지거나 조정 버전이 불일치하면 수집을 실패 처리하고 기존 TLT·SPY 보관 경로는 손대지 않는다. 첫 Actions 성공만으로 원본 지속 보관이나 공개 권리 검증으로 승격하지 않았다.
