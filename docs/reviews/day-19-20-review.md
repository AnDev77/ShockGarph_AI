# 19~20일차 TLT 로컬 가격 입력·거래일 품질 게이트 리뷰

작성일: 2026-10-19. 허가된 실가격 파일이 제공되지 않아 실제 TLT 성능을 계산하지
않았다. 기존 합성 기준선에 연결할 수 있는 비공개 입력 경로와 거래일 품질 검사를
이번 이틀의 범위로 구현했다.

## 변경 구조

| 경로 | 변경 |
|---|---|
| `market_calendar.py` | Nasdaq의 공식 2026년 미국 주식시장 예정 휴장·조기 폐장 스냅샷을 동부시간에서 UTC 종가로 변환 |
| `daily_price_import.py` | TLT CSV 원본 바이트의 불변 보존·해시 계보, 행별 `available_at`과 달력 비교, 누락·중복·늦은 공개 품질 보고 |
| `scripts/import_daily_prices.py` | 로컬 전용 CSV 검사 명령, `data/raw/`에 보존하며 품질 문제가 있으면 종료 코드 2 |
| `tests/unit/test_daily_price_import.py` | 휴장·서머타임·조기 폐장, 원본 재실행 멱등성, 기준선 연결, 누락·중복·늦은 가격·잘못된 입력 시험 |

2026년 달력은 [Nasdaq 공식 일정](https://www.nasdaq.com/market-activity/stock-market-holiday-schedule)을
2026-10-19에 확인한 **예정** 일정이다. 임시 휴장·일정 수정을 자동 반영하는 거래소
원장이 아니다. 가격 공급원의 게시 시각과 과거 수정가격 버전은 CSV에 실제로 제공된
값만 사용한다. 파일 캡처 시각을 행별 최초 게시 시각으로 역산하지 않는다.

## 검증 결과

- `make quality PYTHON=.venv/bin/python`: Ruff 통과, Pyright 오류·경고 0개.
- `make test PYTHON=.venv/bin/python`: 전체 96개 통과. 신규 입력 시험 4개 포함.
- 합성 TLT CSV로 `scripts/import_daily_prices.py` 실행: 예정 세션 6개와 가격 6개,
  누락·중복·늦은 게시 0개, 기계적 구조 검사 통과. 사용 권리와 과거 버전은 여전히
  미확인으로 표시된다. 자동 시험 자료는 모두 합성 가격이며 실제 TLT 관측치가 아니다.

## 결정과 남은 게이트

1. `structurally_ready`는 **파일·일정·시각의 기계적 검사만** 통과했다는 의미다.
   `rights_review_required`, `price_vintage_review_required`는 계속 참이며
   `public_performance_allowed`는 거짓이다.
2. 입력 계약은 TLT, USD, XNAS, 한 세션당 한 수정가격 버전으로 제한한다.
   기업행동 뒤 과거 가격이 재조정되면 해당 시점의 전체 가격 버전 원장을 확보해
   시점별 선택을 구현해야 한다. 현재 중복 버전은 조용히 최신값으로 덮지 않는다.
3. 공급 계약의 개인 연구·시연·파생 지표 공개 범위와 보존 위치·기간을 확인하기
   전에는 제공자 API를 호출하거나 원천값과 실제 성과를 공개하지 않는다.
4. 실제 가격·정규장 세션 원장·공개 시각이 확보되면 우선 5거래일 기준선을 같은
   시점의 단일 시계열에서 점검하고, 20일 홀드아웃과 여러 ETF로 확장한다.
