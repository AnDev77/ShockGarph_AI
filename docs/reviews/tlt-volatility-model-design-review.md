# TLT 변동성 예측 모델 설계 리뷰

작성일: 2026-10-20. 사용자 요청에 따라 이미 구현된 첫 Ridge 후보의 성격을
정확히 밝히고, 논문을 근거로 다음 모델과 검증 조건을 문서화했다.

## 변경 내용

- `docs/tlt-volatility-model-design.md`에서 5·20일 미래 변동성의 정답,
  시점 계약, 현재 Ridge 후보의 결과, GARCH(1,1) 다음 비교, 분봉을 확보한
  뒤의 HAR-RV, 금리 변수 우선순위와 독립 시험의 승인 규칙을 적었다.
- 연준 직원의 2026년 개정 주식 고빈도 변동성 비교 연구와 2015년 국채
  금리 분포 연구를 TLT ETF의 성능 증거로 혼동하지 않도록 연구 대상과
  적용 한계를 따로 적었다.
- `docs/daily-risk-methodology.md`의 이전 상태 문구를 갱신했다. 실제 가격
  탐색 학습은 완료했지만 과거 수정가격 빈티지·자료 이용권을 확인한 실증은
  아직 보류 상태다. README·모델 설명서·프로젝트 흐름도에서 새 설계로
  연결한다.

## 검증 결과

이번 변경은 실행 코드나 예측 결과를 바꾸지 않는 문서 변경이다. 원문을 대조해
2026년 개정 연준 비교 연구의 표본이 S&P 500·미국 주식 40개이며 실현
변동성의 고빈도 자료를 사용한다는 점을 확인했다. 2015년 연준 연구의 정답은
TLT ETF 변동성이 아니라 국채 금리 분포이므로 그 결과를 프로젝트의 성능
주장으로 옮기지 않았다. 현재의 2024년 이후 시험 결과를 이미 살펴본 사실을
문서에 남겨, 새 모델을 같은 기간에 다시 맞춘 다음 독립 성능이라고 주장하지
않도록 했다. 전체 `make test`는 113개 검사를 통과했고, 앞선 첫 모델
시험의 미래 가격 변경·동일 날짜 비교·학습 부족 시 점수 보류 검사를 그대로
포함한다. `make quality`에서 Ruff는 모든 파일을 검사해 통과했고 Pyright는
오류 0개·경고 0개를 보고했다. 문서 내용의 논문 해석과 TLT 적용 가능성은
이 자동 검사만으로 입증되지 않으므로 연구 범위의 차이를 직접 기록했다.

## 사용자 점검표

- [ ] 현재 Ridge 회귀와 향후 HAR-RV를 서로 다른 모델로 이해할 수 있는지 확인한다.
- [ ] GARCH(1,1)의 가격 입력만 있는 단계와 HAR-RV의 분봉 입력 조건을 확인한다.
- [ ] 2024년 이후의 재시험을 독립 검증이라고 표시하지 않는지 확인한다.
- [ ] 공급 계약과 과거 가격 버전이 없을 때 제품 성능을 공개하지 않는지 확인한다.
