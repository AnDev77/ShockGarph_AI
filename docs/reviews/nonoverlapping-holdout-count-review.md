# 미래 변동성 평가의 비중첩 구간 수 정정

작성일: 2026-10-23. 직전 탐색 결과는 20일 평가 시작일 182개를
`182 // 20 = 9`로 내림한 값을 비중첩 미래 구간 수로 설명했다. 이 계산은
예측 시작일의 **완전한 20개 묶음 수**이지, 미래 정답의 날짜가 겹치지 않게
실제로 선택할 수 있는 구간 수가 아니다.

## 예시와 수정 범위

연속 182개 평가 시작일에서 1·21·41·61·81·101·121·141·161·181번째를
선택하면 미래 20거래일의 수익률 구간은 서로 겹치지 않는다. 따라서 선택
가능한 최대 개수는 `ceil(182 / 20) = 10`이다. 5일 평가 시작일 197개도
같은 방식으로 최대 `ceil(197 / 5) = 40`개다. `scripts/analyze_alpaca_history.py`의
탐색 JSON에서 `nonoverlapping_windows`는 이 개수를 보고하고, 기존 모델의
내림값은 `conservative_full_start_blocks`에 따로 보고하도록 수정했다.
시작일이 연속이라는 전제는 분석기가 입력 가격의 거래일 달력을 검증하고
평가 가능 시작일을 연속으로 고르는 이 탐색 경로에 한정된다.

**변동성 계산·모형 학습·평가 게이트·MAE 값은 바꾸지 않았다.** 이 수정은
보고서의 표본 설명 오류를 바로잡는다. 미래 구간의 수익률 날짜가 겹치지
않아도 시장 상태가 시간적으로 연관될 수 있으므로 10개를 독립적인
실험 10회로 해석할 수 없다. 과거 가격의 당시 버전, 새로운 독립 시험
기간과 지표 B 비교는 여전히 확보되지 않았다.

## 검증과 점검표

`make quality PYTHON=.venv/bin/python`에서 Ruff 위반 0건, Pyright 오류와
경고 0건이었다. `make test PYTHON=.venv/bin/python`에서 전체 158개
시험이 통과했다. Alpaca 통합 시험에 미래 정답 비중첩 개수는 올림,
기존 보수적 시작일 묶음은 내림으로 보고되는지 두 종목과 두 기간에 걸쳐
확인하는 검사를 추가했다. 이 테스트는 합성 가격 파일을 사용한다.
실제 Alpaca 과거 가격은 이전 Actions 러너 종료 때 삭제되어 이번에는
실제 자료를 다시 분석하지 않았다.
