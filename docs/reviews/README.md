# 핵심 기능별 개발 리뷰

사용자가 범위를 명시적으로 바꾸지 않는 한, 프로젝트 개발 요청 한 번은
21일 계획의 연속된 이틀을 진행한다.

새 작업은 `<핵심-기능>-review.md`로 기록하고 제목과 본문에 기능을 명시한다.
기존 일차별 파일은 당시의 작업 기록으로 보존한다.

1. 완료한 범위와 의도적으로 미룬 작업
2. 변경된 코드 구조
3. 정확한 테스트·품질 검사 결과
4. 데이터·모델·제품 관련 결정
5. 다음 작업 전에 사용자가 확인하거나 결정할 항목
6. 다음 작업의 계획

커밋 메시지도 실제 주요 변경 내용을 한글로 작성한다.

작업 간 성과 차이는 [진행 기록](../progress.md), 재현된 문제와 해결 여부는
[트러블슈팅](../troubleshooting.md)에 누적한다.
