# 5~6일차 이벤트 분석 파이프라인 리뷰

작성일: 2026-09-22

## 이번 우선순위와 완료 범위

사용자가 동의한 분석 우선순위에 따라 인프라 확장보다 CPI·소수 자산의 분석 경로를 먼저 만들었다.
이번 범위는 `feat/analytics`에서 진행한 연속 이틀 분량의 개발이다.

- 5일차: CPI 공개 API 커버리지 점검, 발표·확률·가격 입력 계약, 누수·결측·중복 검증
- 6일차: 과거 경험적 분포와 확률 가중 분포, 순차 재학습·평가, 대응 재표집, 재현 리포트 CLI
- 소스 코드 변경 전에 시간 누수·수익률·평가 계약 테스트를 작성하고 실패를 확인했다.
- 학습 가이드, 커버리지 점검표, 실행 명령, 현재 구현 상태를 한글로 정리했다.

## 검증 결과

- `make PYTHON=.venv/bin/python quality`: Ruff 통과, Pyright 오류·경고 0개
- `make PYTHON=.venv/bin/python test`: 총 63개 통과, 신규 21개 포함
- `make PYTHON=.venv/bin/python research-demo`: `synthetic_only`, 12개 가상 발표 중 8개 평가
- 같은 입력·설정 재실행: 동일 실행 해시·파일 내용, 원본 입력 불변
- CRPS: 손계산 및 쌍별 거리 정의와 일치
- 포트폴리오: 반대 방향 자산 수익률이 공동 표본에서 상쇄되는지 확인
- 누수: 발표 후 확률, 늦게 공개된 기대·가격, 미확정 정답, 미래 사건의 영향 차단 확인
- 표본 부족: 시나리오 표본이 부족하면 숫자 생성 대신 평가 생략
- Markdown 상대 링크·코드 블록과 `git diff --check`: 통과

## 실데이터 점검 결과와 제한

Kalshi 공개 조회 3곳은 이번 환경에서 HTTP 403이었다. FRED·ETF 공급원 키도 미설정이다.
실제 학습 표본, 모델 예측력, 라이브 배포·지속 실행을 확인한 것은 아니다.
관련 결과는 [커버리지 점검](../cpi-coverage-review.md)을 따른다.

지금 모델은 고정 임계값의 이진 시나리오 경험적 기준선이다. 실제 surprise의 크기,
전통적 기대·최근 변동성·국면을 학습하는 후보 모델은 아직 없다.
학습 분포의 표준편차는 일중 실현변동성의 예측 성과가 아니다.
독립 발표 재표집에는 시계열 의존성·다중탐색 보정이 없으므로 연구 결과 해석 시 제한을 표시한다.
기존 보정 패키지의 행 단위 Brier API는 그대로이며 새 분석의 불확실성은 발표별 CRPS 차이로 계산한다.

## 사용자 점검표

- [ ] 합성 예제를 실행하고 `synthetic_only`와 `train_event_ids`를 확인했다.
- [ ] 고정 임계값 기준선과 실제 surprise 회귀의 차이를 설명할 수 있다.
- [ ] 데이터 공급원 키·이용 가능 범위·공통 기간을 확인할 환경을 정했다.
- [ ] 발표시각·가격 기준시각·경제지표 단위의 매핑 근거를 확보했다.
- [ ] 실데이터 비교 전에 주 지표와 평가 기간을 정할 예정이다.
