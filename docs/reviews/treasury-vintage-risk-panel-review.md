# 미국 재무부 금리 빈티지와 위험 패널 연결 리뷰

작성일: 2026-10-22. 직전 작업은 공개 XML을 받을 때 원본을 보관하는 수집기만
추가했다. 이번 작업은 그 원본을 다시 읽어 비공개 위험 비교 입력으로 만드는
경로와 TLT 가격 이력의 날짜별 겹침을 세는 보고를 추가했다.

## 변경된 구조와 동작

`load_treasury_history`가 `data/raw/us-treasury/` 아래 보관본을 읽는다. 요청한
월·원본 XML·저장 파일명·응답 바이트 SHA-256·보관 페이로드 SHA-256을 검사하고,
같은 관측 날짜에 나중에 다시 수신한 값을 별도 빈티지로 남긴다. 수집 단계에서도
XML을 먼저 검증하므로 잘못된 월이나 중복 날짜의 응답은 저장하지 않는다.

`evaluate_traditional_holdout.py --treasury-archive data/raw`는 날짜별
`UST10Y_PAR`를 B 패널에 전달한다. 해당 값은 실제 수신 시각 이후 예측에서만
사용한다. 원본은 일중 관측·게시 시각을 주지 않으므로 `observation_date`와
`captured_at`을 따로 유지한다. 관측일 0시(뉴욕 시각)는 신선도를 보수적으로
계산하기 위한 기준일 뿐, 실제 게시 시각이라는 주장은 아니다. 나중에 고친
금리 빈티지가 앞선 예측에 섞이지 않도록 시점별 선택을 검사했다. 기존 `DGS10`
CSV와 `UST10Y_PAR`를 같은 시리즈로 합치지 않는다.

`make treasury-coverage PRICE_HISTORY=/private/tlt.csv TREASURY_RAW_ROOT=data/raw`
는 가격 세션 수, 금리 관측일·수신본 수, 같은 날짜의 겹침, 첫 수신일보다 늦은
가격 세션과 이전 날짜에 이미 금리 원본을 수신한 세션 수를 보고한다. 이는
가격 단일 버전을 이용한 **설명용 자료 커버리지**다. 같은 날짜 수신본을 해당
날짜 장마감 예측에 쓸 수 있었다고 추정하지 않는다. 예측 정확도나 실현 변동성
점수를 계산하는 보고가 아니다. 보관 금리 원본이 없다면 입력 오류로 끝난다.

## 실제 검증 결과

`make quality PYTHON=.venv/bin/python`에서 Ruff 위반 0건, Pyright 오류·경고
각 0건이었다. `make test PYTHON=.venv/bin/python`에서 전체 **153개 시험이
통과**했다. 신규 시험은 합성 XML의 두 수신본에서 같은 관측일의 수정 값을
둘 다 보관하는지, 원본 훼손을 해시 검사로 막는지 확인했다. 날짜만 있는
금리가 수신 이전의 예측에 들어가지 않고 나중의 수정 값이 과거 예측을
바꾸지 않는지도 검사했다. 합성 TLT 네 세션과 합성 금리 두 관측일에서는
날짜 겹침 2건이었지만 첫 수신일보다 나중인 가격 세션은 1건으로 구별됐다.
잘못된 XML을 수집했을 때 저장 파일이 0건인지도 확인했다. 통합 시험은 보관
금리 경로가 기존 A/B 비교기에 연결되고 원본 확인 여부와 미검증 수신 시각
상태를 보고하는지 확인했다. **모든 신규 수치는 합성 입력 시험 결과**다.

이 실행 환경에서는 재무부 외부 도메인 HTTP 응답을 받지 못했다. 따라서 실제
금리 보관본, 실제 TLT와의 공통 시점 통계, 실제 A 대비 B의 오차 결과는 이번에
산출하지 않았다. 실제 로컬 TLT 파일을 넣어 `make treasury-coverage`를 실행한
결과는 빈 재무부 보관소 때문에 `invalid_input`과
`Treasury raw archive is empty`였다. 현재 TLT 수정종가 파일 한 벌은 과거 시점별 가격 빈티지를
증명하지 않으므로 `public_performance_allowed=false`와 제품 성능 `HOLD`를 유지한다.
보관 파일의 해시 일관성은 검사할 수 있지만, 외부 시각 인증이나 과거 공급원
게시 시각까지 독립적으로 확인할 수는 없다.

- [x] 저장 원본 해시 및 잘못된 XML의 저장 방지를 합성 시험으로 확인.
- [x] TLT 가격과 금리 보관본의 공통 날짜·첫 수신 이후 세션을 점수 없이 보고.
- [ ] 네트워크가 되는 환경에서 실제 월별 피드를 수신하고 원본 형식을 확인.
- [ ] TLT/SPY 가격의 시점별 원본·이용 권리와 충분한 독립 시험 기간 확보.
- [ ] 실제 공통 표본에서 고정된 A/B 오차와 불확실성을 별도로 평가.
