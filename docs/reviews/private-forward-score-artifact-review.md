# 사전 위험 점수의 비공개 불변 아티팩트 리뷰

## 변경 구조

예측 당시 index와 이후 정답 가격 index를 각각 R2에서 재감사한 후 계산한 점수를, 두 index 원본의 SHA-256을 포함한 조합 식별자로 비공개 R2에 저장한다. 본문에는 원본 index 경로·해시, TLT·SPY 각 5일 또는 성숙한 20일 점수, `public_performance_allowed=false`를 담는다. 조건부 쓰기 뒤 크기·메타데이터 해시·본문 바이트를 다시 읽어 확인한다. 실행당 4MB, 전용 버킷 8GB 게이트를 저장 전에 적용한다.

## 시험과 한계

합성 R2에서 5일이 성숙한 두 종목의 점수 2건을 저장하고 같은 원본 조합 재시도에서는 신규 객체 0건을 확인했다. 저장된 바이트를 바꾸면 collision으로 실패하고, 버킷 한도에 닿으면 점수 객체를 쓰기 전에 거부한다. 해당 통합 모듈의 13개 시험과 Ruff·Pyright 검사는 통과했다. 전체 181개 예상 시험과 wheel·원격 CI 결과는 별도 확인한다.

## 증권사 리서치 관점

이 아티팩트는 계산을 재현할 사후 증거를 보존하며 아직 평가 결과를 공개하는 단계가 아니다. 같은 시작일·기간을 여러 정답 빈티지로 재채점한 아티팩트는 서로 다른 객체가 되므로, 집계 전에 어떤 빈티지를 공식 점수로 삼을지 기준을 고정해야 한다. AGENTS.md에 따른 평가 메타데이터의 PostgreSQL 영속화도 남았다. 실제 미래 정답 0건, 검증된 예측 우위 0건이라는 상태는 변하지 않는다.

## 전체 로컬 검증 결과

wheel 빌드와 필수 소스 7개 확인에 성공했다. Ruff 오류 0건과 Pyright 오류·경고 0건이었다. 전체 181개 시험이 통과했으며 직전 180개에서 점수 불변 저장 통합 시험 1개가 늘었다. 이 시험이 증명하는 것은 조건부 쓰기·읽기 재검증·비용 차단이고 실제 5일 ETF 오차는 아직 측정하지 못했다. 원격 PR 게이트 결과는 별도 확인한다.
