# 연은 위험지수 후보의 시점·신선도 분리 리뷰

작성일: 2026-10-21. 이번 변경은 주간 시장 상태 지수를 종목별 모델 B의
**후보 입력으로 안전하게 연결할 수 있는 계약**이다. 연은 지수를 실제로
수집·학습했거나 SPY·TLT 예측 성능이 좋아졌다는 판정은 아니다.

## 직전 대비 달라진 점

| 항목 | 직전 | 이번 |
|---|---|---|
| 지표 경과시간 | DGS10, VIX 등 모든 지표에 하나의 `max_indicator_age` 적용 | 이름별 `indicator_max_ages`를 줄 수 있으며 지정하지 않은 지표는 기존 공통 상한 유지 |
| 지표 결측 | B 행이 제외된 총 이유만 표시 | 처음 제외를 일으킨 **지표 이름·이유·횟수**도 `indicator_exclusions`에 기록 |
| 비공개 비교 명령 | 전체 지표에 공통 `--max-indicator-age-hours` | `--indicator-age-hours NAME=HOURS`를 반복 입력하고 사용한 상한을 보고서에 기록 |
| 진행·장애 추적 | 기능별 리뷰에 흩어짐 | [진행 기록](../progress.md)과 [트러블슈팅](../troubleshooting.md)에 이전 성과 대비 변화와 장애 상태를 연결 |

## 구현과 계산 경계

- `macro_panel.py`는 `observed_at <= prediction_at`과
  `available_at <= prediction_at`을 **모두** 만족하는 최신 관측만 고른다.
  지표별 `prediction_at - observed_at` 상한을 적용해 너무 오래된 값은 B에서
  제외한다. 주간 관측이 금요일로 찍혀도 실제 게시가 수요일 이후라면 게시
  전 예측에는 들어가지 않는다. 빈 지표를 0으로 채우지 않는다.
- `evaluate_traditional_holdout.py`는 이름에 없는 상한, 중복 상한, 0·음수·
  무한대 상한을 거부한다. 비공개 출력 `schema_version=3`에 적용한 지표별
  상한과 지표별 누락 원인을 넣는다. A, B0, B1, GARCH의 동일 날짜 비교와
  `public_performance_allowed=false`는 유지했다.
- 하나의 예측 행에서 복수 지표가 동시에 결측일 때 **입력 순서상 첫 실패**만
  제외 이유에 기록한다. `indicator_exclusions`는 전체 입력 시리즈의 결측률이
  아니라 B 행의 제외 원인이다.
- [시카고 연은 NFCI의 위험 하위지수](https://www.chicagofed.org/research/data/nfci/about)와
  [세인트루이스 연은 STLFSI4](https://fred.stlouisfed.org/series/STLFSI4)는
  주간 금융시장 상태 지표다. `NFCI_RISK`는 예시 CSV 시리즈 이름일 뿐
  공식 자료의 자동 수집기가 아니다. FRED의 VIX도 CBOE 자료이므로
  연준 자체 예측 수치로 표시하지 않는다.

## 검증 결과와 실제 성과

직전 핵심 작업의 전체 시험은 138개였다. 이번에는 지표별 신선도, 게시 후
사용, 잘못된 설정 거부를 검사하는 단위 시험 3개와 CLI 기록·거부 시험 1개를
추가했다. **`make test PYTHON=.venv/bin/python`에서 142개가 모두 통과**했다.
주간 지표가 관측되었어도 다음날까지 미공개라면 그 날의 B 행은 생성되지
않는지 확인했고, 일별 금리가 오래됐을 때 주간 지수가 신선하다는 이유로
그 행을 유지하지 않는지도 확인했다. CLI 시험에서는 각 지표의 25시간·
240시간 설정이 출력에 남고 알 수 없는 시리즈의 설정은 거부됨을 확인했다.

`make quality PYTHON=.venv/bin/python`에서 Ruff 검사에 위반 0건, Pyright에
오류 0건·경고 0건이었다. 시험의 지표와 가격은 전부 **합성**이다. 실제
NFCI·STLFSI4 관측치, TLT/SPY 시점별 가격·권리, 새로운 독립 시험 기간이
없어서 B의 성능 변화는 이번에도 **측정 불가 (`HOLD`)**다.

## 이번 작업의 트러블슈팅

초기 실행에서 `.venv/bin/python`이 없었다. 오프라인 `uv` 재설치는
필수 패키지 캐시 부족으로 실패했고, 이후 `uv sync --extra dev`로 테스트
환경을 다시 만들었다. 첫 정적 검사에는 기존 그림 스크립트의 선택적
`matplotlib`이 없어 가져오기 오류가 났으며, `uv sync --extra dev --extra viz`
로 복구했다. 신규 시험의 타입 추론 오류는 모호한 `dict` 인자를 명시적
키워드 인자로 바꾸어 해결했다. 기존 통합 시험의 출력 버전 기대값도 2에서
3으로 갱신했다. 짧은 합성 홀드아웃은 비교기가 패널에 도달하기 전에
차단되므로, 이 사례에서 없는 `coverage`를 읽으려던 신규 시험은 차단 상태를
검사하도록 수정했다. 최종 전체 142개와 정적 검사가 통과한 상태다.
