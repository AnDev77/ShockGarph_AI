# 보관 가격 스냅샷의 시간순 홀드아웃 평가 리뷰

작성일: 2026-10-19. 보관된 전체 수정가격 CSV와 캡처 시각을 고정해 TLT 형식의
5·20거래일 최근 변동성·EWMA를 비공개로 비교한다. 입력 파일의 실제 공급원 권리와
수신 기록은 아직 확보되지 않았으며 아래 계산 수치는 모두 **합성 시험 가격**이다.

## 구현 구조

| 경로 | 기능 |
|---|---|
| `packages/risk_engine/shockgraph_risk/daily.py` | `SnapshotHoldoutReport`, 기간별 차단 상태와 결측 거래일, 고정 홀드아웃 점수·입력 지문·정답 해시 |
| `scripts/evaluate_snapshot_holdout.py` | 엄격한 JSON manifest, 상대 CSV 경로, 원본 불변 저장, 거래소 달력과 원본 해시 기록, 비공개 JSON 출력 |
| `Makefile`, `README.md`, `docs/daily-risk-methodology.md` | `risk-evaluate` 실행과 입력 형식, 최소 표본 및 공개 제한 설명 |
| `tests/unit/test_snapshot_holdout.py`, `tests/integration/test_snapshot_holdout_cli.py` | 두 기간의 수치 재현, 짧은 표본 차단, 캡처 누락 진단, CLI 원본 보존과 출력 재생성 |

## 평가 계약

manifest는 2026년 예정 Nasdaq 거래일의 시작·끝, 고정된 시험 시작일,
마지막 예측 이후의 평가 시각, 캡처 순서의 전체 이력 파일을 지정한다. 파일마다
해당 날짜까지 첫 거래일부터 모든 종가가 있어야 하며, 예측 시각까지 최신 완전
스냅샷이 없다면 빠진 날짜를 보고하고 점수를 내지 않는다. 두 기준선은 같은
거래일과 같은 미래 정답에서 비교한다. 겹치는 `h`일 정답을 독립 표본처럼 세지
않도록 `n // h` 비중첩 구간이 2개 미만이면 기간 전체의 점수를 보류한다.

점수를 계산해도 상태는 `evaluated_research_only`이고, 파일·manifest의 해시와
가격 입력 지문, 정답 파일의 해시가 함께 남는다. 파일에 적힌 `captured_at`과
`available_at`이 실제 공급원의 과거 공개 시각인지, 수정가격의 배당·분할 조정
범위가 동일한지, 자료 활용 권리가 있는지는 이 경로만으로 증명할 수 없다.
민감도가 매우 높은 2개 비중첩 구간은 최소 계산 요건일 뿐 사업상 성능 검증은 아니다.

## 시험 결과와 해석

- 95개 합성 예정 거래일에 매일 전체 가격 이력을 캡처한 시험에서 5일 홀드아웃은
  정답 55개와 비중첩 구간 11개를 얻었다. 최근 변동성 MAE는 약 0.000440,
  EWMA MAE는 약 0.000589로 이 인공 패턴에서는 최근 변동성이 작았다.
- 같은 시작일의 20일 홀드아웃은 정답 40개와 비중첩 구간 2개였다. 최근 변동성
  MAE는 약 0.000109, EWMA MAE는 약 0.000145였고 두 기간 모두 동일 입력
  재실행에서 보고서와 짝지은 블록 구간이 정확히 재현됐다. 20일의 2개 구간은
  실제 우열을 주장하기에 매우 부족하다.
- 자료를 70거래일로 줄이자 20일 정답이 15개, 비중첩 구간은 0개가 되어
  `insufficient_nonoverlapping_windows`로 수치가 숨겨졌다. 중간 하루의
  캡처를 제거하면 처음 비는 날짜를 표시하고 두 기간 모두 점수를 보류했다.
- 12개 합성 CSV의 CLI 시험은 원본 12개를 해시와 함께 저장하고 출력에 로컬
  파일 경로를 노출하지 않았다. 동일 입력을 다른 파일로 재실행한 JSON은 일치했고,
  기존 출력 덮어쓰기는 실패했으며, 이력 누락 파일은 `invalid_input`으로 끝났다.
- `make quality`: Ruff 통과, Pyright 오류·경고 0개.
- `make test`: 전체 106개 통과. 이번에 추가한 단위 시험 4개와 CLI 통합 시험 2개가
  고정 홀드아웃, 부족한 20일 표본 차단, 누락 캡처, 재실행과 원본 보존을 확인했다.

## 남은 검증과 다음 연결

실제 TLT의 과거 전체 이력 파일, 원본 수신 증거, 연구·서비스 사용 권리,
임시 휴장 기록과 가격 조정 정의를 확보해야 한다. 자료를 구한 뒤 결측률과
5·20일 유효 구간 수를 먼저 기록하고, 뒤이어 브렌트·금리·VIX의 게시 시각을
맞춘 동일 기간의 증분 모델을 비교한다. 충분한 비중첩 구간과 국면별 분석이
없으면 공개 위험 스냅샷에 성능을 연결하지 않는다.
