# 일별 시장 위험 분석 전환

상태: 2026-10-21 합성 가격 기준선과 2024~2026년 Nasdaq 세션·로컬 TLT CSV 품질 검사 구현.
보관된 전체 가격 스냅샷을 예측 시점에 맞춰 고르는 경로도 합성 자료로 검증했다.
현재 TLT 수정종가 이력 한 벌로 비공개 탐색 학습·비교를 수행했고,
보관 가격 기준선과 전통 지표·발표 전 단일 계약 확률의 시점별 결합을 합성
자료로 검증했다. A/B의 보관 빈티지 분리·동일 날짜 비교는 합성 자료에서
작동하지만 B 실자료 모형과 성능은 아직 없으며,
허가된 가격 공급원 연결과 과거 시점별 실증 성능 검증은 미완료다.
[TLT 변동성 모델 설계](tlt-volatility-model-design.md)에 비교 순서와 선정 규칙을 고정했다.

`packages/risk_engine/shockgraph_risk/daily.py`의 첫 구현은 명시적인 거래소 세션
목록과 가격마다 `available_at`을 요구한다. 해당 시점 이전에 이용할 수 있던 수정
종가만으로 최근 실현 변동성과 EWMA를 계산하고, 미래 가격 전체가 이용 가능해진 뒤
정답을 별도로 붙인다. `make risk-demo`의 가격·평가는 **합성 예제**다.
2024~2026년 Nasdaq 달력과 로컬 CSV 검사 경로는 구현됐다. 별도 비공개 경로에서
현재 TLT 수정종가 이력 한 벌을 사용했으나 당시 공개된 가격 버전을 증명하지 못한다.
로컬 CSV는 원본 해시와 행별 게시 시각을 기록할 수 있지만 실제 공급원의
수정가격 기업행동 빈티지·게시 지연·서비스 이용권은 확인되지 않았다. 데모 손실을
실증 성과로 표시하지 않는다. [입력 게이트](data-source-gate-b.md)의 2025년
1월 9일 임시 휴장은 거래소 추가 공지를 대조해 반영했다. 이후 예외 일정과
2026년 **예정** 세션은 별도로 확인해야 한다.

### 수정가격의 시점별 계산

배당·분할 조정은 과거 수정종가에도 적용될 수 있다. [Databento의 조정계수
예제](https://databento.com/docs/examples/adjustment-factors/applying-adjustment-factors)는
조정계수를 이전 가격 전체에 적용한다. 공급원에 따라 배당 조정 여부도 달라진다.
예를 들어 [IBKR의 자료형 문서](https://www.interactivebrokers.com/docs/tws-api/doc/md/historical-bars)는
`TRADES`와 `ADJUSTED_LAST`의 조정 범위를 다르게 설명한다. 특정 공급원 계약과
수정가격 정의를 확인하기 전에는 서로 다른 출처의 `adjusted_close`를 결합하지 않는다.

`PriceSnapshot`은 **실제로 보관한 한 시각의 전체 이력 파일**이다. 각 예측은
`captured_at <= prediction_at`인 스냅샷 중 그 거래일까지 완전한 최신 파일 하나로
최근 변동성·EWMA를 처음부터 다시 계산한다. 과거의 각 날짜에서 제각기 최신
가격을 골라 한 수익률 시계열로 합치지 않는다. 예측 입력의 해시에는 스냅샷 시각,
각 가격의 수정종가·공개 시각·원본 해시를 담는다. 미래 정답은 평가 시점에
보관한 별도 스냅샷으로 계산하고, 그 파일의 캡처 시각 이전에는 학습에 사용하지
않는다. 최초 가격 버전의 `available_at`이 파일 캡처보다 이르더라도 예측의
실증 근거는 실제 보관 시각을 넘어서 소급되지 않는다.

## 왜 분석 단위를 바꾸는가

기존 Kalshi `T0.3` CPI 감사에서는 결과 확정 발표 55개 중 유효 확률 29개, 과거비율과 비교 가능한 발표 24개를 확인했다. 이는 특정 CPI 계약 정산 결과를 비교하는 표본이다. 계약의 임계값, 1분 캔들, 분석 자산을 늘려도 독립 CPI 발표 횟수는 늘지 않는다. 이 적중률 감사는 [이벤트 연구](cpi-coverage-review.md)로 보존한다. 이 계약 확률은 **당시 해당 계약 참가자가 반영한 기대**를 설명할 수 있지만 TLT 위험 예측력이 입증된 입력이 아니다. 첫 실험은 가격 A와 전통 시장 정보 B의 비교다.

주 분석 표본은 `거래일 × 자산` 패널이다. 거래일을 늘려도 연속한 날짜의 위험과 겹치는 미래 손실은 서로 의존하므로 유효 표본 수가 행 수와 같다고 가정하지 않는다. 선형/비선형 변동성 모델에 대한 [미 연준의 비교 연구](https://www.federalreserve.gov/econres/feds/linear-and-nonlinear-econometric-models-against-machine-learning-models.htm)와 [BIS의 시장 스트레스 예측 연구](https://www.bis.org/publications/working-paper-1250-predicting-financial-market-stress-machine-learning)는 복잡한 모델보다 사전에 고정한 기준선과 표본 외 손실 비교가 중요하다는 출발점이다.

## 분석 정의

매 거래일 `t`의 미국 동부시간 정규장 종가 이후 정해진 시각에 분석 스냅샷을 만든다. `t` 종가의 실제 이용 가능 시각을 확인하지 못하면 다음 거래일로 미룬다. `prediction_at` 이전에 공개·수집돼 이용 가능했던 입력만 사용하고 `label_end_at`이 지난 정답만 재학습에 사용한다.

**특징량(feature)**은 예측할 때 이미 확인할 수 있는 자료를 모델 입력용 숫자로
만든 것이다. 첫 제품의 예를 들면 예정 발표까지 남은 시간, TLT의 최근 변동성,
그때까지 발표된 브렌트유 변화율, 국채금리와 VIX 값이다. Kalshi 계약 확률은
별도의 사건 맥락이다. 발표가 늦은 자료는
해당 날짜의 값이라도 `available_at > prediction_at`이면 사용할 수 없다.

| 분류 | 후보 입력 | 변환 및 주의 |
|---|---|---|
| 대상 자산 | TLT 우선, 이후 SPY·XLE | 배당·분할을 반영한 수정가격, 달력·통화 통일, 권리 확보 |
| 원유 | 브렌트유 일별 현물, 선물은 권리 확인 후 | 1/5/20거래일 변화율·실현 변동성. 발표 시점에 미공개인 EIA 현물 종가는 사용 금지 |
| 금리·물가 기대 | 미 국채 2년·10년, 10년 실질금리·브레이크이븐 | 수준과 변화량 구분. 일별 발표 지연 및 결측 반영 |
| 위험 환경 | VIX, 이후 신용 스프레드·달러 | 수준·최근 변화량. 원천 시리즈의 재배포 조건 확인 |
| 경제지표 | 마지막으로 **발표된** CPI 최초값·당시 컨센서스 | 발표 후 실제 충격과 경과 일수. 당시 기대값 공급원이 없으면 충격 변수 제외 |
| 별도 사건 맥락 | CPI/FOMC 관련 Kalshi **특정 계약**의 당시 호가·확률·거래량 | 질문·임계값·`observed_at`/`available_at`·스프레드·출처·표시 권리를 검증하고 발표 전 관측만 당시 기대라고 설명. 첫 제품 A/B 모델에는 입력하지 않음 |
| 자산 자체 이력 | 1/5/20일 수익률, 과거 변동성 | 계산 구간 종료가 `prediction_at` 이전인지 확인 |

EIA의 [브렌트유 일별 자료](https://www.eia.gov/dnav/pet/hist/rbrted.htm), FRED의 [기대인플레이션](https://fred.stlouisfed.org/series/T10YIE)과 [VIX](https://fred.stlouisfed.org/series/VIXCLS)는 탐색할 시계열이다. FRED/ALFRED의 [빈티지 조회](https://fred.stlouisfed.org/docs/api/fred/series_observations.html)는 개정 자료의 당시 값을 재현하는 데 쓸 수 있으나, 시각별 게시 지연과 ETF 거래가격 권한을 자동으로 해결하지 않는다. 브렌트 현물과 브렌트 선물은 같은 관측이 아니므로 필드·기준시각을 구분한다.

## 정답과 기준 모델

첫 목표는 대상 ETF의 `t+1`부터 `t+h`까지 일별 로그수익률로 계산한 `h=5,20`의 미래 실현 변동성이다. 예를 들어 `sqrt(sum(r²) / h)`를 기간 내 변동성으로 쓰며 연율화 여부를 일관되게 표기한다. 구간 종료일을 `label_end_at`으로 기록한다. 여기서 **정답(label)**은 예측 시점에 알 수 있는 입력이 아니라, 5·20거래일이 지난 뒤 실제 가격으로 계산해 과거 예측과 비교하는 값이다. 이 수치는 미래 가격의 방향이나 손실 금액이 아니다.

1. 동일 기간의 최근 변동성, 단순 이동평균, EWMA를 확정된 기준 모델로 등록한다.
2. 같은 시각·날짜에서 가격과 사전에 이용 가능한 금리·VIX·발표 일정/컨센서스만으로 규제 회귀 B를 맞춘다. 이 입력의 권리·시점과 공통 표본을 확인한다.
3. 표본이 충분할 때에만 B와 **동일 입력·날짜**로 트리 기반 머신러닝을 비교한다. 신경망은 충분한 독립 표본과 반복되는 표본 외 개선이 있을 때만 후보로 둔다.
4. 기존의 확률 결합 C는 첫 제품 경로에서 보류한다. 별도 연구로 다시 시작한다면 B와 **동일 모형·날짜**에 발표 전 계약 확률 특징만 추가하고 `C−B`의 짝지은 오차·독립 발표 수를 따로 보고한다. 확률 결측을 0%로 채우지 않는다.
5. 하방 손실은 다음 5·20거래일의 포트폴리오 누적손실 분위수로 후속 실험한다. 5% 분위수·예상손실은 꼬리 관측과 구간 포함률이 부족하면 제품에 숫자로 제공하지 않는다.

모델 입력으로 같은 날짜의 타 ETF 수익률을 써도 날짜를 분할 경계로 묶는다. 미래 수익률을 알려주는 동시 관측, 역산된 수정가격, 당일 발표 전에는 알 수 없었던 CPI 값이 섞이지 않도록 입력별 `available_at`을 보존한다.

## 성능 주장 규칙

- 시간순 확장/이동 학습에서 각 평가일에 정답이 **이미 확정**된 행만 학습한다. 고정 검증/시험 경계에서는 `label_end_at`이 경계를 넘는 학습 행을 제거한다.
- 하이퍼파라미터·특징 선택·표준화는 훈련 구간 안에서만 맞춘다. 마지막 연속 기간은 최종 시험용으로 남긴다.
- 변동성은 MAE와 양수 분산 예측에 대한 QLIKE를 기준선과 같은 날짜·자산에서 비교한다. 하방 모델은 pinball loss, 구간 포함률과 평균 폭을 보고한다.
- 현재 기준선의 QLIKE는 예측 분산을 최소 `1e-12`로 제한하고 `log(예측분산) + 실현분산/예측분산`을 쓴다. 값 자체보다 동일 표본에서의 차이를 해석한다. 겹치는 정답을 고려한 쌍별 순환 블록 재표집 길이는 예측 기간과 같으며, 2개 블록 미만에서는 구간을 보고하지 않는다. 이는 합성 데모의 민감도 검사이지 실자료의 성능 보증이 아니다.
- 5·20일 정답의 겹침을 고려해 주별/월별 비중첩 평가와 시계열 블록 재표집으로 민감도를 점검한다. 전체 행 수만으로 독립 신뢰구간을 계산하지 않는다.
- 같은 발표에 속한 날짜가 분할을 가로지르지 않도록 하고, A/B는 실제 가격·전통 지표의 공통 날짜에서 비교한다. 확률 스냅샷의 날짜로 A/B 표본을 제한하지 않는다. 이미 본 2024년 이후 TLT 탐색 결과는 신규 후보의 독립 시험으로 재사용하지 않는다.
- 위험 국면별 실패 사례와 비용·데이터 결측·공개 지연을 공개한다. B가 A를 개선하지 못하면 B의 추가 성과를 주장하지 않는다. A의 공개 가능성은 시점·권리·절대 오차·국면별 안정성·사용자 효용을 따로 검토한다.

### 보관 스냅샷의 시간순 홀드아웃

`evaluate_snapshot_holdout`은 지정한 `holdout_start` 거래일 이후의 5·20일
예측에 각각 동일한 날짜의 최근 변동성·EWMA를 대응시킨다. 각 예측은 예측 시각 전에
보관된 **완전 이력 스냅샷 한 개**에서 구하고, 미래 정답은 `evaluation_at`까지 받은
최종 스냅샷에서 구한다. 평가 범위에 필요한 하루치 파일이 없으면 처음 빠진 날짜를
보고하고 해당 기간의 점수 전체를 보류한다.

정답이 계산된 예측 시작 날짜가 `n`개이고 평가 기간이 `h`거래일이면 비중첩
미래 구간 수를 보수적으로 `n // h`개로 센다. 2개 미만이면 MAE·QLIKE·구간을
보이지 않는다. 2개 이상이면 같은 정답과 날짜에서 두 기준선을 채점하고 길이 `h`의
쌍별 블록 재표집 구간을 함께 남긴다. 이 최소 기준은 추론의 충분성이나
실자료 제품 승인 조건을 뜻하지 않는다. 보고서의 모든 계산 상태는
`public_performance_allowed=false`다. 공급원 시점·권리와 거래소 달력의
진위를 별도로 검토해야 한다.

## 제품으로 가는 순서

1. TLT 가격·전통 시장 정보의 **개인 연구, 공개 서비스, 파생 결과 표시 권리**를 확인한다. Kalshi 계약 설명에는 별도로 계약별 시점·호가 품질과 표시 권리를 확인한다.
2. 원본 보존과 `available_at`, 발표 시각을 포함한 가격·전통 지표 공통 날짜 패널을 만들고, TLT 5·20일 정답과 최근 변동성/EWMA를 재현한다. 결측률과 비중첩 구간 수를 먼저 센다.
3. 같은 기간의 A/B를 비교해 **전통 정보의 추가 예측력**을 판단하고, 표본이 허용하면 B와 같은 입력의 작은 머신러닝을 따로 판단한다. 브렌트 등은 시점이 맞는 후보 입력으로 비교한다. 기존 C는 연구 이력으로 보류한다.
4. 통과한 TLT 위험 결과와 불확실성을 FastAPI·공개 웹에서 보여주고 사용성을 확인한다. B의 A 대비 개선, A의 절대 오차·안정성과 이용자 가치를 분리해 판정한다. 어떤 수치도 검증되지 않았으면 전망을 승인하지 않는다. 권리가 확인된 계약의 당시 기대·최초 발표값·ETF/금리 관측을 시점별로 자동 결합한 리포트가 기존 도구를 이용한 수동 조사보다 시간·오류를 줄이는지 별도 시험한다. [성과별 제품 선택](product-goal-and-fallback.md)을 따른다.
5. 이후 SPY·XLE와 [공동 포트폴리오 위험](portfolio-risk-methodology.md)으로 확장한다. 합성 가격 기준선만 선행 구현했고 실제 공동 손실은 검증하지 않았다.
6. 종목 보유 인증 채팅은 분석 리포트/위험 전망의 반복 사용과 토론 수요, 데이터 권리·인증 공급원·운영 역량 확인 후 별도 도입한다.
