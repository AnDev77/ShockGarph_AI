# TLT 변동성 예측 모델 설계와 논문 근거

작성일: 2026-10-20. 이 문서는 일별 ETF 위험 연구의 **다음 실험을 고정하는 설계**다.
구현 완료나 예측 성능의 승인을 뜻하지 않는다. 우선 TLT의 5·20거래일 뒤 변동성을
예측하고, 다른 ETF와 포트폴리오는 각자의 데이터와 기준선을 확보한 다음 검증한다.
거시 이벤트를 독립변수로 하는 [TLT 수익률 예측](macro-event-tlt-return-model.md)은
부호 있는 수익률이 정답인 별도 첫 검증 목표다. 이 문서의 GARCH와 HAR-RV는
그 수익률 정답을 예측하지 않는다.

## 현재 모델은 무엇인가

현재 비공개 탐색 코드는 과거 TLT 수정종가의 일별 로그수익률에서 최근 1·5·20개
수익률의 제곱평균 제곱근을 계산한다. 세 값의 로그를 입력으로 하고, 미래 5일 또는
20일의 같은 통계량의 로그를 정답으로 하는 **Ridge 선형 회귀**를 기간별로 따로
학습한다. 입력 표준화는 학습 구간에서만 하고, 절편을 제외한 계수에는 고정 패널티
10을 쓴다. 2024-01-02 이전에 미래 정답까지 끝난 예만 학습해 모델을 한 번
고정한 뒤 2024년 이후 가격과 비교했다. 이 설정은 구현 경로를 검증하는 첫
후보이지, 논문의 HAR-RV 재현이나 최종 선정된 TLT 모델이 아니다.

실제 수정종가 이력 한 벌의 탐색 비교에서는 두 기간 모두 MAE가 EWMA보다 컸다.
5일 MAE는 Ridge 0.003156, EWMA 0.002740이고 20일은 각각 0.003243,
0.001604이다. 수치는 **일별 변동성 비율의 절대오차**다. 예를 들어 0.003156은
약 0.316%p다. 5일 QLIKE만 Ridge가 낮아 지표별 판정이 다르다. 이 결과를
보고 새 특징량이나 패널티를 고르면 이미 살펴본 2024년 이후 자료는 독립적인
최종 시험이 될 수 없다. [실험 리뷰](reviews/tlt-price-only-model-review.md)에
표본 수와 블록 재표집 결과가 있다.

| 근거 | 원문에서 확인한 내용 | TLT에 적용할 범위 |
|---|---|---|
| [Kılıç, 미 연준 FEDS 2025-061r1, 2026년 개정](https://www.federalreserve.gov/econres/feds/linear-and-nonlinear-econometric-models-against-machine-learning-models.htm) | S&P 500과 미국 주식 40개의 **고빈도 자료로 계산한 실현 변동성**에서 HAR·ARFIMA·국면 전환 HAR와 XGBoost·신경망을 같은 조건으로 비교했다. 1일과 월간에 유리한 모델이 달랐고 ML의 일관된 우위는 없었다. | 기간마다 후보와 기준선을 별도로 비교한다. 이 논문의 주식 성능 수치를 TLT 성능으로 옮기지 않는다. 연준 직원의 작업논문이며 공식 투자 모델이 아니다. |

## 정답과 정보 시점

| 항목 | 사전 정의 |
|---|---|
| 예측 시각 | 미국 ETF 정규장 종가 **이후**, TLT 종가를 공급원에서 실제 수신한 UTC 시각. 당일 가격이 그때 없으면 예측을 늦추거나 결측 처리한다. |
| 가격 | 한 예측에 실제 수신된 **완전한 수정가격 이력 한 벌**만 사용한다. 과거 배당 조정이 언제 반영됐는지 확인할 수 없는 현재 이력은 비공개 탐색에만 쓴다. |
| 정답 | `r_s = log(P_s/P_{s-1})`, `v_{t,h} = (r²_{t+1} + ... + r²_{t+h}) / h`, `h ∈ {5, 20}`. 분산 `v`를 모델에서 비교하고, 화면용 일별 변동성은 `sqrt(v)`로 변환한다. 이는 향후 수익률의 **방향**을 맞히는 문제가 아니다. |
| 학습 가능일 | 정답 구간 종료뿐 아니라 평가 정답용 가격까지 `available_at <= 학습 시각`이어야 한다. 분할 경계를 가로지르는 정답은 훈련에서 제거한다. |
| 결측 | 거래소의 실제 세션을 대조한다. 휴장·조기 폐장·미수신을 임의로 전일 가격으로 채우지 않는다. |

이 수식의 5·20일 미래 구간은 이웃 날짜끼리 겹친다. 예를 들어 1월 2일의
20일 정답과 1월 3일의 20일 정답은 대부분 같은 수익률을 포함한다. 날짜 681개를
독립적인 실험 681번으로 해석하지 않는다.

## 비교할 모델과 추가 데이터의 순서

| 순서 | 후보 | 입력과 데이터 조건 | 질문 |
|---|---|---|---|
| 기준 | 최근 5·20일 변동성, EWMA | 당시 사용 가능한 TLT 종가 | 학습 없이 어느 정도 예측하는가? |
| 1 | GARCH(1,1) | 같은 일별 TLT 수익률, 학습 구간에서만 추정한 매개변수 | 수익률 충격의 지속성을 반영하면 기준선보다 나은가? |
| 2 | 단순 다중 기간 회귀 | TLT의 과거 1·5·20일 변동성, 필요하면 사전에 정한 손실·변환 | 현재 실패한 Ridge의 결과를 재포장하지 않고, 새 독립 자료에서 지속성 가설을 시험할 수 있는가? |
| 3 | HAR-RV | 신뢰할 수 있는 TLT 분봉과 배당·장외 시간 처리를 갖춘 실현 분산 | 더 정밀한 관측과 주별·월별 지속성이 도움이 되는가? |
| 후속 | 국면 모델·ARFIMA·XGBoost | 충분한 기간·국면·허가된 고빈도 자료, 독립 검증 | 단순한 방법을 넘어선 추가 가치가 반복되는가? |

GARCH(1,1)의 사전 지정 형태는 `σ²[t+1] = ω + α·r²[t] + β·σ²[t]`이며
`ω > 0`, `α, β >= 0`, `α + β < 1`의 제약을 둔다. 예측 시점의 조건부
분산에서 5·20거래일 뒤까지 재귀적으로 예측하고, 해당 기간의 예측 분산을
평균해 위의 `v[t,h]`와 비교한다. 모수는 훈련 구간에서만 추정한다. 이 모델도
미래의 실제 성과가 확인되기 전에는 어디까지나 **후보**다.

추가 변수는 **TLT 자체와 금리 관련 변수(예: 2년·10년 금리 변화)**부터
검토한다. MOVE 같은 금리 옵션 변동성은 사용·재배포 권리와 시점 자료가 있을
때만, VIX·브렌트유·CPI는 그다음 별도 입력 묶음으로 시험한다. 변수의 중요도나
인과효과를 논문에서 TLT로 가져왔다고 주장하지 않는다. 각 변수의 관측일,
실제 게시·수신 시각, 수정 이력, 이용권을 기록하고, 기존 모델과 **같은 예측
날짜만** 남겨 추가 전후 오차를 비교한다.

현재 1,253개 TLT 가격 행으로 2024년 이후까지 **이미 결과를 열어 보았다**.
따라서 지금 후보를 새로 골라 같은 2024~2026년을 다시 최종 시험이라고 부를 수
없다. 과거 버전이 확인되는 독립 자료나 앞으로 축적될 신규 기간이 없으면
후보 순위는 탐색으로만 보고한다. 데이터 기간·변수 수를 늘리지 않은 상태에서
딥러닝을 먼저 투입하는 결정도 보류한다.

## 모델 선정 실험 규칙

1. 자료 계약과 원본·게시 시각 검사를 먼저 통과시킨다. 현재의 Yahoo 수정종가
   한 벌은 당시 예측에 실제 사용할 수 있었던 수정가격 버전을 증명하지 못한다.
2. 모델과 5일·20일의 평가 목적을 **독립 시험을 보기 전에** 기록한다. 우선
   사용자에게 설명하기 쉬운 일별 변동성 MAE를 주 지표로, 분산 QLIKE를 보조
   지표로 둔다. 지표가 엇갈리면 두 결과를 모두 보고하고 단정하지 않는다.
3. 훈련 기간에서 모수·표준화를 추정하고, 이어지는 검증 기간에서 후보 변수와
   설정을 선택한다. 최종 연속 기간의 결과는 선택에 쓰지 않는다.
   평가일마다 재학습한다면 그날까지 정답이 확정된 행만 추가한다.
4. 같은 날짜·같은 정답·같은 수신 시점 조건에서 기준선과 후보를 대응시킨다.
   겹치는 정답의 불확실성은 짝지은 시간 블록 재표집과 비중첩 구간 수로
   보고하고, 금리 충격 등 실패 국면도 분리한다. 변수 추가에 따라 표본이
   줄면 공통 표본 비교와 결측 자체의 영향을 모두 밝힌다.
5. 각 기간별 채택은 **독립 시험에서** 기준선보다 MAE가 줄고 그 차이의
   불확실성 구간이 0 아래에 있으며, QLIKE의 짝지은 차이가 뚜렷한 악화를
   보이지 않는 경우만
   검토한다. 여러 모델을 반복 시도한 만큼 우연한 우위를 경계한다.
   이 조건은 이 프로젝트의 보수적 승인 기준이며 위 논문들이 보증한
   임계값이 아니다. 자료 권리나 시점 검사에 실패하면 성능과 관계없이
   외부 성능 표시를 보류한다.

**보조 변동성 연구의 현재 판단:** 첫 Ridge 후보는 탈락했고 EWMA를 비교
기준으로 유지한다. 이 보조 연구의 다음 구현 후보는 일별 자료로 계산 가능한
GARCH(1,1)이다. HAR-RV와 국면
모형은 필요한 자료가 확인된 뒤 별도 단계로 둔다. 이 설계는 2024년 이후
이미 관찰한 성능을 새로운 최종 검증으로 바꾸지 않는다.
