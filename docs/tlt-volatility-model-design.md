# TLT 변동성 예측 모델 설계와 논문 근거

작성일: 2026-10-20. 이 문서는 **발표 전 거시 결과 확률이 TLT 미래 변동성 예측에
추가 가치를 주는가**를 검증하는 다음 실험 설계다. 구현 완료나 성능 승인을 뜻하지
않는다. 첫 정답은 TLT의 향후 5·20거래일 실현 변동성이다. 다음 단계에서 같은 입력을
머신러닝 모델로 확장하고, 다른 ETF와 포트폴리오는 별도 자료와 기준선으로 검증한다.

## 현재 모델은 무엇인가

현재 비공개 탐색 코드는 과거 TLT 수정종가의 일별 로그수익률에서 최근 1·5·20개
수익률의 제곱평균 제곱근을 계산한다. 세 값의 로그를 입력으로 하고, 미래 5일 또는
20일의 같은 통계량의 로그를 정답으로 하는 **Ridge 선형 회귀**를 기간별로 따로
학습한다. 입력 표준화는 학습 구간에서만 하고, 절편을 제외한 계수에는 고정 패널티
10을 쓴다. 2024-01-02 이전에 미래 정답까지 끝난 예만 학습해 모델을 한 번
고정한 뒤 2024년 이후 가격과 비교했다. 이 설정은 구현 경로를 검증하는 첫
후보이지, 논문의 HAR-RV 재현이나 최종 선정된 TLT 모델이 아니다.

실제 수정종가 이력 한 벌의 탐색 비교에서는 두 기간 모두 MAE가 EWMA보다 컸다.
5일 MAE는 Ridge 0.003156, EWMA 0.002740이고 20일은 각각 0.003243,
0.001604이다. 수치는 **일별 변동성 비율의 절대오차**다. 예를 들어 0.003156은
약 0.316%p다. 5일 QLIKE만 Ridge가 낮아 지표별 판정이 다르다. 이 결과를
보고 새 특징량이나 패널티를 고르면 이미 살펴본 2024년 이후 자료는 독립적인
최종 시험이 될 수 없다. [실험 리뷰](reviews/tlt-price-only-model-review.md)에
표본 수와 블록 재표집 결과가 있다.

## 정답과 정보 시점

| 항목 | 사전 정의 |
|---|---|
| 예측 시각 | 미국 ETF 정규장 종가 **이후**, TLT 종가를 공급원에서 실제 수신한 UTC 시각. 당일 가격이 그때 없으면 예측을 늦추거나 결측 처리한다. |
| 가격 | 한 예측에 실제 수신된 **완전한 수정가격 이력 한 벌**만 사용한다. 과거 배당 조정이 언제 반영됐는지 확인할 수 없는 현재 이력은 비공개 탐색에만 쓴다. |
| 정답 | `r_s = log(P_s/P_{s-1})`, `v_{t,h} = (r²_{t+1} + ... + r²_{t+h}) / h`, `h ∈ {5, 20}`. 분산 `v`를 모델에서 비교하고, 화면용 일별 변동성은 `sqrt(v)`로 변환한다. 이는 향후 수익률의 **방향**을 맞히는 문제가 아니다. |
| 학습 가능일 | 정답 구간 종료뿐 아니라 평가 정답용 가격까지 `available_at <= 학습 시각`이어야 한다. 분할 경계를 가로지르는 정답은 훈련에서 제거한다. |
| 거시 확률 시점 | CPI/FOMC 등의 공식 `release_at`과 별도로 계약별 `observed_at`, `available_at`, `captured_at`, 계약 정의·버전을 보존한다. 발표 전 특징량은 `available_at <= prediction_at < release_at`을 만족한 원본 스냅샷에서만 만든다. 발표 후 결과·정산 확률은 과거 예측의 입력이 아니다. |
| 결측 | 거래소의 실제 세션을 대조한다. 휴장·조기 폐장·미수신을 임의로 전일 가격으로 채우지 않는다. |

이 수식의 5·20일 미래 구간은 이웃 날짜끼리 겹친다. 예를 들어 1월 2일의
20일 정답과 1월 3일의 20일 정답은 대부분 같은 수익률을 포함한다. 날짜 681개를
독립적인 실험 681번으로 해석하지 않는다.

## 확률 입력과 모델 복잡도를 분리하는 비교

| 순서 | 후보 | 입력과 데이터 조건 | 질문 |
|---|---|---|---|
| A: 기준선 | 최근 변동성·EWMA | 당시 사용 가능한 TLT 종가 | 단순 관성이 어느 정도 맞는가? |
| B: 전통 정보 | 가격 이력, 사전 공개된 금리·VIX, 거시 일정·기존 기대값의 소수 변수로 규제 회귀 | 가격과 전통 정보만으로 어느 정도 개선하는가? |
| C: 확률 추가 | **B와 같은 모형·평가 날짜·학습 규칙**에 발표 전 Kalshi 거시 확률 특징만 추가 | `C−B`의 짝지은 손실 차이가 확률 정보의 추가 가치인가? |
| D: 머신러닝 | **C와 같은 입력·날짜**의 작은 트리 앙상블 등 | `D−C`가 비선형 모형의 추가 가치인가? |

`C−B`는 오차가 줄어들면 음수다. A도 **C가 가능한 공통 날짜**에서 다시
채점한다. 확률 스냅샷이 없는 날을 `0%`로 대체하지 않는다. 다음 발표가 없는
날에는 발표까지 남은 시간·결측 상태를 따로 표시하고, 사전에 정한 이벤트 창과
전체 일별 패널을 각각 보고한다. 계약 임계값 하나를 완전한 CPI 분포라고 부르지
않는다. 유효한 경우에만 결과 구간별 확률·분포의 퍼짐/극단 확률·변화량과 호가
스프레드/거래량·스냅샷 지연을 특징량 후보로 사전 등록한다. 다수 계약의 결과 구간
정의와 합이 일관되는지 검사한다. 금리와 VIX의 공개 시각도 같은 규칙을 따른다.

GARCH(1,1)은 가격만 쓰는 별도 통계 기준선 후보로 남기고, HAR-RV는 신뢰할 만한
분봉 자료가 생긴 뒤 비교한다. 이 후보의 성능이 확률 정보의 가치를 대신 증명하지
않는다. 사전 공개된 브렌트유, 실질금리·기대인플레이션과 MOVE는 이용권과
공통 날짜를 확인한 뒤 B/C/D의 동일 입력 계약에 단계적으로 넣을 수 있다. 실제
CPI 수치와 예상 밖 충격은 **발표 이후**에만 이후 예측에서 사용한다. 변수 중요도는
인과효과가 아니다.

현재 1,253개 TLT 가격 행으로 2024년 이후까지 **이미 결과를 열어 보았다**.
따라서 지금 후보를 새로 골라 같은 2024~2026년을 다시 최종 시험이라고 부를 수
없다. 과거 버전이 확인되는 독립 자료나 앞으로 축적될 신규 기간이 없으면
후보 순위는 탐색으로만 보고한다. 기존 CPI 계약 감사의 비교 가능 발표 24회는
TLT 확률 결합의 표본 수가 아니며, 1,253개 가격 행도 독립된 1,253개 거시
사건이 아니다. 먼저 실제 확률·가격의 공통 표본과 발표 횟수를 세고, 독립
기간이 부족하면 딥러닝을 보류한다.

## 모델 선정 실험 규칙

1. 자료 계약과 원본·게시 시각 검사를 먼저 통과시킨다. 현재의 Yahoo 수정종가
   한 벌은 당시 예측에 실제 사용할 수 있었던 수정가격 버전을 증명하지 못한다.
2. A/B/C/D와 5일·20일의 평가 목적을 **독립 시험을 보기 전에** 기록한다. 우선
   사용자에게 설명하기 쉬운 일별 변동성 MAE를 주 지표로, 분산 QLIKE를 보조
   지표로 둔다. 지표가 엇갈리면 두 결과를 모두 보고하고 단정하지 않는다.
3. 훈련 기간에서 모수·표준화를 추정하고, 이어지는 검증 기간에서 후보 변수와
   설정을 선택한다. 최종 연속 기간의 결과는 선택에 쓰지 않는다.
   평가일마다 재학습한다면 그날까지 정답이 확정된 행만 추가한다.
4. 같은 날짜·같은 정답·같은 수신 시점 조건에서 A/B/C/D를 대응시킨다.
   겹치는 정답의 불확실성은 짝지은 시간 블록 재표집과 비중첩 구간 수로
   보고하고, 동일 발표의 여러 계약·날짜가 분할을 가로지르지 않게 한다. 금리
   충격 등 실패 국면도 분리한다. 변수 추가에 따라 표본이
   줄면 공통 표본 비교와 결측 자체의 영향을 모두 밝힌다.
5. 확률 특징의 채택은 **독립 시험에서** C가 B와 A보다 MAE를 줄이고 그 짝지은
   차이의 불확실성 구간이 0 아래에 있으며, QLIKE가 뚜렷하게 악화하지 않을 때만
   검토한다. D는 C와 동일 입력에서 별도 비교한다. 단일 평가에서 차이가
   통계적으로 불명확하면 개선을 주장하지 않는다. 여러 모델을 반복 시도한 만큼
   우연한 우위를 경계한다. 이 기준은 프로젝트의 보수적 승인 규칙이다.
   자료 권리나 시점 검사에 실패하면 성능과 관계없이 외부 성능 표시를 보류한다.

**현재 판단:** 가격만 쓴 첫 Ridge 후보는 EWMA보다 MAE가 커 탈락했다.
이 실패는 발표 전 확률의 추가 가치를 시험한 결과가 아니다. 다음 구현은
확률 스냅샷과 TLT 가격·전통 정보의 **공통 날짜 및 시점 계약 확인**이다.
이후 A/B/C, 표본이 허용하면 D를 평가한다. 이 설계는 이미 살펴본 2024년
이후 성능을 새로운 최종 검증으로 바꾸지 않는다.
