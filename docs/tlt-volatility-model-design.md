# TLT 변동성 예측 모델 설계와 논문 근거

개정일: 2026-10-23. 이 문서는 **가격 기준선 A와 전통 정보 모델 B의 TLT 미래
변동성 예측력**을 검증하는 설계다. 구현 완료나 성능 승인을 뜻하지 않는다.
첫 정답은 TLT의 향후 5·20거래일 실현 변동성이다. 독립 표본이 충분하면 B의
입력을 머신러닝 모델로 확장한다. Kalshi 계약 확률은 별도 사건 맥락이고 기존
C 입력 경로는 선택적 연구로 보존한다. 다른 ETF와 포트폴리오는 별도 검증한다.

## 현재 모델은 무엇인가

이 연구의 목표는 단순 가격 규칙을 완성품으로 선택하는 것이 아니라 **기존 통계
모형 대비 전통 시장 정보와 후속 머신러닝이 미래 변동성 예측을 개선하는지**
구별하는 것이다. A의 최근 변동성·EWMA는 최소 기준이고, 일별 가격으로
GARCH(1,1)을 추가해 통계 기준선의 범위를 넓혔다. 가격만 쓴 Ridge(B0)와
가격·전통 지표 Ridge(B1)는 같은 구조·날짜·정답을 사용해 **전통 정보 추가
효과**를 분리한다. B0/B1의 패널티 10은 탐색용 고정값이며 논문에서 도출된
최적값이 아니다. 시점별 보관 자료의 A/B 비교는 합성 자료로 계산을 검증했다.
별도로 현재 수정종가 한 벌에 대한 Ridge·GARCH 탐색 평가를 수행했으며,
과거 시점별 가격 버전과 독립 시험이 없는 실증 성능으로 승인하지 않았다.

현재 비공개 탐색 코드는 과거 TLT 수정종가의 일별 로그수익률에서 최근 1·5·20개
수익률의 제곱평균 제곱근을 계산한다. 세 값의 로그를 입력으로 하고, 미래 5일 또는
20일의 같은 통계량의 로그를 정답으로 하는 **Ridge 선형 회귀**를 기간별로 따로
학습한다. 입력 표준화는 학습 구간에서만 하고, 절편을 제외한 계수에는 고정 패널티
10을 쓴다. 2024-01-02 이전에 미래 정답까지 끝난 예만 학습해 모델을 한 번
고정한 뒤 2024년 이후 가격과 비교했다. 이 설정은 구현 경로를 검증하는 첫
후보이지, 논문의 HAR-RV 재현이나 최종 선정된 TLT 모델이 아니다.

실제 수정종가 이력 한 벌의 탐색 비교에서는 두 기간 모두 MAE가 EWMA보다 컸다.
5일 MAE는 Ridge 0.003156, EWMA 0.002740이고 20일은 각각 0.003243,
0.001604이다. 수치는 **일별 변동성 비율의 절대오차**다. 예를 들어 0.003156은
약 0.316%p다. 5일 QLIKE만 Ridge가 낮아 지표별 판정이 다르다. 이 결과를
보고 새 특징량이나 패널티를 고르면 이미 살펴본 2024년 이후 자료는 독립적인
최종 시험이 될 수 없다. [실험 리뷰](reviews/tlt-price-only-model-review.md)에
표본 수와 블록 재표집 결과가 있다.

같은 현재 수정종가에서 2024-01-02 이전 551개 일별 수익률로 GARCH(1,1)의
모수를 한 번 맞췄다. 이후 날짜의 수익률은 해당 예측 시점까지 분산 갱신에만
사용하고 모수를 재학습하지 않았다. 5일 MAE는 GARCH 0.003962, EWMA
0.002740이며, 20일은 각각 0.003512, 0.001604다. 5일 QLIKE에서는 GARCH가
더 낮았지만 20일 QLIKE와 두 기간의 주 지표 MAE에서는 EWMA가 낮았다.
따라서 이 **Yahoo 입력·기간에서** GARCH를 채택하지 않는다. 그래프와 날짜 일치 검사, 두 지표를 모두
보고한 [GARCH 탐색 시각화 리뷰](reviews/tlt-exploratory-garch-visual-review.md)를
참조한다. 이것도 이미 관찰한 2024년 이후 가격 한 벌의 비공개 탐색 결과다.
별도의 Alpaca SIP 현재 조정 이력(2024-01-02~2026-10-21)의 2026년
탐색에서는 TLT 20일 GARCH와 SPY 20일 Ridge 등의 MAE가 EWMA보다
낮았다. [종목별 가격 비교](reviews/alpaca-price-only-comparison-review.md)와
[겹침 진단](reviews/overlap-diagnostics-review.md)을 참고한다. 공급원·훈련·시험
기간이 다르고 둘 다 과거 시점별 가격 버전이 없는 현재 이력 재계산이므로
두 결과로 전체 후보의 승패를 정하지 않는다.

## 정답과 정보 시점

| 항목 | 사전 정의 |
|---|---|
| 예측 시각 | 미국 ETF 정규장 종가 **이후**, TLT 종가를 공급원에서 실제 수신한 UTC 시각. 당일 가격이 그때 없으면 예측을 늦추거나 결측 처리한다. |
| 가격 | 한 예측에 실제 수신된 **완전한 수정가격 이력 한 벌**만 사용한다. 과거 배당 조정이 언제 반영됐는지 확인할 수 없는 현재 이력은 비공개 탐색에만 쓴다. |
| 정답 | `r_s = log(P_s/P_{s-1})`, `v_{t,h} = (r²_{t+1} + ... + r²_{t+h}) / h`, `h ∈ {5, 20}`. 분산 `v`를 모델에서 비교하고, 화면용 일별 변동성은 `sqrt(v)`로 변환한다. 이는 향후 수익률의 **방향**을 맞히는 문제가 아니다. |
| 학습 가능일 | 정답 구간 종료뿐 아니라 평가 정답용 가격까지 `available_at <= 학습 시각`이어야 한다. 분할 경계를 가로지르는 정답은 훈련에서 제거한다. |
| Kalshi 사건 맥락 | CPI/FOMC 등의 공식 `release_at`과 별도로 계약별 `observed_at`, `available_at`, `captured_at`, 계약 질문·임계값·버전·호가 품질을 보존한다. 발표 전 설명에는 `available_at <= 관측 기준시각 < release_at`인 원본 스냅샷만 쓴다. 발표 후 결과·정산 확률은 당시 기대가 아니다. |
| 결측 | 거래소의 실제 세션을 대조한다. 휴장·조기 폐장·미수신을 임의로 전일 가격으로 채우지 않는다. |

이 수식의 5·20일 미래 구간은 이웃 날짜끼리 겹친다. 예를 들어 1월 2일의
20일 정답과 1월 3일의 20일 정답은 대부분 같은 수익률을 포함한다. 날짜 681개를
독립적인 실험 681번으로 해석하지 않는다.

## 첫 모델 비교와 선택적 연구

| 순서 | 후보 | 입력과 데이터 조건 | 질문 |
|---|---|---|---|
| A0: 단순 가격 기준선 | 최근 변동성·EWMA | 당시 사용 가능한 TLT 종가 | 단순 관성이 어느 정도 맞는가? |
| A1: 통계 기준선 | GARCH(1,1), 나중에 고빈도 자료가 있을 때 HAR-RV | 일별 TLT 종가. HAR-RV는 분봉 기반 실현 변동성 필요 | 확립된 통계 모형 대비 개선하는가? |
| B0: 동일 모형 대조군 | Ridge에 가격 변동성 두 항만 입력 | B1과 **동일한 공통 학습·평가 날짜**, 정답, 패널티 | 같은 모형에서 가격만으로 무엇을 설명하는가? |
| B1: 전통 정보 | B0에 당시 이용 가능한 금리 등 지표 수준을 추가하는 Ridge | B0과 같은 조건의 공통 패널; 거시 일정·기대값은 현재 미구현 | **B1−B0**가 전통 지표의 추가 가치인가? |
| 선택적 ML | 같은 입력·날짜의 작은 트리 모형, 이후 표본·자료 권리가 허용할 때 작은 시계열 신경망 | 가격만/B1 각각에서 정보 추가 효과와 복잡도 증가 효과가 다른가? [단계 검토](reviews/modern-risk-model-research-stage-review.md) |
| 보존된 C 연구 | 별도 승인 후 **B와 같은 모형·평가 날짜·학습 규칙**에 발표 전 계약 확률 특징만 추가 | 새 독립 표본에서 `C−B`의 짝지은 손실 차이가 확률 정보의 추가 가치인가? |

A/B는 **가격과 전통 지표를 이용할 수 있는 공통 날짜**에서 먼저 채점한다.
Kalshi 확률을 확보하지 못한 날짜를 A/B의 학습·시험에서 제외할 이유는 없다.
사건 설명에서는 하나의 임계값 계약을 완전한 CPI 분포나 전체 시장의 합의라고
부르지 않는다. 계약 문구·임계값, 당시에 관측·이용 가능한 확률, 시각과
스프레드·거래량·지연·출처를 함께 기록하고 표시 권리를 확인한다. 향후 C를
별도 연구한다면 `C−B`는 오차가 줄어들 때 음수이며, A/B/C를 **C가 가능한
공통 날짜**에서 다시 비교한다. 확률 결측을 `0%`로 대체하지 않고, 연구용
특징량 정의와 모델 비교를 새로운 독립 시험 전에 등록한다.

GARCH(1,1)은 조건부 평균 0을 고정하고 `h_t = ω + αr²_(t−1) + βh_(t−1)`를
가우시안 준최대우도로 추정한다. `ω>0`, `α,β>=0`, `α+β<1`이며,
추정에 쓰는 수익률은 홀드아웃 시작 **이전** 자료만 남긴다. 평가일에는 그날
예측 시각까지 존재한 전체 가격 스냅샷 하나로 모형 상태만 갱신한다. 미래
잔차는 알 수 없으므로 두 번째 날부터는 `E[h_(t+k)] = ω+(α+β)E[h_(t+k−1)]`로
전개한다. 5·20일 예상 분산을 평균한 뒤 제곱근을 취해 프로젝트의 정답과
단위를 맞춘다. 기본 100개 이상의 과거 수익률이 없거나 최적화에 실패하면
GARCH 점수만 보류한다. HAR-RV는 신뢰할 만한 분봉 자료가 생긴 뒤 비교한다.
이 후보의 성능이 확률 정보의 가치를 대신 증명하지
않는다. 사전 공개된 브렌트유, 실질금리·기대인플레이션과 MOVE는 이용권과
공통 날짜를 확인한 뒤 B와 선택적 ML의 동일 입력 계약에 단계적으로 넣을 수 있다. 실제
CPI 수치와 예상 밖 충격은 **발표 이후**에만 이후 예측에서 사용한다. 변수 중요도는
인과효과가 아니다.

현재 1,253개 TLT 가격 행으로 2024년 이후까지 **이미 결과를 열어 보았다**.
따라서 지금 후보를 새로 골라 같은 2024~2026년을 다시 최종 시험이라고 부를 수
없다. 과거 버전이 확인되는 독립 자료나 앞으로 축적될 신규 기간이 없으면
후보 순위는 탐색으로만 보고한다. 기존 CPI 계약 감사의 비교 가능 발표 24회는
TLT 확률 결합의 표본 수가 아니며, 1,253개 가격 행도 독립된 1,253개 거시
사건이 아니다. 먼저 실제 가격·전통 지표의 공통 표본을 세고, 독립 기간이
부족하면 딥러닝을 보류한다. Kalshi 공통 사건 수는 C 연구를 별도 재개할 때만 센다.

## 모델 선정 실험 규칙

1. 자료 계약과 원본·게시 시각 검사를 먼저 통과시킨다. 현재의 Yahoo 수정종가
   한 벌은 당시 예측에 실제 사용할 수 있었던 수정가격 버전을 증명하지 못한다.
2. A/B와 5일·20일의 평가 목적을 **독립 시험을 보기 전에** 기록한다. 우선
   사용자에게 설명하기 쉬운 일별 변동성 MAE를 주 지표로, 분산 QLIKE를 보조
   지표로 둔다. 지표가 엇갈리면 두 결과를 모두 보고하고 단정하지 않는다.
3. 훈련 기간에서 모수·표준화를 추정하고, 이어지는 검증 기간에서 후보 변수와
   설정을 선택한다. 최종 연속 기간의 결과는 선택에 쓰지 않는다.
   평가일마다 재학습한다면 그날까지 정답이 확정된 행만 추가한다.
4. 같은 날짜·같은 정답·같은 수신 시점 조건에서 A0/A1/B0/B1을 대응시킨다.
   B1과 B0의 차이는 **동일한 모델 방식에서 지표 입력만 추가한 효과**로,
   B1과 A0/A1의 차이는 서로 다른 모형 전체의 예측력 비교로 따로 해석한다.
   겹치는 정답의 불확실성은 짝지은 시간 블록 재표집과 비중첩 구간 수로
   보고하고, 거시 발표를 사용하는 경우 동일 발표의 여러 날짜가 분할을
   가로지르지 않게 한다. 금리 충격 등 실패 국면도 분리한다. 변수 추가에 따라 표본이
   줄면 공통 표본 비교와 결측 자체의 영향을 모두 밝힌다.
5. B의 채택은 **독립 시험에서** A보다 실용적으로 MAE를 줄이고 짝지은 차이의
   불확실성, QLIKE, 실패 국면을 함께 살펴 결정한다. 선택적 ML도 B와 동일 입력·
   날짜에서만 비교한다. 단일 평가에서 차이가 불명확하면 개선을 주장하지
   않는다. 자료 권리나 시점 검사에 실패하면 외부 성능 표시를 보류한다.

이 기준은 **첫 제품의 A/B 판정 조건**이다. A는 개선 주장이 아닌 오차·국면별
안정성과 사용자 효용으로 별도 평가한다. Kalshi 확률을 위험 모델에 넣는 C
연구를 후일 재개한다면 별도 사전 등록·실제 공통 표본·새 독립 시험과 B 대비
증분 검증이 필요하며 첫 제품의 성과로 옮겨 쓰지 않는다. 모델별 표시 결정은
[성과별 제품 경로](product-goal-and-fallback.md)를 따른다.

**현재 판단:** 이전 Yahoo TLT 탐색에서는 Ridge·GARCH의 MAE가 EWMA보다
컸지만, 이후 Alpaca SIP의 다른 기간 탐색에서는 일부 가격 후보의 MAE가
더 낮았다. 둘 다 시점별 독립 성능 평가가 아니므로 모델 채택·탈락을
확정하지 않는다. 어떤 가격 탐색도 B나 발표 전 확률의 추가 가치를
시험한 결과가 아니다. 보관 가격
스냅샷에 전통 정보와 발표 전 단일 계약 확률을 연결하는 시점 계약은 합성
자료로 구현했다. 합성 보관 자료 비교기는 훈련 정답을 홀드아웃 시작 시점의
가격 빈티지에서 계산하고, 같은 시험 날짜의 A0/A1/B0/B1을 평가한다.
GARCH가 100개 수익률에 못 미치는 합성 시험에서는 그 점수를 보류한다. 다음 단계는
실제 가격·전통 지표의 **공통 날짜·권리 확인**과
A/B의 독립 평가이며, 표본이 허용하면 같은 입력의 ML을 평가한다. Kalshi는
계약별 기대를 별도 설명하기 위한 권리·시각·호가 품질을 확인한다. 이 설계는 이미 살펴본 2024년
이후 성능을 새로운 최종 검증으로 바꾸지 않는다.
