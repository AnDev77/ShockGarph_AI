# CPI·미국 ETF 데이터 커버리지 점검

점검일: 2026-09-26

## 이번 실행 결과

공식 호환 운영 URL을 사용한 Kalshi 공개 GET과 전체 CPI 감사를 실행했다. 기본 운영
URL은 HTTP 403 또는 시간 초과가 있었고 호환 URL도 한 차례 일시적으로 시간 초과됐지만,
재시도한 전체 실행은 접근 오류 없이 완료됐다.

| 자료 | 확인 결과 | 현재 판단 |
|---|---|---|
| Kalshi KXCPI 시장 | 과거 483개, 현재 69개 시장 레코드 조회 | 기술적 접근 가능 |
| 고정 임계값 `T0.3` | 결과 확정 이벤트 55개 | 동일 이진 질문의 시간순 평가 가능 |
| 계약 종료 직전 1분 확률 | 29개 품질 통과, 6개 오래된 호가, 20개 유효 캔들 없음 | 결측을 보고한 제한적 평가 가능 |
| Kalshi 확률 Brier | 비교 가능한 24개에서 0.1005 | 누적 과거비율 0.2339보다 낮음 |
| SPY·TLT·GLD | `ALPHA_VANTAGE_API_KEY` 미설정 | 실가격 연결 미실행 |
| 거시 자료 | `FRED_API_KEY` 미설정 | 기대값·빈티지 연결 미실행 |
| CPI 확률·ETF 가격 공통 표본 | 아직 없음 | 자산 반응 모델 학습 전 단계 |

사건별 Brier 차이 `시장확률 − 누적 과거비율`의 평균은 -0.1334이고, paired bootstrap
95% 구간은 [-0.1888, -0.0847]이었다. 이는 선택된 24개 사건에서 `T0.3` 정산 결과를
구분한 결과다. SPY·TLT·GLD 수익률 예측력이나 인과효과를 뜻하지 않는다.

## 품질 규칙

- 결과가 `yes` 또는 `no`로 확정된 `T0.3` 계약만 사용한다.
- 계약 거래 종료시각 이후 캔들은 제외한다.
- 거래량이 양수이고 YES 매수·매도 가격이 0~1 범위이며 역전되지 않아야 한다.
- 스프레드는 0.10 이하여야 한다.
- 가장 최근 유효 캔들이 거래 종료 전 15분 안에 있어야 한다.
- 조건을 통과하지 못한 26개 사건의 확률을 보간하거나 결과값으로 대체하지 않는다.
- 단순 기준 모델은 현재 사건보다 앞선 정산 결과만 사용한다.

과거 계약의 거래 종료시각은 BLS 발표 5분 전으로 일정하지 않다. 이 단계는 Kalshi 계약의
거래 가능한 마지막 확률을 평가한다. 자산 반응 연구에서는 각 월의 실제 BLS 발표시각을
별도로 연결해야 한다.

## 재현

```bash
python scripts/probe_cpi_coverage.py --max-pages 2
python scripts/audit_kalshi_cpi.py --request-interval 0.3
```

전체 감사는 원본 응답을 해시 기반 불변 저장소에 보관하고, 품질 결과와 점수를 별도
내용 해시 보고서로 만든다. `artifacts/`는 Git 추적 대상이 아니다.

## 다음 데이터 연결 순서

1. BLS 최초 발표치·발표시각·당시 시장 기대값을 월별 이벤트와 결합한다.
2. 이용권이 확인된 공급원에서 SPY·TLT·GLD 장전 또는 분봉 가격을 확보한다.
3. 발표 직후 5분·30분과 정규장 구간의 수익률을 사건 단위로 만든다.
4. 55개 전체와 확률 품질 통과 29개의 차이를 보고해 선택 편향을 점검한다.
5. 과거비율·전통적 CPI surprise·시장확률 모델을 같은 표본 외 사건에서 비교한다.

[데이터 가용성 검토](data-feasibility.md), 자산 공급원 조건은
