# 모델 설명서

상태: 초기 1일차에는 학습한 모델이 없었다. 현재 일별 위험에는 TLT의 현재
수정종가 이력 한 벌에서 가격만 사용해 한 번 학습한 **비공개 탐색 모델**이 있다.
이 모델은 2024년 이후 5·20일 비교에서 EWMA보다 평균 절대오차가 컸고,
과거 가격 버전의 공개 시점도 확인되지 않아 제품 예측으로 승인하지 않았다.
이 결과는 거시 확률을 입력으로 사용한 모델의 실험 결과가 아니다. 발표 전 확률을
추가하는 규제 모형과 동일 입력의 머신러닝은 아직 학습·평가하지 않았다.
기존 CPI/Kalshi 이벤트 연구에는 시장확률을 그대로 사용하는 기준 모델과 평가
함수가 있고, 이벤트 단위 예측 모델은 아직 없다.

일별 TLT의 발표 전 확률 추가 효과·머신러닝 추가 효과 비교와 독립 시험 조건은
[TLT 변동성 예측 모델 설계](tlt-volatility-model-design.md)에 있다.

첫 학습 후보는 이벤트 단위 시간순 분할을 사용하는 로지스틱 확률 보정 모델이다.
시장확률을 그대로 사용하는 기준 모델과 반드시 비교한다.
고정된 시험 데이터 분할에서 Brier 점수, 로그 손실, 기대 보정 오차,
분류별 결과, 표본 수, 신뢰구간을 보고하기 전에는 성능을 주장하지 않는다.
