# 모델 설명서

상태: 2026-10-21. 현재 TLT 수정종가 이력 한 벌의 가격 전용 Ridge는
**비공개 탐색**에서 2024년 이후 5·20일 모두 EWMA보다 평균 절대오차가 컸다.
별도의 보관 가격·합성 지표 패널에서는 최근 변동성·EWMA, 가격 전용
GARCH(1,1), 동일 Ridge의 가격 전용 B0와 지표 추가 B1의 누수 방지·
동일 날짜 채점을 시험했다. 이 합성 시험은 실제 TLT와 금리의 성능이 아니다.
과거 가격 버전과 지표의 실제 게시 시각·이용권이 확인되지 않아 어떤 모델도
제품 예측으로 승인하지 않았다. 실제 지표 추가 B1−B0와 B1−A의
표본 외 결과는 없다. 발표 전 확률을 추가하는 규제 모형과 같은 입력의
머신러닝도 아직 학습·평가하지 않았다.
기존 CPI/Kalshi 이벤트 연구에는 시장확률을 그대로 사용하는 기준 모델과 평가
함수가 있고, 이벤트 단위 예측 모델은 아직 없다.

일별 TLT의 전통 지표 추가 효과·선택적 확률 연구·머신러닝 비교와 독립 시험 조건은
[TLT 변동성 예측 모델 설계](tlt-volatility-model-design.md)에 있다.

다음 내용은 첫 제품의 TLT 위험 모델과 별개인 **기존 CPI 확률 연구 계획**이다.
이벤트 단위 시간순 분할을 사용하는 로지스틱 확률 보정 모델을 연구한다면
시장확률을 그대로 사용하는 기준 모델과 반드시 비교한다.
고정된 시험 데이터 분할에서 Brier 점수, 로그 손실, 기대 보정 오차,
분류별 결과, 표본 수, 신뢰구간을 보고하기 전에는 성능을 주장하지 않는다.
