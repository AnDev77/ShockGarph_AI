# 사전 분석 계획

## 분석 순서

분석은 두 단계로 나눈다. 1단계가 실패해도 결과를 숨기지 않고 2단계의 해석 범위를 낮춘다.

### 1단계: 이벤트 확률 검증

결과 $y_t \in \{0,1\}$와 발표 전 시장확률 $p_t$에 대해

$$
BS_t = (p_t-y_t)^2
$$

를 계산한다. 기준 확률은 사건 $t$ 이전에 정산된 결과만 이용한 누적 YES 비율이다.
최소 과거 10개 이후 같은 사건의 손실 차이
$d_t=BS_{market,t}-BS_{history,t}$를 보고한다.

주 지표는 평균 Brier 차이와 사건 단위 paired bootstrap 95% 구간이다. 월별 시계열
의존성에 대비해 비교 사건이 30개 이상이 되면 길이 3의 이동 블록 bootstrap을 강건성
분석으로 추가한다. 현재 24개 결과는 예비 결과로 표시한다.

### 2단계: 자산 반응의 증분 예측력

모든 모델은 같은 학습 구간과 같은 평가 사건을 사용한다.

| 모델 | 입력 |
|---|---|
| A 가격 기준 | 과거 수익률, 최근 실현변동성, 자산·월 효과 |
| B 전통 정보 | A + 발표 전 CPI 기대, 금리·달러 상태 등 사전에 이용 가능했던 변수 |
| C 예측시장 | B + Kalshi 원시확률, 스프레드, 확률 변화량 |
| D 보정 확률 | C의 확률을 학습 구간에서만 보정한 후보 |

주 비교는 C−B다. D−C는 확률 보정의 추가 가치를 보는 보조 비교다. 표본이 작으면
복잡한 트리 모델을 만들지 않고 규제 선형 모델과 경험적 조건부 분포를 사용한다.

## 평가 지표

| 우선순위 | 지표 | 해석 |
|---|---|---|
| 주요 | CRPS | 전체 예측분포와 실현 수익률의 거리 |
| 보조 1 | 상승확률 Brier | 방향확률의 정확성 |
| 보조 2 | 5% pinball loss | 하방 분위수의 정확성 |
| 보조 3 | 90% 구간 포함률·폭 | 보정과 날카로움의 균형 |
| 탐색 | 평균오차·절대오차 | 점예측 참고치 |

같은 사건의 손실 차이를 우선 보고한다. 자산 3개와 여러 보조 구간의 검정은 Holm 방식으로
보정하되, 효과크기와 불확실성을 p값보다 먼저 제시한다.

## 시간순 검증

1. 사건을 `release_at` 순서로 정렬한다.
2. 첫 20개 이상을 초기 학습으로 사용한다.
3. 각 시험 사건마다 당시 이용 가능한 결과만으로 다시 학습한다.
4. 정규화·특징 선택·확률 보정도 해당 학습 구간 안에서만 수행한다.
5. 같은 CPI 발표의 세 자산과 여러 구간을 서로 다른 데이터 분할에 넣지 않는다.
6. 최종 시험 사건을 확인한 뒤 모델이나 품질 기준을 바꾸지 않는다.

## 사전 고정 강건성 분석

| 항목 | 기본값 | 강건성 범위 |
|---|---|---|
| 호가 신선도 | 15분 | 5분, 30분 |
| 최대 스프레드 | 0.10 | 0.05, 0.15 |
| 시장확률 | 매수·매도 중간값 | 매수·매도 경계에서 결과 범위 보고 |
| 최소 과거 사건 | 10 | 5, 15 |
| 주요 가격 구간 | 08:29→09:00 ET | 5분, 개장, 당일 종가 |
| 특수 국면 | 전체 | 2020~2021 제외, 긴축기 분리 |

강건성 결과가 기본 결과와 방향이 다르면 기본 결과만 강조하지 않는다. 기준을 결과에 맞게
고른 경우에는 확인적 결과가 아니라 사후 탐색으로 표시한다.

## 표본 흐름과 결측

논문 첫 그림은 다음 흐름을 포함한다.

1. 결과 확정 `T0.3`: 55개
2. 확률 품질 통과: 29개
3. Brier 기준 비교 가능: 24개
4. BLS 최초 발표값 결합: 추후 기록
5. 세 ETF 공통 가격 결합: 추후 기록
6. 최종 표본 외 평가: 추후 기록

포함 사건과 제외 사건의 연도, 정산 결과, 시장 거래량을 비교한다. 제외가 무작위라고
가정하지 않으며, 가능하면 포함 여부를 종속변수로 한 단순 진단을 부록에 둔다.

## 중단·하향 기준

- ETF 공통 시험 사건이 10개 미만이면 확인적 성능 주장을 중단한다.
- 장전 가격의 시작·종료 정의가 사건마다 일치하지 않으면 고빈도 분석을 중단한다.
- BLS 최초 발표 빈티지와 계약 정산 정의를 매핑하지 못하면 surprise 분석을 중단한다.
- 데이터 이용조건이 논문 공유를 허용하지 않으면 원시 자료는 공유하지 않고 코드·해시·집계만 제공한다.
- C−B의 개선이 없으면 이를 그대로 보고하고 설명·시나리오 도구의 제품 가치와 분리한다.

## 결과표 틀

### 표 1. 데이터 커버리지

연도별 전체 사건, 유효 확률, BLS 결합, 자산별 가격 결합, 최종 공통 표본을 보고한다.

### 표 2. 확률 정확도

시장확률과 누적 과거비율의 Brier, 차이, 신뢰구간을 전체·기간별로 보고한다.

### 표 3. 자산 분포 예측

자산별 A/B/C/D의 CRPS와 C−B 차이를 같은 시험 사건에서 보고한다.

### 표 4. 하방위험과 보정

5% pinball loss, 90% 포함률·폭, 실패 사건을 보고한다.

### 부록 표

품질 기준 민감도, 가격 구간 민감도, 동시 발표 제외, 특수 국면 제외를 보고한다.
