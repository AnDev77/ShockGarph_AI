# Kalshi 데이터 확대와 민감도 분석 전략

작성일: 2026-10-01 (한국 시각)

## 목표와 작업 범위

목표는 같은 사건에서 기존 정보에 Kalshi 확률을 추가했을 때 자산 반응 예측이
개선되는지 검증하는 것이다. 현재 구현은 과거 발생비율과 Kalshi 확률을 비교하는
예비 실험이다. 전통 거시정보 기준선과의 비교를 완성한 것으로 해석하지 않는다.
곡률 특징은 보류한다. DNN 구간 학습은 아래 조건을 갖춘 뒤 수행할 후속 실험이다.

2026-10-01 후속 구현에서 분봉의 구조·시각·호가·스프레드·거래량 실패 사유를
분리하고 F0~F4를 같은 원본 후보에 적용하는 집계 파이프라인을 추가했다. 이 변경은
기존 기준 F0를 대체하지 않는다. 실제 결과는 GitHub Actions의 새 집계가 성공한 뒤
별도 리뷰에 기록하며, 결과를 보고 임계값을 다시 선택하지 않는다.

## 현재 표본과 먼저 확인할 사항

2026-09-30 Actions `36787052115`의 53개 BLS 사건에서 Kalshi 품질 미통과는
`no_eligible_candles` 19건과 계약 종료시각 기준 `stale` 5건이다.
통과한 29건 중 TLT 시작 가격 결측 2건과 실제 발표 기준 신선도 탈락 3건을 제외한
최종 공통 사건은 24건이다. 추가 신선도 탈락은 발표 16분 전 2건, 20분 전 1건이다.
계약 종료시각과 BLS 발표시각을 혼용하지 않는다.

먼저 19건을 빈 응답, 시각 부적합, 호가 누락·비정상, 스프레드 초과, 거래량 누락·0 등으로
분해한다. 사건별 주된 제외 사유와 분봉별 복수 실패 사유를 별도로 집계해 중복 계산을 막는다.
거래량 누락과 0은 구분한다. 조회 구간에서 유효 분봉을 찾지 못한 사실을 시장 전체에
관측값이 존재하지 않는다는 뜻으로 해석하지 않는다.

## 1차: 원본 재확보

1. 실제 BLS 발표시각을 기준으로 조회 구간·시장 식별자·페이지 누락과 과거/현재
   엔드포인트 선택을 감사한다. 같은 원본에서 기준별 적격 관측을 다시 선택한다.
2. 과거 자료는 API가 지원하는 해상도와 보관 범위 안에서 누락을 복구한다.
   같은 1분봉 API를 더 자주 호출해도 과거에 없던 틱이나 분봉이 생성되지는 않는다.
3. 향후 사건은 발표 이전 여러 시점에 호가와 거래량을 수집한다. 호출 제한을 준수하고
   시장 시각·수신 시각·원본 해시를 저장한다. 신규 계약 결과 확정 뒤 같은 평가에 편입한다.
4. TLT 시작 가격은 동일 피드·동일 가격 정의로 복구를 시도한다. 더 오래된 가격을
   사용하거나 보간하는 방안은 가격창 민감도 분석으로 따로 정의한다.

복구 후에도 원본 스냅샷과 기존 결과를 보존한다. 코드 버전·입력 해시·필터 버전으로
실험을 식별하고 재수집으로 바뀐 표본과 정책 변경으로 바뀐 표본을 구분한다.

## 2차: 사전 고정 필터 민감도 분석

모든 후보는 실제 발표 전 관측만 사용한다. 각 후보 안에서는 조건을 만족하는 가장
최근 호가를 선택하며 자산·수익률 정의·모델 구조·학습 기준은 고정한다.
아래 다섯 후보를 1차 실험으로 고정한다. 전체 조합 탐색은 추가 사후 탐색으로 표기한다.

| 후보 | 발표 전 관측 나이 | 최대 스프레드 | 거래량 조건 | 목적 |
| --- | --- | --- | --- | --- |
| F0 기준 | 15분 이내 | 0.10 | 양수 | 현재 기준 유지 |
| F1 시간 | 30분 이내 | 0.10 | 양수 | 신선도 조건만 변경 |
| F2 호가 | 15분 이내 | 0.15 | 양수 | 스프레드 조건만 변경 |
| F3 거래 | 15분 이내 | 0.10 | 양수 요구 해제 | 거래 활동 조건만 변경 |
| F4 결합 | 30분 이내 | 0.15 | 양수 요구 해제 | 사용자 제안 완화안 |

F3·F4는 유효 호가가 있을 때 거래량 0 또는 누락을 허용하되 각각 표시한다.
음수·비유한 등 잘못된 거래량은 정상 관측으로 취급하지 않는다.
유한하고 정렬된 호가 `0 <= bid <= ask <= 1`, 유효 UTC 시각, 발표 전 가용성,
계약·BLS 정의 일치는 모든 후보의 공통 조건이다. 확률은 동일한 호가 중간값 정의를 쓴다.
15분·0.10은 통계적 필연값이 아니며 연구상 품질 기준이다.

### 비교할 대상과 성능 차이

각 필터 후보에서 과거 발생비율과 Kalshi 모델을 동일 학습 사건과 동일 시험 사건으로
평가한다. 주 지표는 사건별 `d = CRPS(Kalshi) - CRPS(기준 모델)`과 그 평균이다.[^score]
향후 전통 거시정보 기준선이 완성되면 별도 버전에서 동일 방식으로 C−B를 검증한다.

필터 간 비교는 두 표로 나눈다.

- **공통 시험 사건 비교:** F0와 후보가 모두 평가 가능한 동일 사건에서 CRPS와
  대응 차이를 비교한다. 후보별 과거 학습 표본은 달라질 수 있으므로 학습 수와
  선택한 호가의 변화도 보고한다. 이는 표본 확대까지 포함한 정책의 효과다.
- **전체 가용 사건 비교:** 후보별 모든 평가 가능한 사건의 수·기간·CRPS를 보고한다.
  사건 구성이 다른 평균끼리의 차이를 모델 개선의 증거로 단정하지 않는다.

추가 원인 분석에서는 공통 학습·시험 사건도 고정하고 호가 선택 차이를 살펴본다.
확대 표본 효과와 확률 관측값 변경 효과를 가능한 범위에서 구분한다.
원시 CRPS, 기준 모델 대비 차이, 제외 사유, 관측 나이·스프레드·거래량 분포,
연도·국면·YES/NO 비율을 함께 기록한다. 네 자산·기간 조합을 사건 수로 합산하지 않는다.

### 결과 해석과 시험 보호

성능 개선은 엄격한 필터의 선택 편향을 증명하지 않는다. 학습 표본 증가, 평가 사건 구성,
호가 변경, 우연이 원인일 수 있다. 성능 악화도 엄격한 필터가 필수라는 증명은 아니다.
결론은 해당 비교 조건에서 관찰된 효과와 불확실성으로 제한한다.

기존 24건의 결과는 이미 관찰했으므로 이번 민감도 분석은 탐색적이다.
후보 선정은 개발 구간의 시간순 검증에서 수행하고 최종 시험은 결과를 보지 않은
향후 사건 또는 별도로 확보한 미열람 기간에 고정한다. 확인적 분석에 재사용하지 않는다.
기존 초기 학습 20건·최소 시험 10건의 연구 게이트를 유지하고 초기 5건 진단은 구분한다.
게이트 통과가 통계적 충분성을 보장하지 않는다. 모든 후보를 보고하고 유리한 조합만
선택하지 않는다. 사건별 대응 재표집 구간은 탐색적으로 보고하며 시간 의존성과
후보·자산·기간의 다중비교를 별도 고려한다.[^validation]

## 후속: DNN 구간 학습과 사건 단위 평가

슬라이딩 윈도우는 입력 구성 방법이고, 변형을 가하는 데이터 증강은 별도 방법이다.
100일 관측에서 길이 20일·간격 1일의 입력 구간은 81개지만, 각 구간 뒤에 예측할
미래 라벨이 필요하면 실제 지도학습 표본 수는 더 적다. 구간들은 상관되어 있으며
새로운 독립 CPI 사건을 생성하지 않는다.[^augmentation]

장기 시장 시계열에서 표현을 사전학습하고 이벤트 예측에 활용하는 방안은 후속 가설이다.
TS2Vec 같은 시계열 표현 학습이 방법론적 참고가 될 수 있으나 CPI·Kalshi에서의
성능 개선을 보장하지 않는다.[^representation] 우선 단순 기준 모델과 데이터 감사를 완성한다.

1. 시간순·사건 단위로 개발/검증/최종 시험을 정의한 뒤 윈도우를 만든다.
   같은 발표의 모든 자산·시점·증강본은 동일한 평가 구간에 귀속시킨다.
2. 정규화·특징 선택·증강·DNN 사전학습은 각 fold의 과거 학습 자료에만 적합한다.
   무라벨 데이터라도 미래 시험 기간을 사전학습에 사용하지 않는다.
3. 훈련 라벨 구간이 검증·시험 시점까지 걸치면 해당 훈련 표본을 제거한다.
   입력 길이·예측 기간을 기록해 경계와 정보 가용시각을 검증한다.
4. 시험에서도 예측 시점 이전의 실제 자료로 만든 입력 윈도우를 사용할 수 있다.
   실제 운영처럼 과거 입력 일부가 겹치는 것 자체가 항상 누수는 아니다.
   동일 사건의 중복 예측을 독립 시험 사건으로 세거나 시험 증강본으로 표본 수를
   부풀리지 않는다. 주 평가 시점·기간을 고정하고 사건별 점수 하나씩 비교한다.[^validation]
5. 과거 시험 사건은 결과가 가용해진 뒤 사전 고정된 walk-forward 절차의 후속 학습에
   들어갈 수 있다. 그 결과를 본 뒤 전체 시험에 맞춰 모델이나 기준을 조정하지 않는다.

최종 평가는 실제 관측 결과를 사용하며 사건 수와 시계열 의존성을 함께 보고한다.
실제 CPI 사건도 경제 국면에 따라 의존할 수 있으므로 무조건 독립이라고 가정하지 않는다.

## 참고문헌과 적용 범위

[^score]: Gneiting & Raftery (2007), *Strictly Proper Scoring Rules, Prediction, and Estimation*, JASA 102(477), 359–378. [논문](https://doi.org/10.1198/016214506000001437). 확률 예측 평가와 CRPS의 근거이며 본 프로젝트의 필터 임계값이나 표본 수 기준을 정당화하지 않는다.
[^validation]: Roberts et al. (2017), *Cross-validation strategies for data with temporal, spatial, hierarchical, or phylogenetic structure*, Ecography 40, 913–929. [논문](https://doi.org/10.1111/ecog.02881). 의존 자료의 검증 원칙을 참고한다. 금융 사건의 구체적인 시간 분할·라벨 가용성 규칙은 본 프로젝트 설계다.
[^augmentation]: Wen et al. (2021), *Time Series Data Augmentation for Deep Learning: A Survey*, IJCAI, 4653–4660. [논문](https://www.ijcai.org/proceedings/2021/631). 시계열 증강의 방법과 한계를 다루며 증강이 독립 사건 수를 늘린다는 근거는 아니다.
[^representation]: Yue et al. (2022), *TS2Vec: Towards Universal Representation of Time Series*, AAAI 36(8), 8980–8987. [논문](https://doi.org/10.1609/aaai.v36i8.20881). 시계열 표현 학습의 참고 연구이며 Kalshi 기반 자산 예측의 직접 검증은 아니다.
