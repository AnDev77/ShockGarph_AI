# 금융 자료와 종목 커뮤니티의 책임 경계 및 1차 배포 계획

결정일: 2026-10-28(한국 시간). 이 문서는 목표 구조와 10월 31일 배포 판정 기준이다. 문서 작성은 기능 구현·배포·모델 성능을 뜻하지 않는다. [이전 5일 계획](finance-community-five-day-milestones.md)의 사건별 방 가정은 바뀌었다. 개인 노트는 첫 배포에서 제외하고 후속으로 둔다. [Java–FastAPI API 계약](api/finance-service-contract-v1.md)이 실제 경로와 이전 조건의 기준이다.

## 제품의 두 축과 화면

| 축 | 사용자에게 보일 것 | 첫 배포의 한계 |
|---|---|---|
| 거시 발표·분석 | 공식 FOMC·CPI·고용 일정과 원문, QQQ·SPY의 같은 기준 과거 관측, 출처·시각·자료 상태 | 실제 가격 표시 권리가 확인되지 않으면 수치 미노출. 발표와 움직임의 인과관계나 미래 방향 예측을 주장하지 않음 |
| 종목별 개인화·대화 | QQQ·SPY 관심 등록, 자료 목록·상세, 공개 읽기·로그인 쓰기 종목방 | 개인 노트·임의 종목방·계좌 연동·주주 인증·결제는 후속 |

| 화면 | 사용 흐름과 최소 상태 |
|---|---|
| 홈 | 다음 공식 발표 목록 → QQQ·SPY 선택; 원문 시각과 한국 변환 시각·출처 표시 |
| 종목 상세 | 자료 목록의 카드 선택 → 공식 발표·기사 링크와 관련 근거 → 허가된 과거 관측 또는 자료 없음 상태 |
| 개인 영역 | 회원 관심 목록 등록·조회·삭제. 개인 노트 화면은 첫 배포 범위 밖 |
| 종목방 | QQQ 또는 SPY의 공개 메시지 조회 → 로그인 작성 → 커서 재접속·신고·삭제 |
| 연구 상태 | 미래 예측 수치는 독립 사전 평가 전까지 `HOLD`; TLT 연구를 QQQ/SPY 전망으로 전용하지 않음 |

외부 기사 본문은 공급원 권리 확인 없이 복제하지 않는다. 목록은 출처·시각·원문 링크와 연결 이유를 우선 제공한다. 공개 의견과 공식 자료·검증된 계산은 화면에서 구분한다.

## 백엔드의 단일 소유권

| 책임 | 최종 소유자 | 현재 확인된 상태 |
|---|---|---|
| 공식 발표 수집, 원본·이용 시각 검증, QQQ·SPY 과거 관측과 모델 평가 | ShockGraph의 Python 작업과 FastAPI 읽기 API | 수집·연구 기반 및 초안 사건 카드 계약 존재. 공식 자료의 자동 입력, QQQ/SPY 과거 반응 공개 API·화면은 미완료 |
| 회원·관심 목록·종목방·신고·향후 노트/결제/구독 | 금융 Java 영역 | doChallenge에는 운동 모임 인증·채팅 초안만 있음. 금융 관심 목록·종목방·노트·결제는 미구현 |
| 단일 웹 주소와 화면 | 웹/앱 및 라우팅 | `/api/market/**`는 FastAPI, `/api/member/**`·`/api/community/**`·`/ws/**`는 Java로 연결하는 목표. 브라우저 통합 미검증 |

ShockGraph PR #11의 FastAPI 회원 관심 목록은 **현재 초안의 임시 통합 계약**이다. Java를 최종 소유자로 삼을 때는 회원 ID·종목별 이전, 중복·삭제·롤백을 시험한다. 이전 전에는 임시 소유권을 명시하며 두 DB에 같은 관심 목록을 양방향 저장하지 않는다. doChallenge 운동 모임의 참가 자격을 금융 종목방 권한으로 재사용하지 않는다. 금융 Java 실행체의 저장소·배포 단위는 별도 구현에서 정하되 기존 운동 서비스를 금융 제품의 영구 신원 저장소로 가정하지 않는다.

두 서비스는 상대 DB를 직접 수정하지 않는다. Java의 로그인 토큰과 FastAPI의 검증은 실제 두 서버에서 발급·조회·만료·위조·회원 삭제를 연결해 시험한다. 내부 분석 호출은 브라우저 토큰 전달과 별개로 권한을 정의한다. 향후 결제의 주문·승인·취소·구독 상태는 Java가 소유하고 FastAPI는 유료 조회 권한 결과만 확인한다. Kafka는 원본 저장 후 아웃박스의 비동기 후속 처리 후보이며 이번 사용자 화면과 채팅의 선행 조건이 아니다.

## 1차 배포 판정

- **제한 공개 베타:** HTTPS 접속 주소, 운영 DB/비밀값, 실제 브라우저·실DB 사용자 흐름(노트 제외), 공식 일정과 최소 한 종류의 실제 출처 자료, 표시 권리가 확인된 과거 관측, 채팅 신고 처리, 배포 상태 검사·롤백을 모두 확인한 경우. 가격 원문은 공개하지 않고 허가된 파생 값만 표시한다.
- **내부 시연:** 위 입력·호스트·권리·기능 일부가 없으면 로컬 또는 제한된 DEMO만 시연한다. 자료 없는 화면이나 합성 가격을 실자료·배포 성공이라고 부르지 않는다.
- **배포 보류:** 타인의 관심 목록 노출, 미래 발표값 조기 공개, 인증 우회, 채팅 무단 전송/신고 불능, 표시 권리 위반, DB 장애를 가짜 정상 응답으로 숨기는 경우.

코드가 바뀌면 각 저장소의 빌드·정적 검사·전체 시험·원격 PR 게이트를 확인한다. 시험 통과와 모델의 실제 미래 성능 및 사용자 재방문 수요는 별개다. 미래 정답과 독립 평가가 충분해지기 전 모델 성능은 `HOLD`. 초안 PR의 자동 병합이나 승인 없는 배포는 하지 않는다.
